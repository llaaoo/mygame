# 余烬监狱 · 2D 探索与组合战斗 MVP

Godot 4.6.3 单人原型：从营地进入监狱，发现技能记录，通过条件组合释放法术，解救测绘员、改变监狱水路、完成营地委托并击败火焰领主。

## 运行

使用 Godot 4.6.3 打开 `project.godot`，按 F6 运行当前场景或 F5 运行项目。项目默认入口是 `mvp.tscn`；命令行运行：

```bash
godot --editor --path . --import
godot --path .
```

云环境中如需可写用户目录，可先设置：

```bash
export XDG_DATA_HOME=/workspace/.mygame-env/data
export XDG_CONFIG_HOME=/workspace/.mygame-env/config
export XDG_CACHE_HOME=/workspace/.mygame-env/cache
mkdir -p "$XDG_DATA_HOME" "$XDG_CONFIG_HOME" "$XDG_CACHE_HOME"
```

启动后阅读介绍，点击“开始探索 / 继续旅程”。首次可先阅读营地“施法材料手册”，再去工作台加工或按M配置材料。

“法术组合规则”指动作、法阵、Buff与施法材料共同决定法术结果；“制造配方”指工作台把原料加工成库存物品。两者在数据和存档中分别管理，旧法术知识自动兼容迁移。

## 操作

| 输入 | 行为 |
|---|---|
| WASD | 移动 |
| 鼠标左键 | 近战；若自行装备左手技能，则使用该技能 |
| 鼠标右键 / 6 | 火花：按下瞄准，松开释放 |
| 空格 | 闪避，也会取消正在准备的组合 |
| 按住 Shift 施法 | 消耗适配恩赐强化本次法术；普通施法保留恩赐 |
| E | 阅读记录、领取补给、使用通道或篝火 |
| 1 | 学会后的震荡 |
| 2 | 学会后的凝神 |
| 3 | 学会后的霜阵 |
| 4 | 学会后的水引 |
| 5 | 学会后的火阵 |
| K | 调整已掌握的技能编组，包括雷阵和泼洒树脂 |
| M | 材料库存、按动作配置强化；营地可加工 |
| J | 探索日志、法术组合规则说明和路线提示 |
| Esc | 暂停、返回营地或重置遭遇 |
| F5 / F9 | 保存 / 恢复探索进度并返回营地 |

法阵需要合法的空地。瞄准铭刻时会显示范围，红色表示被障碍阻挡。准备中明显移动或受伤会取消；不同类型法阵可并存，同类重建只更新自己。站在重叠处，同一动作会共同触发相容结果，总费用相加；走到仅覆盖一个圈的位置可只触发该圈。

## 路线与发现

```text
余烬营地 → 监狱外院 → 黑火药库 → 重卫关隘 → 熔炉大厅
              ↓           ↓           ↓
          军械档案室    排水回廊     返回营地捷径
              ↓           ↓
          静默祈堂     蓄水机房 → 营地检修梯
```

- 外院入口的记录教授火阵与火球法术组合规则。
- 军械档案支路教授震荡与范围焰环。
- 排水支路教授霜阵与寒霜弹。
- 静默祈堂的凝神碑教授凝神与两种互斥增益；机房的试验记录教授寒霜新星，这些记录需清场后领取。
- 9 个区域包含 8 处战斗遭遇，共17名守卫与一名火焰领主。
- 前进通道要求清场；通常可以退回前一区域整备。
- 火球可以引爆油桶；环境火焰也会伤害玩家。
- 补给点只领取一次，营地篝火可重复恢复生命与法力。
- 战斗升级获得属性点，可在营地训练点分配，结果自动保存。
- 档案室清场后可救回测绘员艾妲；她会出现在营地，与委托板使用同一交付入口。
- 营地有“失联的测绘员”“重启水路”“失落的组合研究”三项委托，分别奖励1、2、2属性点，每项只可领取一次。
- 蓄水机房可选择冷却熔炉（新Boss遭遇生命280→210、火抗30%→10%），或魔力导流（法力回复3→5 MP/秒）。可以回机房改道，效果从下一次进入区域生效；不会重生已清场的敌人。两者均开启营地往返检修梯。
- J日志显示区域状态、委托进度、已学法术组合规则和当前水路。人物、通路、机关与记录使用不同颜色和图标。

## 15条条件法术组合规则：法阵与回响

| 条件与动作 | 结果 | 基础消耗 |
|---|---|---|
| 火阵内使用火花 | 定向火球 | 12 MP + 法阵一次触发 |
| 火阵内使用震荡 | 以法阵为中心的范围喷发 | 14 MP + 法阵一次触发 |
| 霜阵内使用同一个火花 | 寒霜弹，命中减速 | 10 MP + 法阵一次触发 |
| 霜阵内使用震荡 | 寒霜新星，范围伤害与减速 | 12 MP + 法阵一次触发 |
| 火阵内使用凝神 | 余烬战意，10秒近战攻击力+8并赋予火焰命中 | 10 MP + 法阵一次触发 |
| 霜阵内使用凝神 | 霜行，8秒移速+30% | 10 MP + 法阵一次触发 |
| 雷阵内使用火花 | 雷矢，连锁近敌，强化对潮湿目标伤害 | 11 MP + 法阵一次触发 |
| 雷阵内使用震荡 | 雷环，范围雷击与水面导电 | 13 MP + 法阵一次触发 |
| 雷阵内使用凝神 | 雷息，9秒移速+15%，后续雷击伤害+35% | 10 MP + 法阵一次触发 |

火花和震荡在阵外有较弱的近距离效果。凝神在阵外消耗4 MP，提供5秒移速+8%；四种凝神增益互斥，重新释放会替换/刷新，离开区域时清理。组合结果不是独立可装备技能。每个法阵持续 15 秒、两次触发；技能栏显示当前实际结果、费用与准备进度。

静默祈堂的“回响刻板”与排水回廊的“毒理记录”提供新的准备动作。用K编组回响铭印和毒雾：

| 准备与动作 | 结果 |
|---|---|
| 回响印记＋火花 | 回响三重矢，12 MP |
| 回响印记＋震荡 | 回响脉冲，范围最多三次命中，14 MP |
| 回响印记＋凝神 | 共鸣护盾，8秒减伤40%，10 MP |
| 回响印记＋水引 | 回响复苏，四次恢复共至多24生命，9 MP |
| 回响印记＋毒雾 | 穿透孢子，12 MP＋毒性萃取1 |
| 共鸣护盾＋Shift＋震荡 | 主动消耗护盾，范围守护爆破，8 MP |

回响铭印本身需要6 MP和回响墨1，印记持续12秒，随施法者移动。状态法术组合规则消费准备状态；相容法阵结果同时响应，另消费对应法阵次数。Shift释放时，状态作用域中守护爆破优先于回响；互斥增益取优先级最高者，同级取后布的阵。悬停技能槽查看全部结果与总费用。准备中状态过期或被刷新会取消，跨区与读档不保留临时印记。

## Buff的保留与兑现

普通施法可保留恩赐：余烬战意/霜行使适配火焰/冰霜法术伤害+20%，雷息保留已有雷击命中+35%。按住Shift施放适配伤害动作，额外3 MP并消费恩赐，换取更强形态：

- 余烬：更高伤害，火球留燃烧区，近身火花/喷发扩大并铺火；失去原攻击与火焰近战收益。
- 霜行：更高伤害、冰弹额外穿透2次或新星半径+36；失去移速收益。
- 雷息：更高伤害、雷矢增加2发或雷环半径+48；失去持续移速与命中增益。与雷晶粉可组合为五发，保留粉末的伤害取舍。
- 共鸣护盾：普通震荡保留40%减伤；Shift＋震荡才消费护盾释放爆破。

不适配的动作不会误吃恩赐；输入意图在准备开始时锁定。细节与Outward参考见 [Buff依赖与兑现](docs/BUFF_CASTING_DESIGN.md)。

## 用已有机制产生变化

- 火阵与雷阵错位叠放，在交叠处一次火花同时产生火球和雷矢，23 MP、每个阵一次触发；也可以走到单圈区域节省资源。回响等相容准备可继续共同响应。
- 余烬战意将普通挥击变成火元素工具：能烧敌人、融冰、引爆中毒，或点燃油桶/油面、打开已有火元素机关。
- 雷电沿连通水面绕过拐角传播，干燥空隙会截断。水引的铺设形状、敌我站位都会影响结果。
- 共同动作总费用不足、准备中离开部分圈或任一效果被拒时，整次取消；不会少发一个结果、误扣费用或留下一半免费效果。

设计依据与已核对的Outward资料见 [联动复盘](docs/OUTWARD_INTERACTION_REVIEW.md)。

## 法术联动、材料与世界

- 水引无直接伤害，可灭火并制造水域。水引→冰霜触发凝冻，水引→火球触发蒸发，冰霜→火球触发融化，水引→雷矢/雷环触发导电。雷息可继续强化雷击。
- 冰霜冻结水域，雷电令水面带电，火焰把水变成蒸汽，也能点燃油面。覆盖层显示实际地面状态，地面危险也会影响玩家。
- 毒雾消耗毒性萃取制造毒区；水引可冲洗毒区和解除中毒，火球可引爆中毒目标。毒性冰霜可同时施加冻结与中毒，再接火球触发两种反应。
- 铭刻灰使火/霜阵持续更久；树脂使火球减速并在命中后留下燃烧区；霜盐提高冰霜穿透或范围；雷晶粉可把雷矢变成三发散射。回响墨还能让三重矢穿透，毒性萃取可给冰霜附毒，守护粉延长增益。每种强化有额外法力和材料费用。
- 雷阵每次铭刻必需雷晶粉1；泼洒树脂必需树脂制剂1。雷阵在机房清场后学习，两者用K编组。
- M按动作配置可选材料；不足会拒绝释放，需明确取消强化才可用普通版本。预览、中断和失败不扣费，成功打空会消耗。
- 营地工作台把炭屑、树液、晶砂加工为七种成品；守护粉还需要先加工铭刻灰。外院荆棘药箱、排水回廊热冲击封匣、档案室导能晶簇可通过法术解开，获得材料。另有祈堂的三相共鸣锁、关隘的守护誓碑和回廊的毒性蒸馏器，共六处法术机关。
- 原料与机关奖励只领取一次，休息和重置遭遇不补满。旧存档可回营地领取新手册，无需重开。

完整数值、反应规则和资源来源见 [法术与施法材料说明](docs/CASTING_MATERIALS_DESIGN.md)。

## 保存与失败

MVP 使用独立的 `user://save_2.sav`，不会读取或覆盖旧房间模式的默认槽 1。重要发现、清场、区域切换与编组调整会自动保存，手动 F5 也可保存。写入先生成临时文件，并保留上一份 `.bak`。

主档损坏时会尝试有效备份；无法恢复或版本较新时保留原文件，禁止自动覆盖。手动读档失败会保留当前旅程。

保存知识、发现记录、角色成长、技能编组、环境破坏、探索/清场里程碑、委托领奖、水路选择、施法材料库存与配置、法术机关完成状态；不从战斗中途恢复投射物、法阵或临时 Buff。读档回到营地。死亡也返回营地，保留已取得进度，未清理遭遇重新开始。

本章清场进度默认保留，不随休整刷新。暂停菜单的“重置遭遇”会重建战斗与环境，保留已学知识、委托奖励、水路选择和发现记录；已领取补给不重复发放。旧版本存档无需重开，进入新增支路即可继续探索。
