## 人形敌人与玩家共用角色规则

旧存档不重新生成已击败敌人；Esc→重置河谷遭遇可重复体验，保留世界成果但不再给击杀奖励。当前范围与实测见[共用角色与敌人](docs/SHARED_CHARACTERS.md)。

## 灰河谷战利品：所见即所得

人形敌人的刀、矛、法杖、皮甲、靴、盾与饰物来自实际穿戴，同一件装备给敌人与玩家相同效果。基础人形外观不再绘制未持有的武器护甲。靠近敌人按F观察，击败后靠近遗骸按F逐件或全部搜刮；用掉的材料不会补回，满背包或满水囊时余物保留，离区、死亡与读档均不重抽。O查看持有件数，脱离附近敌人且结束当前动作后可手动换装，I与O沿用同一库存。

灰河谷现有22个遭遇、11项委托，新增断桥守望者洛恩、矿道运料官芮克和封锁执事赫铎，9种可回收装备。新增运料线提供搜刮与绕路找货两种途径：读被截的运料单，搜刮行囊或寻找货车/矿工样品箱，向镇中索砾交付真实原料。已有清场存档仍能遇到新增具名角色；无奖励重试不会生成新战利品。规则、兼容与验证范围见[灰河谷装备与战利品](docs/GRAYRIVER_LOOT.md)。

## 远征界面与河谷人物

Tab或右下角按钮统一打开整备与制作、委托、装备、补给、知识和操作设置；用鼠标进入编组和选材，靠近设施后可点击交互按钮。列表支持搜索与筛选，装备对照显示同槽数值变化；追踪委托会随目标完成更新，HUD给出方向与距离，未探索的目标不公开精确位置。M支持缩放、拖动与自定路标；路标可以清除，追踪委托会替换自定路标。

## 现场组合与本地试玩

快捷栏保留基础动作，组合结果来自当前法阵、地面、恩赐、材料与装备；没有组合预案、自动补阵或连招按钮。G选择本次材料：适配且成功实际使用才消费并清除，取消或失败保留，离区/死亡/读档清除选择但保留库存。

菜单返营现在解除暂停后站定撤离3秒，移动、攻击、施法和受伤会打断。敌人近战有锁向扇形预告、远程锁向提示、首领范围预警，侧向移动与距离可以使攻击落空。回廊清场后可用炭屑2、谷粮2建设永久检修前哨，提供原短休与需燃料/真实火源的锅位。

N显示当前需求与可搜索补给，详细规则二级查看；HUD以状态图标显示食物、饮水与茶计时；J记录已发现补给、建设、捷径与未取部件。实验名称仅给记录命名，不执行或应用配置。见[操作与本地包说明](docs/LOCAL_PLAYTEST.md)、[五轮实施记录](docs/FIELD_COMBINATION_ITERATION.md)与[首章实测](docs/FIELD_CHAPTER_PLAYTEST.md)。

## 远征生存：饮食、饮水与休整

N查看需求和补给。营地西侧领取一次性口粮袋；井边装水，炉灶烤饼或净水。档案室和回廊可学茶与炖汤，谷粮/苦叶需要240秒游戏时间再生。食物和饮水影响恢复，疲劳影响施法准备；耐力能减少消耗。

野外锅可借真实火焰节省炭屑，踩入燃烧格会受伤并打断；水源冻结、导电或污染会改变取水条件，修复排污泵能改善水质。回营和读档不自动补满生命法力，到篝火主动休整；免费粗食保证耗尽补给仍能整备。规则和验证见[远征生存](docs/SURVIVAL_EXPEDITION.md)。

## 元素构筑试玩：四类基础元素

本轮已接通“地面／材料→Shift凝神→元素恩赐”：水系流息提供减伤，毒契提供抗毒，火、水系凝霜、雷继续复用已有恩赐；完整或部分消费会改变持续收益与自身风险。动作/法术组合/材料/装备为11/24/7/4，详细费用、解锁和实例见[四元素恩赐联动](docs/FOUR_ELEMENT_ATTUNEMENT.md)。

水与霜已合并归属：同一个水系可铺水清洗、凝霜控制、破冰接路，并与火形成蒸汽、与雷或毒交互。规则与兼容方式见[元素与形态修订](docs/ELEMENT_FAMILY_DESIGN.md)。

火、水、雷、毒共用元素与地面定义；凝霜并入水系，与液态水和蒸汽形成同一体系的不同用途，已有动作、材料和装备数量保持不变。蒸汽现在减免25%投射物直接伤害，导电水域保留潮湿性质；节律护手可让Shift部分消费恩赐，保留剩余时长50%，换取较弱伤害强化与额外费用。

J→知识可查看“元素关系”及“实验路线与配置记录”。档案室、排水回廊和机房各有一次性实验补给；机房分流阀能改变实际水路，冰可断路、震荡可接回，检修晶闸检测实际导电。敌人会按风险和碰撞选择局部移动方向。记录页可比较四种配置的操作、伤害、耗材和用时。

具体玩法、规则边界与验证见[元素构筑试玩交付说明](docs/FIVE_ELEMENT_IMPLEMENTATION.md)。20—30分钟是待实际试玩校准的目标。

## 重启调和台：多种检修方式

营地东北接取“重启调和台”，档案室读图纸，再去回廊和机房解封、现场F取回部件。可用有效力量/智力、已有法术链或有限材料完成。现场F查看、C切换、F站定开始，Esc收起；战斗继续，受伤、移动或其他动作会中断，只有成功才扣材料。

## 运行

使用 Godot 4.6.3 打开 `project.godot`，按 F6 运行当前场景或 F5 运行项目。项目默认入口是 `grayriver.tscn`；命令行运行：

```bash
godot --editor --path . --import
godot --path .
```

云环境中如需可写用户目录，可先设置：

```bash
export XDG_DATA_HOME=/workspace/.mygame-env/data
export XDG_CONFIG_HOME=/workspace/.mygame-env/config
export XDG_CACHE_HOME=/workspace/.mygame-env/cache
mkdir -p "$XDG_DATA_HOME" "$XDG_CONFIG_HOME" "$XDG_CACHE_HOME"
```

启动后阅读介绍，点击“开始河谷旅程”。首次先阅读镇中施法手册、领取离镇口粮，沿路牌自行选路。材料制造配方随探索学习，按G选择本次强化材料。

“法术组合规则”指动作、法阵、Buff与施法材料共同决定法术结果；“制造配方”指工作台把原料加工成库存物品。两者在数据和存档中分别管理，旧法术知识自动兼容迁移。

## 现有技能的组合与用途

当前重点是复用已有工具。基础火花也能融冰、蒸发和引爆中毒；震荡可用剩余冻结控制换取碎冰伤害，也能打碎冻结水路，接回导电通路。水引、树脂与毒雾支持鼠标选择120范围内落点，水引放在脚下可洗去燃烧和中毒。凝神恩赐仍由玩家选择保留或主动消费。

基础动作数量保持不变，详细关系与取舍见[现有技能组合与扩展](docs/EXISTING_SPELL_INTERACTION_PLAN.md)。

水引现在可通过霜盐、雷晶粉或毒性萃取铺设冰面、导电水域或毒地；同一份材料与现有恩赐、装备借阵继续联动。戴守阵者指环，在火阵内Shift施放毒水，地面会依次由水变毒、再被引燃，消耗材料、充能和额外法力。普通施法保留原用途，污染水不能洗毒，导电也可能伤到自己。规则与试玩路径见[涌现施法设计](docs/EMERGENT_CASTING_DESIGN.md)。

## 已接通的魂术、Buff与装备

外院新增“魂术拾遗”：击败守卫留下蓝白残魂，60秒内靠近，用K编组汲魂。4 MP换1层蕴魂，默认上限3层、持续45秒；满层或中断不吞残魂。普通施法保留，Shift＋火花/震荡/凝神/水引各消费1层，分别得到穿透魂焰、魂霜范围、先祖护佑、净魂。先祖护佑还可保留防护或主动释放。树脂、霜盐、回响墨、守护粉沿用既有强化规则；魂术也可解开外院的缄默骨匣。

O打开装备与构筑，营地整备台换装；I背包沿用同一装备系统。四件固定探索装备带来布阵范围、魂量容量、恩赐释放、准备速度的取舍，同槽只能选一件。旧存档会补回已领取发现新增的装备，保持未装备状态；未领取的装备在详情中给出来源线索。技能、Buff和装备均有预览、失败回滚、跨区清理与保存验证。

详细规则、取舍与测试见[技能—Buff—装备迭代](docs/SPELL_BUFF_EQUIPMENT_ITERATION.md)。

## 路线与发现

```text
余烬营地 → 监狱外院 → 黑火药库 → 重卫关隘 → 熔炉大厅
              ↓           ↓           ↓
          军械档案室    排水回廊     返回营地捷径
              ↓           ↓
          静默祈堂     蓄水机房 → 营地检修梯
```

- 外院入口的记录教授火阵与火球法术组合规则。
- 军械档案支路教授震荡与范围焰环。
- 排水支路教授霜阵与寒霜弹。
- 静默祈堂的凝神碑教授凝神与两种互斥增益；机房的试验记录教授寒霜新星，这些记录需清场后领取。
- 9 个区域包含 8 处战斗遭遇，共17名守卫与一名火焰领主。
- 前进通道要求清场；通常可以退回前一区域整备。
- 火球可以引爆油桶；环境火焰也会伤害玩家。
- 固定奖励只领取一次；谷粮和苦叶采集有独立再生时间。营地篝火需主动休整，恢复会消耗饱食和饮水。
- 战斗升级获得属性点，可在营地训练点分配，结果自动保存。
- 档案室清场后可救回测绘员艾妲；她会出现在营地，与委托板使用同一交付入口。
- 营地有“失联的测绘员”“重启水路”“失落的组合研究”“狱中复核”“重启调和台”五项委托，分别奖励1、2、2、1、1属性点，每项只可领取一次。
- 蓄水机房可选择冷却熔炉（新Boss遭遇生命280→210、火抗30%→10%），或魔力导流（法力回复3→5 MP/秒）。可以回机房改道，效果从下一次进入区域生效；不会重生已清场的敌人。两者均开启营地往返检修梯。
- J日志显示区域状态、委托进度、已学法术组合规则和当前水路。人物、通路、机关与记录使用不同颜色和图标。

## Buff的保留与兑现

普通施法可保留恩赐：余烬战意/霜行使适配火焰/冰霜法术伤害+20%，雷息保留已有雷击命中+35%。按住Shift施放适配伤害动作，额外3 MP并消费恩赐，换取更强形态：

- 余烬：更高伤害，火球留燃烧区，近身火花/喷发扩大并铺火；失去原攻击与火焰近战收益。
- 霜行：更高伤害、冰弹额外穿透2次或新星半径+36；失去移速收益。
- 雷息：更高伤害、雷矢增加2发或雷环半径+48；失去持续移速与命中增益。与雷晶粉可组合为五发，保留粉末的伤害取舍。
- 共鸣护盾：普通震荡保留40%减伤；Shift＋震荡才消费护盾释放爆破。

不适配的动作不会误吃恩赐；输入意图在准备开始时锁定。细节与Outward参考见 [Buff依赖与兑现](docs/BUFF_CASTING_DESIGN.md)。

## 用已有机制产生变化

- 火阵与雷阵错位叠放，在交叠处一次火花同时产生火球和雷矢，23 MP、每个阵一次触发；也可以走到单圈区域节省资源。回响等相容准备可继续共同响应。
- 余烬战意将普通挥击变成火元素工具：能烧敌人、融冰、引爆中毒，或点燃油桶/油面、打开已有火元素机关。
- 雷电沿连通水面绕过拐角传播，干燥空隙会截断。水引的铺设形状、敌我站位都会影响结果。
- 共同动作总费用不足、准备中离开部分圈或任一效果被拒时，整次取消；不会少发一个结果、误扣费用或留下一半免费效果。

## 法术联动、材料与世界

- 水引无直接伤害，可灭火并制造水域。水引→冰霜触发凝冻，水引→火球触发蒸发，冰霜→火球触发融化，水引→雷矢/雷环触发导电。雷息可继续强化雷击。
- 冰霜冻结水域，雷电令水面带电，火焰把水变成蒸汽，也能点燃油面。覆盖层显示实际地面状态，地面危险也会影响玩家。
- 毒雾消耗毒性萃取制造毒区；水引可冲洗毒区和解除中毒，火球可引爆中毒目标。毒性冰霜可同时施加冻结与中毒，再接火球触发两种反应。
- 铭刻灰使火/霜阵持续更久；树脂使火球减速并在命中后留下燃烧区；霜盐提高冰霜穿透或范围；雷晶粉可把雷矢变成三发散射。回响墨还能让三重矢穿透，毒性萃取可给冰霜附毒，守护粉延长增益。每种强化有额外法力和材料费用。
- 雷阵每次铭刻必需雷晶粉1；泼洒树脂必需树脂制剂1。雷阵在机房清场后学习，两者用K编组。
- G按动作配置可选材料；不足会拒绝释放，需明确取消强化才可用普通版本。预览、中断和失败不扣费，成功打空会消耗。
- 营地工作台把炭屑、树液、晶砂加工为七种成品；守护粉还需要先加工铭刻灰。外院荆棘药箱、排水回廊热冲击封匣、档案室导能晶簇可通过法术解开，获得材料。另有祈堂的三相共鸣锁、关隘的守护誓碑和回廊的毒性蒸馏器，本章现有10处可选机关，含本次两处可取件设备。
- 原料与机关奖励只领取一次，休息和重置遭遇不补满。旧存档可回营地领取新手册，无需重开。

完整数值、反应规则和资源来源见 [法术与施法材料说明](docs/CASTING_MATERIALS_DESIGN.md)。

## 保存与失败

MVP 使用独立的 `user://save_2.sav`，不会读取或覆盖旧房间模式的默认槽 1。重要发现、清场、区域切换与编组调整会自动保存，手动 F5 也可保存。写入先生成临时文件，并保留上一份 `.bak`。

主档损坏时会尝试有效备份；无法恢复或版本较新时保留原文件，禁止自动覆盖。手动读档失败会保留当前旅程。

保存知识、发现记录、角色成长、技能编组、环境破坏、探索/清场里程碑、委托领奖、水路选择、施法材料库存与配置、法术机关完成状态、调和台解封/取件/修复事实与完成方法；现场作业进度不存档，不从战斗中途恢复投射物、法阵或临时 Buff。读档回到营地并保留保存时生命/法力、需求与食品效果；死亡恢复半数生命/法力并提供应急需求下限。死亡也返回营地，保留已取得进度，未清理遭遇重新开始。

上段描述监狱MVP。灰河谷使用独立槽3并恢复实际旅程位置；v9保存个人定时增益、异常、控制恢复、周期进度、来源强度与冷却，F9和重新进入保持实际余量。离区按游戏时间结算效果与正常死亡掉落，休息同样推进计时；离线不推进。投射物、法阵、区域临时能量、瞄准与准备不恢复。旧v7/v8档按实际剩余食品效果兼容导入，迁移不重复清毒。

本章清场进度默认保留，不随休整刷新。暂停菜单的“重置遭遇”会重建战斗与环境，保留已学知识、委托奖励、水路选择和发现记录；已领取补给不重复发放。旧版本存档无需重开，进入新增支路即可继续探索。

## 验证与开发

测试与验证在云环境中执行。GitHub Actions 已停用，原工作流保留在 [备份目录](.github/disabled-workflows/README.md)，推送和 PR 不再自动触发测试。

统一运行入口会隔离存档并保留日志：

```bash
python3 tools/run_tests.py
python3 tools/run_tests.py --suite quick
python3 tools/run_tests.py --tests save_recovery cast_refactor
python3 tools/run_tests.py --tests gut_domain
```

已接入GUT 9.6.1（Godot 4.6），用于无帧率依赖的领域检查。runner按前置/并行集成/串行输入分阶段执行，保留`results.json`与错误摘要，并阻止同一检出目录重复运行。插件取舍、上游许可、测试失败原因与操作见[开发工具](docs/DEVELOPMENT_TOOLS.md)。

也可单独运行Godot脚本：

```bash
godot --headless --path . --script res://tests/test_exploration_mvp.gd
godot --headless --path . --script res://tests/test_exploration_content.gd
godot --headless --path . --script res://tests/test_spell_materials.gd
godot --headless --path . --script res://tests/test_advanced_spells.gd
godot --headless --path . --script res://tests/test_joint_interactions.gd
godot --headless --path . --script res://tests/test_boon_choices.gd
godot --headless --path . --script res://tools/validate_mvp_content.gd
```

直接运行Godot测试脚本会写入当前 `user://`，请使用独立 `XDG_DATA_HOME`；统一runner会自动隔离。完整命令、实现边界和验证限制见 [MVP 实现说明](docs/MVP_RELEASE.md)，架构改造见 [重构进展](docs/REFACTOR_PROGRESS.md)。
