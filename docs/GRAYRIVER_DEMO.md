# 灰河谷巡河篇章：系统深化与远征内容

2026-11-08（北京时间）。起点 e9c72fbb5537c780f1b39a4cf968c46ac3daa4fe。目标是约两小时的可玩demo；本文区分内容预算、受控验证、正常AI输入复走和未验收项目。

## 系统判断与边界

现有库存、真实穿戴/掉落、近战/弓、武技附魔、基础施法、表面反应、制造、采集、饮食、按小时休息和持久化已经可以支持远征内容。本轮优先补齐它们之间影响旅程的衔接：地面调谐形式、连续操作反馈、满包奖励、跨层指路、调查线索和不可逆世界后果。没有再引入通用任务脚本语言、第二份库存、独立副本掉落系统或新的数值成长框架。

架构继续按 Godot 4.6 的[场景组织](https://docs.godotengine.org/en/4.6/tutorials/best_practices/scene_organization.html)与[节点替代方案](https://docs.godotengine.org/en/4.6/tutorials/best_practices/node_alternatives.html)：定义是Resource，进度/领域服务是RefCounted，需要空间、命中或输入的对象才进入场景树。灰河谷JSON装配既有类型，不把JSON变成执行脚本。

新增小接口：

- `ExplorationQuestData.unlock_claims`：找到线索后才在委托列表显示；交付也重新验证可用性。旧任务空数组保持兼容。
- `ExplorationWorldEventData.irreversible`、`ExplorationWorldChoiceData.grants_claims`：明确选定后记录互斥世界事实，第二次请求拒绝。可改道的旧水路事件保持原行为；校验器禁止可反复改选的事件生成永久后果。
- `CampaignGame.grant_material_reward`：通用战役保留旧奖励适配；灰河谷通过现有`GrayriverLoot`实例转移领取。溢出保留在现场物资箱及原UID容器里，搜空后隐藏；重进不补满。没有把物资复制进另一份库存字典。
- `FrontierGuidance`：沿实际、已开放的出口图找下一段路线；多层地图通过返回链换算到河谷坐标。未到访的内部目标不在地图上透视，已知任务仍可引向入口。

## 六项修复

1. 智能水系调谐接入既有地面组合。另提供火、冰、雷、毒地的明确上下文形式；知识、Shift、真实地表、费用和提交时重验继续由原组合处理。条件消失拒绝，不回退成免费凝神。
2. 动作改绑为物品后，滚轮逐项验证瞄准、最近动作、最近轮盘来源；过期来源不再遮蔽有效槽。
3. 世界滚轮跳过与智能项实际形式相同的固定项，第一格就改变形式；G/K仍可明确选择跟随或固定。
4. 施法拒绝保留顶部通知；底栏只为真实瞄准、悬停或准备显示预览，移除重复通知与无关默认R预览。
5. 选材说明同时保留口袋/背包数量和现场来源，不相互覆盖。
6. 数量交易通过只读事务预演显示合计、付款方余额、资金可买数量、差额及实际拒绝原因；不可行按钮禁用。确认走同一库存事务并重新验证。

## 可玩结构

镇中任务板东侧的“巡河悬赏：三处失联”开启巡河调查。推荐先完成原北路的火阵教学和山脚档案馆，再沿下面的调查线推进。旧档也可接入，不重置原发现、物资、装备或封锁解除标志。

| 阶段 | 玩法与实际联动 | 建议内容预算 |
|---|---|---|
| 镇中准备、旧猎营与档案馆 | 学基础组合、采集制造、读调度令、取得卷宗；可先回镇卖战利品 | 20–30分钟 |
| 灰脊烽堡：庭院→风井 | 弓手射界与上下掩体路；冻风门、继电器、信号炉；修避风棚可按小时休息；名册与补给支线 | 20–25分钟 |
| 遗钟墓：侧廊→封室 | 绕毒地、净化架、脆裂封条；泵工回执与冰→火→冲击调音；净化后重进不再渗毒 | 20–25分钟 |
| 沉水泵站：大厅→压力井 | 水面导电、掩体、进水轮；南北控制器可任选顺序；最终明确决定供水或封压 | 20–25分钟 |
| 旧矿道、监狱、回镇交付与支线 | 原远征、旧监狱封锁、装备整修、报告、食品/耗材补给与成长 | 20–35分钟 |

预算合计100–140分钟，是首次阅读、探索、整备和部分支线的设计目标，**不是实测通关时长**。熟练直走、跳过阅读或跳过支线会更短；没有增加等待、强制刷怪或重复交付来凑时长。要把“稳定可玩两小时”视为已验收，仍需要完整真人新档盲玩计时、难度和资源反馈。

当前总计10个区域（河谷+9个内部区域）、43场固定遭遇、15处机关、19项委托。本轮增加6个内部区域、21场遭遇、10处机关和8项委托。旧地图、旧角色和旧配方保留。

新增4种真实角色配置：烽堡弓手（有限箭袋）、失联队长（剑盾与护衣）、泵站刻阵工（有限火石/喷剂）、遗钟守槛人（战杖）。角色外观与死亡物品读取实际库存，不另设奖励池；刻阵工用掉的介质不会再从模板掉出。强敌没有改用忽略角色装备的通用boss场景。

## 机关与路线

每个推进机关都有法术/表面路线和站定6秒的手工作业路线；手工材料从真实库存支付，受伤或离开中断，不提前扣料。三处上层的下行楼梯受实际机关事实约束，下层保留无需耗材的返回楼梯。不会因缺少某一种法术而困死在副本内。

| 地点 | 魔法路线 | 手工路线 |
|---|---|---|
| 烽堡风门 | 冰→冲击 | 废金属1、布料1 |
| 风井继电器 | 水→雷 | 废金属1 |
| 信号台 | 实际燃烧保持1秒 | 炭屑2、树液1 |
| 墓道净化架 | 水→火 | 苦叶2、布料1 |
| 墓道封条 | 火→冲击 | 废金属1 |
| 遗钟 | 冰→火→冲击 | 晶砂1、布料1 |
| 泵站进水轮 | 冰→冲击 | 废金属2 |
| 北侧控制器 | 水 | 清水1、布料1 |
| 南侧锁扣 | 火→冲击 | 废金属1、炭屑1 |

入口告示在第一组敌人之外，说明安全整备方向、前方威胁、机关要求和撤退方式。物资箱是有限的；采集点仍遵循游戏小时再生，料理与休息使用原生存规则。

最终总闸需要两个控制器都完成，且附近无敌人，玩家才能决定：

- **恢复供水**：下次进入河谷，东岸取水场开放清水口和常明柴灶；维护竖井不能通行。
- **永久封压**：下层维护竖井通往东岸，维护储备箱可领取；不会开放复水设施。

总报告要求档案馆卷宗、烽堡信号、遗钟回执、泵站决定和旧监狱清场；回镇交付后显示巡河终章，可继续探索。旧`completed`仍代表旧监狱阶段，新的终章用已有claims保存，不追溯清除旧档。

## 后续深化顺序

当前应先验证这条完整远征，避免继续叠加基础系统。最高优先级是三份同一起点存档分别走武器、法阵和物品投送，覆盖任务衔接、背包容量、食品/法力补给与死亡返程；再用真人首次游玩时长决定应补哪段内容。机关的两条路线已经可用，但战斗中的选材、状态提示与敌人起手仍需要这种整段对照来判断，不能从单次基础攻击样本推出平衡结论。

内容作者下一项最有价值的工具是前置事实图诊断：现有校验已检查引用、实际步行可达与无耗材返回链，未来应再发现相互等待的机关/任务前置，并把错误定位到JSON字段。它可以保护后续扩写，不需要另建任务执行语言。空间化机关表现、更多敌人战术与叙事支线应在完整远征反馈之后逐项增加；当前点数奖励、装备出售/拆解/强化和设施解锁已经足以承接新增探索收益。
