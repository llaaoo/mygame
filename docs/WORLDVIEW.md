## 基调与确认范围

这是一个仍有人生活、经营和相互依靠的边境世界。旧秩序正在松动，危险来自荒野、匮乏、欠账、被遗忘的职责，以及有人借权力维护的旧伤。魔法稀少，力量需要来源，获取和使用都伴随代价。

世界可以阴暗，但善意可以奏效。客栈的灯火、可靠的同行者、一次兑现的承诺和修好的水路，都应让玩家看见生活值得继续。悲剧不能成为所有任务的唯一结局，所有人也不必都藏着恶意。

| 层级 | 当前约定 |

| 已确认的创作方向 | 新玩家没有可用魔力；少数人经探索、考验和付出代价获得施法能力；魔法与日常技艺有边界；世界略阴暗且保留温情；神明确实存在；新内容服从世界内的因果与真实来源 |
| 暂用背景 | 本文的旧王国、灰河谷事故与觉醒旧事、神明分类和四位神祇概念，可先用于组织后续内容；涉及细节时保持一致 |
| 尚待设计 | 觉醒地点、具体试炼、代价数值与能否逆转、获得节奏、完整神谱、纪年、国名及大地图；这些不因本次归档而冻结 |

## 普通人的世界

大陆已有漫长的居住史，王国、城邦、地方领地和自治城镇通过商路与河道往来。铁器、作坊、水磨、窑炉和矿业构成日常生产。复杂的魔法设施需要少数专门人员维护，也依赖燃料、材料、劳力和运输。

暂以“旧王国”指曾统筹部分道路、水利、矿业与防务的较大政权。继承争执与地方分权削弱了其控制，留下仍被执行的命令、相互冲突的权利和无人负责的设施。具体王朝名称、年代及疆域后定；更古老的遗迹仍有超出已知工程历史的秘密。

灰河谷可以向上游山地矿镇、下游商贸城市、西部林地文化和东部旧军路扩展；这是未来创作方向，不是已完成的地图承诺。地区的差异来自地形、生计、历史与习俗，不按伤害元素机械划分国家。

## 魔力、觉醒与学习

### 玩家从普通旅人开始

新玩家没有可用魔力，不能直接施法。最初依靠武器、防御、闪避、工具、消耗品、陷阱、补给及他人帮助生存。玩家可以先得到材料、公式或法术记录；知道怎样做，与身体能够施法是两件事。

玩家具有少见的潜在适性，但不是预言中的唯一继承人。世界上存在其他适格者和不同传承，觉醒地点也不必只有一处。多数人终生不掌握魔法：适性、接触传承的机会、承担代价的意愿和持续训练缺一不可。

### 获得魔力是一段可选择的经历

1. 从文书、旅人或罕见施法者处获得线索。
2. 通过完全能以非魔法方式完成的冒险抵达相关地点。
3. 通过检验适性、理解风险的实际考验，而非只点击一个确认框。
4. 在清楚后果的前提下，自愿接受代价。
5. 获得魔力容量，再通过师承、记录、探索与练习学习具体技法。

觉醒是重要的个人转折。拒绝或延后觉醒仍应有完整的武者成长与主要探索路径；不能要求先施法才能获得第一次施法资格。需要魔法的可选秘密可以保留，必要进度须有合理的非魔法途径。

暂用的代价方向是长期体魄潜能与魔力容量之间的取舍。初次代价应清晰且受控，进一步深化需要继续投入；混合角色可依靠有限魔力与材料准备，深入施法者更依赖保护、补给和位置。具体属性损失、换算、是否可逆与重修方式仍待设计。

### 三种不同的获得

- **觉醒**赋予主动施法的资格，魔力容量描述可承载多少力量。
- **学习**赋予具体操作与公式知识，不能替代觉醒。
- **补充或强化**恢复既有魔力、改变容量或使用效率，不能通过普通加点、装备或药剂绕过觉醒。

信仰与神赐另有来源：法师可以不信神，未觉醒者也可能得到神明关注。一次神迹、赐福或借用器物的力量，不自动授予永久施法能力。

## 魔法与材料的共同规则

基础操作决定释放方式，材料和实际来源决定性质，法阵提供结构、维持与转化条件。组合来自现场准备和亲手执行，而非把每种效果变成一门独立技能。

觉醒后，火花、脉冲与基础凝能阵等可以有明确的无材料形式，但仍受魔力、知识和现场条件约束。无材料形式不是缺料时的自动替代。暂时召出的火、水或构造体可以存在；临时效果不能据此无限变成可储藏、出售或食用的永久库存。

| 行为或来源 | 世界观边界 |
|---|---|
| 药剂、毒瓶、燃烧物、普通喷剂 | 效果来自真实配方与材料，普通人可以按工具和知识要求使用 |
| 武器抹布、涂料 | 使用实物给具体武器附上材料所含力量；使用者无需因此成为法师 |
| 武技释放附魔 | 经训练可释放武器已储存的力量；必须消费真实涂层，不凭空生成元素 |
| 主动铭阵、调谐、塑形、汲取 | 属于主动施法，需要觉醒及相应知识；凝能阵无材料不等于无施法门槛 |
| 已充能器具 | 可以有独立于施法资格的使用方式，但须明确器具知识、充能及消耗条件 |
| 喷洒及其魔法强化 | 普通喷洒与需要施法的强化要分清；当前喷洒费用尚需按此迁移 |
| 食物、炼金、调谐、神赐 | 都可以产生状态，但来源各异；游戏中名为“恩赐”的状态不自动成为神明赐福 |

冰可以作为水的形态；不把现有元素目录、状态分类或伤害标签直接等同于宇宙本源与神谱。物品UID是实现身份守恒的技术工具，不是世界居民能够感知的神秘法则。犯罪与纠纷通过实际见证和传播成立，不由全知的道德监视者自动判定。

## 神明、信仰与代价

神明确实存在，能留下神迹、遗物与可见影响；对这些事实的解释仍可有分歧。神明不需要频繁现身解决凡人的日常困境，教会和祭司也不天然拥有无误的知识。

暂用两类概念组织创作，不视为已定的完整神谱：

- **立世诸神**与生死、季节、秩序等世界基础相连，也受到自身职责约束。主要通过圣地、征兆、梦、祝福和遗物行动，直接神迹罕见。
- **界外尊主**拥有与欲望、秘密、变化、记忆等相连的独立领域，通过化身、契约、交易、诱惑和委托接触凡人。

这两类不按善恶一刀切。凡人祭司可能误解神意或借教义谋利；界外存在也可能切实帮助一个人，只是它理解承诺、身份与代价的方式不同于人类。

| 暂用称谓 | 领域与日常联系 | 内容方向 |
|---|---|---|
| 守灯者 | 庇护、归途、旅人平安；客栈、路卫与家人 | 路灯、避难、接待陌生人及守住庇护承诺 |
| 铸誓者 | 工艺、契约、责任；工匠、官员与部分守卫 | 作品与承诺的责任，合法命令和正当职责的冲突 |
| 渡终者 | 死亡的边界、亡者安宁 | 遗骸、姓名、葬仪及处理残魂的规矩 |
| 藏名者 | 界外的秘密、名字与遗忘 | 藏起受迫害者的身份，也可能索取被记住的权利 |

称谓和具体教义可继续调整。不可为了接入四种增益就制造四个只负责卖属性的神；信仰应先在习俗、人物选择、建筑与冲突中成立。现实事故可以有人为原因，不必把所有线索最终归因于神明操控。

## 死亡、残魂与记忆

强烈的生命活动、情感或长期魔法作用可能留下回响；死后残魂是有条件出现的现象。回响是否保有完整人格，仍是信仰与研究中的争论，不预设每个可吸取能量都等于一个完整的人。

处理残魂可能影响亡者、亲属与活人，不同地方会有葬仪、亲属许可和禁忌。回收自己法阵的余能，与汲取死者残魂可以技术相关，却具有不同的社会与伦理含义。当前“蕴魂”也可以来自法阵余能，不能据状态名称把每次使用都解释成杀人。

死亡后的普遍复活、存档读档形成的时间循环尚未成为设定，不因游戏便利而自动写入宇宙规则。

## 灰河谷的地方基础

灰河谷曾是彼此依赖的矿业、水利和运输辖区。镇中生活依赖荒野和设施供给，设施也依赖镇中的工匠、劳力与运输。地点先有生活和生产用途，再有玩家探索的风险与秘密。

| 地点 | 背景用途与扩充依据 |
|---|---|
| 河谷镇 | 贸易、住宿、制造和地方事务；保留可信的日常生活与人情 |
| 林地、旧猎营、矿区 | 狩猎、巡路、矿料与特殊材料来源；危险有生态或社会原因 |
| 湖区、水利设施、蓄水池 | 供水、排水与水压管理；改变水路会影响真实使用者 |
| 瞭望堡 | 道路警戒、信号和人员调度，留下名单与执行记录 |
| 档案窖 | 人员名册、图纸、补给账目与旧命令，支撑调查而非万能答案 |
| 旧监狱 | 关押、强制劳役及对矿业工程的控制；部分权力延续至今 |
| 钟墓 | 安葬、姓名与集体记忆；后曾容纳避难者 |

### 暂用历史因果

十余年前，过度开采和拖延维护促成严重的矿区、水利事故。旧监狱方面获得紧急管制与限制通行的权力，此后逐渐把应急权力变为长期控制。镇子恢复部分自治，但债务、管辖权和责任没有厘清。

旧监狱权力曾组织少数适格者接受觉醒，以维持矿井、炉场和水利设施。有些人为报酬与地位自愿参与，有些人受到债务或刑期胁迫。事故后，名单被封存，幸存者的经历被删改。近期补给事故、欠饷欠粮、维护人员与巡路者失踪、名字被涂抹，让旧事重新浮现。

这条因果是后续创作采用的背景提案，事故日期、责任人、具体证据与觉醒遗址仍需结合任务逐步落地。玩家可以通过碎片线索找到遗留的觉醒场所，不能把完整答案直接塞进第一本手册。

“火焰领主”暂作为旧监狱统治者的称号：掌握火焰技艺，受到炉场强化，控制知识、守卫与物资，并以自身不可替代为统治理由。老兵赫铎是旧命令的执行者，不是这位领主。封锁主要涉及旧监狱与工业地带，不是封死整个河谷的神秘结界；镇子仍需能与外界往来。

### 既有内容必须保留的区别

- 路卫洛恩欠粮、军需芮克的有限物资、赫铎对旧命令的服从，首先是人的处境。并非每个守卫都被附身、异化或变成亡灵；谈判也不等于让整个敌对区域自动和平。
- 巡路名册中奥伦的名字遭涂抹；钟墓线索指向失踪者收留受伤泵工，名牌“并非祭品”。新增神秘叙事不能无说明地把这条线改为献祭。
- 旧排污泵的处理解除污染；工业水轮在炉场冷却与魔力引流间可反复调节；蓄水池的最终“恢复水流／封住压力”则永久互斥，恢复水流会毁掉检修竖井，封住压力保留通道和储备。这是三处不同的水利后果，不可合并成同一个总闸事件。
- 艾妲承担书记和地方事务，萨芙经营整修，苇娘经营客栈；灰河猎队与河谷守路队是地方身份与职责，不自动升级为国家军队或神授职业。
- 稀少的施法者应从装备、准备、师承和社会地位上被辨认；普通路卫、猎人和工匠主要通过各自技艺行动。拥有材料不等于人人觉醒。

这些区别可在[灰河谷内容](../content/frontier/grayriver.json)、[人物故事](../gameplay/frontier/grayriver_stories.gd)、[档案窖场景](../content/maps/grayriver/archive.tscn)、[人物服务](../content/social/)及[地方身份](../content/social/charters/catalog.tres)中核对。旧监狱独立验证场景的全部内容不自动成为灰河谷历史。

## 后续内容的审核问题

新增内容先回答以下问题，再接入现有Resource和领域服务。说明应进入对应任务、地区或内容制作记录，无须为每个小物品另建一套文档框架。

| 内容 | 至少需要解释 |
|---|---|
| 材料、装备与配方 | 从哪里获得、由谁制作、为何有这种性质、供谁使用，如何进入真实采集和库存循环 |
| 敌人、NPC与群体 | 为什么在这里、靠什么生存、为何敌对或愿意交涉、能力与物资从何而来 |
| 法术、武技与成长 | 力量来源、适格条件、谁传授、付出什么；未觉醒者的合理路径是什么 |
| 地牢与机关 | 原来用来做什么、为何变成现在这样、谁仍关心它；空间与谜题怎样服务这个用途 |
| 任务与选择 | 谁受益、谁承担代价、留下哪些可感知后果；知识、态度和实物奖励不能互相冒充 |
| 神迹与残魂 | 谁能见证、不同人物如何解释、是否真的涉及神明或人格；不要用神秘力量抹掉已有人的因果 |

同一地点的危险、补给、人物职责与历史应互相支撑。略阴暗的色调不要求每处都是废墟，也不要求每件材料都来自痛苦。小规模的可信生活比无来源的大量怪物和宝箱更适合作为扩充基础。

## 现状差异与后续迁移顺序

本次只归档世界观，不修改运行规则、正式存档或现有数值。以下为待办，不代表已实现或已验证：

| 顺序 | 当前差异或风险 | 后续落地要求 |
|---|---|---|
| 1 | 当前开局有魔力，早期手册和火石阵路线默认可施法 | 先重排不依赖魔法的首玩与必要探索，再接入线索、考验和自愿觉醒；保留玩家学过的知识 |
| 2 | 尚无与魔力容量独立的觉醒门槛 | 在共同角色／施法规则中统一表达资格并供预览、UI、AI读取；检查属性点、装备、药剂和旧档，不能用MP数值代替资格 |
| 3 | 当前喷洒仍收取MP，日常材料动作与主动施法尚未按本设定划清 | 审核实际动作目录，分清普通工具投送和魔法强化，沿用真实来源、库存事务与共同效果执行链 |
| 4 | NPC模板、文书与既有提示可能默认法术普及 | 审核施法者比例与传承来源，明确普通人可用的器具和附魔；不会因同阵营而免费拥有知识、魔力或材料 |
| 5 | 新历史和神祇尚未作为完整内容进入游戏，个别称谓不统一 | 以习俗、地方文书、人物动机和有限任务逐步接入；统一艾妲“测绘员／书记”、巡路队称谓、档案馆／档案室／档案窖指代，保留稳定ID |

实施前需要为新旅程与已有旅程分别设计兼容策略。不能通过一次模板更新清空玩家魔力、删除知识、重置物资或覆盖既有选择；新增持久语义遵循[存档扩展](SAVE_SYSTEM.md)，校验由所属领域负责。迁移验证至少覆盖未觉醒通路、资格防绕过、普通材料操作、觉醒后施法、旧档保留与保存重进。

后续每次调整先更新本文件相应条目，注明影响的内容与兼容需求，再同步具体内容和提示。已经发生于玩家存档的世界事实不会因改写背景而自动撤销。用户新的明确决定优先于本基准。
