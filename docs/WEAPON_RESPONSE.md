# 武器操作响应与卡顿修复

2026-11-09，Godot 4.6.3，Linux 云环境。基线为 `efc30adeddec99ae4afd9bd70de778901d5a3e00`。本轮处理实际同步耗时、收招锁步和短输入丢失，不调整伤害、体力、冷却、攻击总时长、命中窗口与内容预算。

## 原因与实现

完整存档会校验新快照及已有主/备份档；生存字段校验反复调用默认食品目录。目录没有长期持有者，查询返回后其引用释放，后续又加载整组 Resource。武技查询也有同样问题。战斗中的自动保存或击杀保存因此可能占用主线程约100毫秒。

沿用既有 ItemCatalog 的做法，MartialCatalog、ProvisionCatalog、ProductionCatalog 和 TrainingCatalog 各自保留默认只读定义的强引用。没有缓存角色、库存、条件判断或验证结果。生存校验仅对三个剩余时间字段遍历对应食品上限；非有限数、非法期限、UID、容量、主/备份与原子写入检查继续执行。存档格式不变。

Godot 4.6 官方[资源文档](https://docs.godotengine.org/en/4.6/tutorials/scripting/resources.html)说明资源按引用计数管理：在内存中才共享加载结果，无使用者时自动释放。此次核对了对应版本文档，采用已有目录模式，没有增加全局加载框架或异步保存协议。

物理动作以前把出手时的移动倍率应用到整段动作，起手站定的武技连收招也完全不能移动。AttackProfile 新增 `recovery_movement_multiplier`，默认1；仅在有效阶段结束后，按后摇进度平滑恢复到该倍率。前摇/有效阶段仍使用原倍率，锁向、前踏、挥出/离弦提交、命中防重与闪避资格不变。玩家与敌人共用规则，重击副本继承该定义。

原输入缓存只有150毫秒，战杖第一击在0.55秒再次按左键时，距0.88秒动作结束还有330毫秒，输入会过期。现在攻击后摇内保留350毫秒，其余情况仍为150毫秒。只保留一个真实请求，新请求替换旧请求；复制输入方向和参数，执行时重验快捷绑定、武器及费用。到期与动作完成按本物理步内的实际先后比较。换装、控制、死亡和离区沿原取消路径清理。缺体力或绑定失效通过现有拒绝反馈显示；不自动连招、补涂层或重复执行。

HUD仅在存在待尝试输入时临时显示“攻击/武技已输入 · 收招后尝试”。等待不提前扣费，不代表后续必然成功。

## 同一脚本的耗时对比

[基准脚本](playtests/weapon-response/benchmark.gd.txt)在隔离新档中装备战杖并学习横扫。每个查询/动作采样50次；快照、校验、读档与完整保存各5次；下表为中位数，单位毫秒。完整保存会实际写盘，包含原有主/备份轮换和校验。样本小，不设依赖云端CPU速度的测试门槛。

| 操作 | 修复前 | 目录修复后 | 最终实现复测 |
|---|---:|---:|---:|
| 查询武技定义 | 0.098 | 0.001 | 0.001 |
| 武技可用性查询 | 0.106 | 0.006 | 0.006 |
| 快照结构校验 | 35.615 | 1.332 | 1.454 |
| 读取并校验已有档 | 31.560 | 1.978 | 2.099 |
| 完整保存 | 103.578 | 7.834 | 9.810 |
| 接受普通攻击 | 0.031 | 0.030 | 0.030 |
| 接受武技 | 0.442 | 0.037 | 0.039 |

原始日志：[基线](playtests/weapon-response/baseline-profile.log)、[只修目录](playtests/weapon-response/catalog-profile.log)、[最终复测](playtests/weapon-response/final-profile.log)。同步保存仍存在；这证明当前快照的热点减少，不能保证任意大型后期存档或其他设备都无帧尖峰。

## 真实输入与覆盖范围

`weapon_response`覆盖330毫秒提前输入、350毫秒边界、大步长过期、单次请求、参数快照、换装取消、绑定失效、缺体力反馈、后摇移动、严格存档校验及保存UID。

`weapon_response_input`使用实际Godot鼠标/键盘事件。原生Xorg图形运行、兼容渲染，正常AI和世界时钟；装备、武技知识与安全测试位置由fixture提供，继承fixture关闭HP/MP自然恢复以观测消费，不提供无限体力或免费冷却。敌人未在此次受控位置交战，因此不作为自然开荒、战斗平衡或完整关卡验收。

- 闲置时左键在下一物理帧开始第一击；收招再次手动左键，第二击间隔约0.867秒。原配置总时长0.88秒，差异在一物理步采样范围内；没有额外空等或第三次自动攻击。
- E独立触发横扫，前摇持D仍站定，收招中段速度约176，完整步速330。三次攻击分别按真实配置消耗15、20、30体力，MP保持60。
