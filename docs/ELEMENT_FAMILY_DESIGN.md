# 基础元素与形态：水系合并修订

2026-11-05。根据最新方向，将水与霜合并为同一个基础元素，优先增加单个元素内部的用途和取舍。当前基础元素为火、水、雷、毒四类；凝霜是水系形态，蒸汽是水的变化状态，均不再作为独立基础元素规划。

## 一个水系，多个用途

| 水系变化 | 已有用途 | 取舍 |
|---|---|---|
| 液态 | 铺水、清洗、连接环境 | 适合自救或布场；清洁水才能洗毒 |
| 凝霜 | 减速、冻结、改变导电通路 | 保留控制，或用冲击破冰兑现、恢复水路 |
| 蒸汽 | 短暂减免投射物直接伤害 | 同时减速；需要火与水作用，不防御近战、范围或DOT |
| 与雷交互 | 导电水域、传播危险 | 依赖连接与站位，也可能伤到自己 |
| 与毒交互 | 污染、拒止、预备引燃 | 失去清洁用途，选择持续消耗或提前兑现 |

液态、凝霜、蒸汽属于同一元素的不同使用方式；导电与污染继续是水与其他元素的交叉。这样可以围绕同一水系搭配清洗、控制、防御、环境布置与条件兑现，不需要把每种用途拆成一门独立元素。

例如玩家可以先铺水，选择凝冰保留减速；也可破冰恢复水路，再接雷电；受到远程压力时，用火与水创造蒸汽。每一步改变原有用途，也会失去另一种机会。

## 本轮已实现

- 元素目录公开四类基础元素；原ice定义保留为父元素water下的凝霜形态，提供归属查询和去重后的元素亲和查询。
- 同时带有water、ice标签的效果只显示一份水系归属；预览中的凝霜效果显示“水·凝霜”。
- J元素关系页将凝霜规律放在水系下面。旧存档的ice基础线索迁移到water，已有动作、法术组合、装备和已验证反应保持原ID。
- 材料、霜行、霜阵与原有命中效果继续使用具体形态条件。液态水负责潮湿与清洗，凝霜负责冻结；普通水引不会因共同归属而自动冻结或消费霜行。
- 未新增技能、装备、材料或元素反应条目；现有数值、16条地面反应及操作路线保持兼容。

归属与形态分开读取：ElementCatalog.all_definitions提供基础元素，all_aspects提供形态；family_id/family_definition和family_ids供配置归类与预览使用；definition保留精确的形态定义及其命中状态。旧is_element查询继续认可合法的ice标签，is_core_element区分基础元素与形态。

不要将所有ice命中标签直接替换为water。两者归属相同，但“施加冻结”与“施加潮湿/清洗”仍是不同操作。形态专用Buff和材料可以保留自己的适配条件；今后需要水系通用能力时，应明确使用元素归属查询。

## 后续内容原则

围绕水系内部的形态与操作发展配置：控制型选择保留冰面和减速，兑现型选择破冰或融化，防御型使用蒸汽，布场型连接水路并接入雷或毒。它们是同一体系里的选择，可以跨搭配，不作为职业硬锁。

新增法术先判断现有送达方式或形态能否表达；新增Buff和装备优先改变保留/消费、覆盖、位置或转换条件。不因需要更多条目而把凝霜、蒸汽或导电水另立为基础元素。

本轮没有增加自由物态切换按钮、温度模拟、独立的蒸汽施法或新的专精树。后续若增加这些能力，仍需明确来源、成本与失去的机会。
