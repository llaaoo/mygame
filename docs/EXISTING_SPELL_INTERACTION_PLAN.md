2026-11-05，按用户校准收拢重点。上一轮把新增魂术放得过重；当前优先深化已有动作的关系和操作空间。保留上一轮已接通的工作，本轮技能、主动组合、材料和装备条目保持11/19/7/4，不再追加技能按钮、素材货币或装备名称。

## 设计标准

评价一次迭代，先看玩家能否用已有工具做出新决策：同一个动作有战斗、环境、准备、资源兑现等用途；条件组合改变使用方法或时机，存在代价、风险和反制；学会一条性质后能在别处推导复用。已有动作无法表达新的决策时，才考虑增加基础技能。

| 现有工具 | 组合和用途 | 玩家取舍 |
|---|---|---|
| 火花 | 阵内改变为远程/元素结果；阵外也能点油、融冰、蒸发、引爆中毒 | 省去布阵投入，承担近身风险；远程与范围仍依赖准备 |
| 水引 | 定点铺水、脚下洗去燃烧/中毒、铺设导电通路、为冻结准备条件 | 无直接伤害；水路也会把雷电危险带到自己身边 |
| 震荡 | 对已冻结目标碎冰，或打碎冻结地面恢复水路；不同阵内仍按各自元素转化 | 额外50%伤害，失去剩余冻结控制；基础覆盖范围较小 |
| 凝神 | 不同法阵赋予不同恩赐；普通施法保留，Shift主动兑现 | 增强这次法术后失去持续收益，不应总是按住强化键 |
| 泼洒树脂 | 把油放在需要的位置，火花/火焰近战即可点燃；树脂也能强化已有火球 | 铺场与强化共用同一库存；脚下铺油同样危险 |
| 毒雾/毒性材料 | 留人、区域拒止；毒性冰霜先控制并附毒，后续火花可融冰并引爆 | 火焰兑现会移除准备状态，水也会洗去中毒和毒区 |
| 回响 | 已有动作转化为多次效果；回响脉冲可在第一跳兑现冻结 | 消费印记/材料；冻结被打碎后，后续脉冲不能再次吃同一份收益 |
| 火/霜/雷法阵 | 站位选择单圈或叠圈、不同结果与总投入，配合工具制造环境 | 准备时间、范围、次数、总法力；不能把叠圈视为无代价升级 |

## 本轮落地

### 材料、Buff、环境与装备共用一条变化链

继续深化同一个水引：霜盐造冰、雷晶粉导电、毒性萃取污染；材料按性质和送达类型适配，地面通过有序载荷沿已有规则变化。守阵者指环支持Shift借阵，先发生材料变化，再接受一个可反应法阵的作用，保留落点并统一结算材料、充能、Buff与法力。毒水借火阵得到燃烧地面，冰水借火阵恢复水面；不添加对应的独立技能。规则、取舍和技术边界见[涌现施法设计](./EMERGENT_CASTING_DESIGN.md)。

### 性质跟随效果，不依赖某个技能名字

玩家的火焰、冰霜、雷电、暗影与冲击命中按标签复用共享的命中反应。保留原有技能专属配置，按反应ID去重：火球已配融化时，不因共享规则再结算一次。火焰近战直接带元素性质，不再复制火球的反应清单。

这补齐了基础火花、材料变体、范围结果与附魔攻击之间的割裂。现有的凝冻、融化、蒸发、导电、雷息共鸣、毒焰、蒸汽、腐影关系继续复用；震荡与回响脉冲新增“碎冰”这一命中关系，不增加主动法术组合条目。

每次命中读取附加状态前的快照：本次刚附加的中毒不会被本次自己引爆，下一次火花才可兑现。一个动作有多个效果时，后命中的效果仍可利用前一个效果创造的条件，因此火/霜叠圈会按实际命中先后出现蒸汽或融化。反应触发有浮动文字反馈。

同样两个元素，顺序也产生不同取舍：先火后冰，冰霜获得50%蒸汽额外伤害并留下冻结；先冰后火，火焰获得60%融化额外伤害，但失去冻结控制并留下燃烧。收益随兑现这次命中的伤害计算，不是固定附加数值。

反应冷却按目标区分，一次范围攻击可以分别引爆多个中毒敌人，不因第一个敌人触发就吞掉其他敌人的反应。DOT不重触发直接命中反应。

### 水路形成可操作的连锁

水引铺水 → 冰霜冻结水路/敌人 → 震荡碎冰并恢复水路 → 雷电沿连通水面传播。也可保留冻结控制，等更安全的输出时机。水路仍会被干燥空隙截断，破冰没有取消传播上限和敌我风险。

火花落点所在的格子必定参与表面交互，避免细小火花在格子边缘因没有覆盖格心而无法点燃脚边的油。

### 落点是操作的一部分

水引、树脂、毒雾可以用鼠标选择120范围内的落点，包括脚下。瞄准环显示真实作用半径，按效果颜色区分，准备期间保留已锁定的位置；释放请求记录位置，准备过程中不重新采样鼠标。显式请求同样限制距离。旧的“方向施法”便捷接口保留原固定前方行为。

水引放在脚下复用湿地原有的灭火/冲毒规则，无需新学一个专用自救技能；把油或毒放在脚下则仍可能伤到自己。回响等条件将动作转为Buff时，沿用对应的自作用效果。

已有手记、材料手册、火阵与霜阵记录、技能说明和探索日志补充这些实验线索，没有新增领一次奖励的知识条目。

## 后续优先级

先用试玩检查工具之间能否互相准备、改变位置和环境、兑现/保留Buff，再调整成本和反馈。材料与装备优先改变已有操作的覆盖、持续、速度或用途，并保留明显代价。暂不以新增魂术分支、更多新名字或只提高伤害作为迭代目标。
