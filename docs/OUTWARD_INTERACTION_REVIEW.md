# Outward 参考复盘：先连接已有机制

> 2026-11-04。用户校准：扩充要产生联动、用途变化和发现感，不能把技能/材料数量当作主要成果。本轮沿用已有15条配方、7种材料和6处机关，调整它们之间的关系。

## 参考了什么

本轮核对了两份可访问的公开社区技能数据：

- [OutwardBuilder / data/skills.json](https://github.com/Kalbintion/OutwardBuilder/blob/master/data/skills.json)
- [OutwardCalculator / data/skillTrees.json](https://github.com/JaneTransRights/OutwardCalculator/blob/main/data/skillTrees.json)

它们是社区资料，并非官方当前版本平衡表。下列参考采用双方能核对的技能用途，Flamethrower的工具损耗描述来自第一份数据；不据此照搬数值，也没有把本项目的全部设计说成原作现成规则。

| Outward 资料中的具体行为 | 应借鉴的关系 | 当前项目此前的缺口 |
|---|---|---|
| Spark既是弱小火焰动作，也能点燃营火，并与其他法术组合 | 基础动作同时参与战斗、探索与准备 | 元素虽然存在，部分用途仍被锁在“法术命中”通路 |
| 火、风、冰Sigil声明其他技能在圈内获得额外效果 | 空间准备改变同一动作；位置是操作的一部分 | 所有法阵互相替换，结果全局择一 |
| Reveal Soul把尸体附近的灵魂变为施法上下文；Conjure本身依赖其他能力 | 世界里已有的东西也应成为施法条件 | 主要条件都是玩家自己按键生成，世界条件较浅 |
| Infuse Fire消费Warm恩赐，使近战获得火焰伤害与燃烧 | 把准备转换为另一类操作的能力，存在用途取舍 | 余烬战意只加近战数值，没有接通元素反应 |
| Flamethrower要求火把/提灯，并损耗所用工具耐久 | 同一件资源在照明、探索和战斗间分配 | 材料容易沦为某法术专属加成按钮 |

火阵＋Spark的原作关系也沿用用户已明确指出的参考。多圈并发的具体费用、上限、互斥处理和回响规则是本项目本轮的实现选择。

## Buff关系的进一步校准

同一份公开技能数据还明确描述了：Focus提供Discipline；Perfect Strike以Discipline为条件；Moon Swipe因Rage/Discipline增强；Flash Onslaught消费Discipline，Feral Strikes消费Rage。这说明Buff同时承担持续收益、技能资格、增强条件和主动消耗资源，不能仅当一次性的配方标记。

当前继续复用现有恩赐：普通施法保留增益，Shift施法主动消费适配恩赐强化本次形态；共鸣护盾也改成Shift＋震荡才引爆。Shift是本项目选择，不是原作按键复刻。具体取舍、材料联动与提交规则见 [Buff依赖与兑现](./BUFF_CASTING_DESIGN.md)。

## 本轮实际调整

### 1. 法阵从替换关系变成空间组合

探索入口中，火、霜、雷不同法阵可并存，每类最多一个；重建只更新同类。位于多个圈覆盖处时，一个动作触发各圈的适配配方，相容的回响准备也一起响应。

例如错位布置火阵与雷阵，在交叠处使用火花，得到火球和雷矢，总计23 MP，各阵用一次触发量，不另外加基础火花费。向外走到仅被火阵覆盖的位置，则自然变回单火球12 MP；不需要新增技能或模式菜单。

投射物保留各自速度，因此实际命中先后决定目标状态的反应。范围结果以各自法阵为中心。既有配方仍决定具体结果，本轮没有宣称支持任意拼接。

同一作用域内的互斥规则仍存在：守护爆破优先于回响脉冲；多个互斥增益只保留优先级最高者，同级取后布的阵。只对最终保留的结果收费，不为立即被覆盖的Buff扣费。

### 2. 余烬战意把近战变成元素工具

现有火阵＋凝神仍赋予余烬战意和原来的攻击加成，同时赋予近战fire标签。此后普通挥击能够：

- 让敌人燃烧，融化冻结，或引爆中毒；
- 点燃命中位置的油面、以火焰破坏油桶；
- 打开原本接受火元素的荆棘药箱。

这些用途读同一个元素规则，不为“火剑开药箱”再写一条法术或机关答案。挥击期间不重新扣法术材料；增益结束、被替换或跨区清理时失去元素性质。

这里借鉴Infuse Fire的“准备转为近战用途”，并未实现或声称复刻原作Warm恩赐的独立获取/消费流程。

### 3. 导电读水域拓扑

雷电接触水面后，沿四邻接的连续水格扩散，能够绕过水路拐角，干燥空隙会截断传播。一轮最多处理48格，伤害仍由既有感电状态与模拟tick产生。

水引于是同时成为灭火/解毒工具、冰霜准备、雷电导体。布水形状、敌我站位和干燥隔离会改变战术。玩家也受带电地面影响，铺更多水有收益和风险。

### 4. 材料按用途分配

沿用已有材料：树脂可作为铺油的必需消耗，也可改变火球命中后的地面；墨可以用于先做回响准备，也可以强化已产生的三重矢。多结果动作只对适配结果消费可选素材，基础动作的必需媒介只收一次。总费用在技能栏和M配置页可见。

## 为联动补齐的执行语义

组合不是循环“施法几次然后希望不出错”。释放前锁定完整结果、位置条件、各圈版本、状态版本和总成本；任一条件消失或资源不足时取消整次，不偷发低价子集。

每个执行器先准备离树的投射物/AoE和待应用Buff。全部接受后才激活效果、发送施法事件和结算技能使用；后一个结果被拒绝时清理前面暂存的实例，并恢复法力、材料、各圈次数和准备状态。

同一动作的效果共享来源编号，真实生命组件能完整接收多个结果，Body/Hurtbox仍按各效果去重。其他独立动作保留受击无敌约束，不会因为联动而取消防护窗口。

旧main场景保留单圈原型规则，探索MVP启用并存。旧回归中用于单配方验证的场景显式清理其他圈，新联动测试专门覆盖并存语义。

## 后续验收方式

优先看以下试玩问题，而不是统计又加了多少名字：

1. 玩家能否用站位自然选择单圈/叠圈、低成本/高投入？
2. 能否从“火焰近战点燃油面”推想到油桶、冻结目标和荆棘也适用？
3. 能否利用水路拐角控制敌人，同时避免把自己留在导电区域？
4. 已学知识能否在别处复用，而非每个机关都重新收集一份专用答案？
5. 新材料是否改变准备、形态或用途，并与已有用途争用资源？

尸体/灵魂与工具耐久的世界条件值得下一步做小型样板；本轮先落实上述关系，没有顺手增加整套新职业、装备或资源类型。人工画面、手感、整章难度和资源平衡仍需试玩。

自动验证见 `tests/test_joint_interactions.gd`：并存/同类更新、总费不足、离开部分圈、准备中失效、第二个效果拒绝后的完整回滚、共同命中真实生命、互斥增益选费、真实近战元素反应与既有机关复用、连通导电/干地隔离/有界传播。完整验证入口见 [MVP实现说明](./MVP_RELEASE.md)。
