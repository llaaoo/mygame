# 用已有法术构成可推导的变化

> 七批开发已实施，当前玩法与验收见[元素构筑试玩交付说明](./FIVE_ELEMENT_IMPLEMENTATION.md)。下文保留设计形成过程，标为候选的旧段落应对照交付说明判断实现状态。

2026-11-05。本轮继续收拢到基础能力之间的关系：基础动作、法术组合规则、材料和章节装备仍为11/19/7/4。新增的是通用的介质变换接口，没有增加主动法术、材料货币或装备条目。

## 设计目标

玩家发现一个性质后，可以在其他场景推导用途。水是可铺设的介质，冰、雷、毒、火作用于介质；投射物与范围是送达方式；材料改变性质，Buff改变形态与投入，装备改变可使用的条件。惊喜来自这些规则先后发生，而每种新用途不必都配一条专属法术。

一次扩展应同时回答：现有工具获得什么用途、什么条件下值得使用、失去什么、怎样被环境或敌人改变。如果只是增加一个名字或伤害倍率，优先回到现有关系上调整。

当前是围绕地面介质的可玩样例。它尚不包含流体、水位、温度、质量、任意材料混合或装备自由插槽，也不假设所有标签都有两两反应。

## 基础元素与扩展基线

> 最新修订：水与霜合并为水系，基础元素为火、水、雷、毒。具体归属、旧标识兼容与已实现范围见[元素与形态修订](./ELEMENT_FAMILY_DESIGN.md)。

用户进一步明确：先锚定基础元素，在其上扩展法术、Buff、装备，再通过相互组合形成多样玩法与配置。本节为2026-11-05的后续设计基线；标为候选的内容尚未实现，当前可玩范围仍以下面的试玩表和代码为准。

### 先深化火、水、雷、毒，水系包含凝霜

以四类基础元素作为当前核心，凝霜作为水系形态。这里的“元素”是玩家可理解、可复用的魔法性质，不追求现实物质分类，也不建立四类相互克制的固定环。

| 元素 | 核心职责 | 已有世界关系 | 玩家长期面对的选择 |
|---|---|---|---|
| 火 | 点燃、持续压力、兑现准备 | 引燃油与毒地；把水变蒸汽，把冰面融回水 | 立即兑现，还是保留冻结/中毒条件；地面火也有站位风险 |
| 水（含凝霜、蒸汽变化） | 铺设、清洗、冻结控制、短暂庇护 | 清洁水洗去燃烧/中毒；凝霜改变水路，蒸汽提供防御；可导电、受污染 | 保留液态用途或凝霜控制，还是破冰/融化/与其他元素交互 |
| 雷 | 利用连接传导、集中兑现 | 沿连通湿地传播，干地截断；命中潮湿目标获益 | 延伸导电路径，还是切断路径保护自己 |
| 毒 | 污染、延迟压力、预备点火 | 水被污染；毒地可点燃或冲洗；中毒可被火兑现 | 让毒持续生效，还是提前引爆；也可能被清洗掉 |

水与霜归入同一水系，以液态、凝霜和蒸汽表达不同用途，不为此新增温度模拟。毒作为污染性质与其他元素交叉，不只是换一种颜色的持续伤害。表中角色状态和地面状态分别结算，例如“火命中冻结角色”和“火融化冰面”可以有不同收益与持续时间。

已有暗影及腐影关系保留，暂不继续扩展为完整主元素体系；之后是否提升为核心元素，要看它能否提供当前四类表达不了的操作。蕴魂是可消费准备资源，回响是结果组织方式，法阵是空间条件，冲击是作用方式；它们可以与元素相交，不因有一个标签就都另设为基础元素。现有资源ID、解锁与存档不因本次设计分类调整而迁移或删改。

### 元素定义性质，各系统决定怎样使用

| 维度 | 决定什么 | 扩展约束 |
|---|---|---|
| 元素 | 施加哪种性质，能与哪些状态反应 | 同一性质跨法术、材料和附魔复用；没有规则时不凭标签自动产生效果 |
| 法术/动作 | 如何送达：近距施加、投射、铺地、范围冲击、自身准备等 | 复用执行行为；不要求每个元素都配齐所有形态，重要术式仍需探索学习 |
| 施法者Buff | 持续收益、施法资格、增强条件或可消费投入 | 明确属于哪种关系；有实际收益才消费，不把所有Buff都当自动燃料 |
| 目标状态 | 已有的潮湿、冻结、中毒等准备 | 实际命中时判断，是否消费必须明确；不能把本次新挂状态当作旧准备 |
| 材料 | 添性质、造介质、改形态或承担必要媒介 | 与生存制造共用库存；可选材料不成为所有基础动作的必需品 |
| 装备 | 改变条件的使用方式、作用位置、保留或兑现方式 | 每件表达明确关系与代价；优先改变操作，再考虑数值加成 |
| 环境 | 提供真实介质、连接、障碍和风险 | 同类表面遵守同类规则；不保证机关、角色和装饰都支持全部性质 |

目标关系是“一个元素能被多种工具使用，一种工具能因不同条件改变用途”。这不等于“任意元素＋任意形式都能自由合成”：当前仍有已学术式、可支持的行为、相容条件和资源边界。

### 法术、Buff与装备围绕关系扩展

法术先审查现有动作缺少哪一种操作，再决定是否新增。更换元素颜色或提高伤害不足以构成新增动作的理由。例如近距施加与远距投射可以保留不同的准备成本，不能为了组合数量让火球绕过法阵条件。更多结果可以由材料和条件生成，仍属于同一个已装备动作。

Buff继续区分四种关系：自身提供持续收益、决定某术式资格、存在时增强效果、主动消费换取另一种收益。现有余烬战意、霜行、雷息和护佑优先沿此深化；水和毒不需要为了四类对称立刻新增同名恩赐。现有例子是霜盐使水引具有冰霜性质，霜行因此能被消费来扩大冰面；只提供伤害收益的恩赐不应被零伤害工具白白消耗。

装备已有“借用一个可反应法阵”这一关系。后续候选优先考虑改变条件，例如让范围变小但能在远端使用条件、以较弱的本次效果保留部分准备、或在特定介质上改变布阵方式。这些均为候选，尚无对应新装备；每次只验证一种操作变化，并明确作用域、触发上限与资源去向，避免返还条件后形成免费循环。不能给每个元素简单复制一套增伤装备就算完成构筑。

同一元素也应支持多种玩法，而不锁成固定职业。例如水系凝霜可以控制后保留冻结，也可以用冲击碎冰兑现，还可以消费霜行扩大控场、承担失去移速的代价；雷可以直接命中潮湿目标，也可以借材料铺设危险水路。水系的不同形态与火、雷、毒的交叉应能解决单一用法不擅长的问题，同时仍可选择专精一种元素。

### 探索奖励围绕规律展开

先让玩家看到性质，再发现控制方法，随后获得改变条件的工具，并安排在旧场景回用。例如先学会用水灭火，再发现水能结冰和导电，之后用已获得的材料、恩赐或守阵者指环改变水引用途。环境常识一旦支持就一致生效，不通过隐藏解锁禁止水导电；需要训练的主动术式仍独立学习。

奖励可以是一条可验证规律、一个新的送达方式、一种可加工材料、一件改变条件的装备，或改变介质分布的世界选择。每项奖励都应至少安排一次安全试验和一次有压力的运用，不能只给长说明或战力数字。

### 实施顺序与验收

1. **元素语义与反应审计**：列清四类元素及其形态在命中、角色状态、地面和物体上的已支持行为与缺口；共用元素标识，保留不同作用域规则。优先澄清不一致处，不盲目补齐所有两两反应。
2. **深化现有关系**：围绕保留/消费、冻结/破冰、铺路/断路、清洗/污染，用已有动作验证选择。当前水引链是首个样例，不代表其他元素都已经具有同等深度。
3. **Buff与装备补足操作缺口**：只添加能改变时机、条件位置、介质或资源兑现的关系；先制作少量能互相交叉的选择，再考虑新条目数量。
4. **扩展探索场景和敌人反馈**：为同一规律提供不同应用，例如安全水路与危险水路、留住敌人与破冰换伤害；具体可改变的地形和敌人反应按场景逐个实现，不提前承诺全场景支持。
5. **有明确缺口再加元素**：候选元素应带来独有操作或介质关系，并能解释它怎样接入已有工具；风、土、生命或暗影不预先承诺全部扩展。

每次迭代至少展示一项新的有代价决策、两处复用同一规律的场景，以及普通施法仍值得保留的原因。测试同时覆盖结果、条件消费、失效原因、敌我风险、传播上限和准备失败回滚；玩法多样性仍需试玩比较，不能用排列组合数量或自动化测试通过代替。

当前代码已有共享命中反应、地面反应、有序介质载荷、材料性质适配、恩赐修正和借阵事务，可承载这一方向。已接通统一元素/地面定义与能力审计，并通过父元素归属将凝霜纳入水系；现有结算模块继续读取精确形态，不另建平行伤害或状态系统。当前实现与后续候选分别见交付说明和元素形态修订。

## 可以直接试玩的组合

营地读材料手册，在M给水引选择一种材料；O查看守阵者指环来源，在营地换装。水引仍使用原快捷槽，可指定120范围内的落点。

| 已有工具与条件 | 结果与用途 | 投入和取舍 |
|---|---|---|
| 水引，不配材料 | 铺水、自救冲洗、延伸导电通路 | 5 MP；无直接伤害 |
| 水引＋霜盐 | 水域→冰面；扩大冰面覆盖 | 1霜盐，额外2 MP，范围+30；不再留下普通水面 |
| 水引＋雷晶粉 | 水域→导电水域；连接已有湿地传播危险 | 1雷晶粉，额外4 MP；玩家同样会感电 |
| 水引＋毒性萃取 | 水域→毒地；拒止或预备点火 | 1萃取，额外3 MP；污染水不再洗毒 |
| 上述冰水＋霜行，Shift施法 | 用同一动作铺更大冰面 | 霜行再扩大36，额外3 MP，失去剩余移速增益 |
| 守阵者指环＋火阵内Shift水引 | 水域→蒸汽 | 1次法阵充能，额外2 MP；普通施法仍铺水 |
| 同样条件＋毒性萃取 | 水域→毒地→燃烧地面 | 材料、充能和额外法力共同投入；地面危险不区分敌我 |
| 同样条件＋霜盐 | 水域→冰面→水域 | 火能化去刚凝成的冰；这次不再保留冰面控制 |
| 冰面＋阵外震荡，再接雷击 | 破冰恢复水路，雷电再沿水路传播 | 也可以保留冻结；干地仍会截断传播 |

表中法力是装备修正前的额外成本。指环保留原本全法术费用+15%、布阵范围+24和寿命+6秒；所有成本相加后统一修正并取整。普通零伤害水引仍无直接伤害，材料和灌注没有凭空赋予直接伤害。危险地面通过原有状态路径生效。

借阵只处理地面介质，不把该元素加入命中标签。例如毒水借火阵形成燃烧地面，命中仍是水/毒性质，不会同时获得一次免费的火焰命中和毒焰引爆。材料本身提供的标签仍参与命中和恩赐适配；命中前状态快照继续防止自己刚附毒就自引爆。

## 一条计划与执行链

1. 根据动作、已学规则、法阵和施法者状态确定本次结果，保留已有互斥组与优先级。魂术/回响等若把水引变为自身增益，就先执行这些已有结果；预览据此显示。
2. 应用选中的适配材料。保留原有ID适配，同时支持“性质标签＋送达类型”，无需为每个新的水系投射物复制材料名单。
3. 处理已有恩赐。普通施法保留适配恩赐；Shift才请求消费。零伤害工具需要实际获得范围、穿透、散射或介质变化，才消费恩赐，避免为无效伤害倍率付费。
4. 装备允许且按住Shift时，造地结果尝试借阵。先投影材料/恩赐作用后的地面状态，再从新到旧找自己的可用法阵，只选择一个能改变该状态的法阵。无反应不加价、不扣充能；已有组合已经借阵的结果不重复借阵。
5. 将法力、材料、恩赐与法阵充能合并进现有施法事务。准备期间条件改变则取消；任何效果拒绝执行，全数回滚。借阵保留原落点，不把水域移动到阵中心。
6. 执行时先铺设整个基础介质区域，再按顺序应用载荷标签。范围与投射物命中共用这条地面路径。预览的状态链读取同一份反应表，不另外维护组合答案表。

例如“水引＋毒性萃取＋火阵借能”只描述`wet → poison → fire`，由已有的`wet+poison=poisoned`、`poisoned+fire=burning`自然得出结果；没有增加“毒火水引”技能资源。

## 边界与反馈

- 地面按现有64像素格子模拟，直接覆盖范围必定生效；一轮范围作用共用导电访问预算48，避免每个格子独立传播48次。既有256活跃地面格上限保留。
- 反应持续时间沿用对应地面规则。冰、雷、蒸汽并不自动继承12秒水域寿命；状态仍按原系统处理。
- 预览显示介质状态链、最终作用范围/颜色、总法力、材料、恩赐与借阵充能。地面颜色与瞄准颜色共用定义；M配置、材料手册、既有毒理/导电手记和J日志给出线索。
- 同槽换装、施法材料改变、离开法阵、充能或Buff版本变化，都使已接受的准备重新校验；不会降级成另一种效果后照样扣费。
- 制造配方仍只负责原料转库存材料。运行时介质反应属于法术/世界规则，不混入制造配方或增加新的持久化法术身份。

## 后续迭代标准

下一轮优先观察冰面控制与破冰、电路截断、普通水与污染水、保留恩赐与消费恩赐之间是否形成真实选择，再调成本、持续时间和敌人行为。装备可逐步改变介质保留、条件位置或兑现方式，每次只增加能和已有性质相交的一条规则。

持续追踪同一动作解决多少种问题、一个属性能复用到多少个场景、组合是否总是严格更强，以及失败是否能被玩家解释。新增基础能力应填补这些关系无法表达的操作，而不以技能条目数作为进度指标。
