# 世界观 v0.2：普通旅人与可选觉醒的落地

2026-11-11。设定基准见[世界观](WORLDVIEW.md)。本文描述当前实现契约，不把基准背景和待填内容写成新增玩法。恢复后的验证结果须另行记录；旧云端临时证据在环境中断后丢失，不作为可下载附件或本工作树的验收证明。

## 无魔力的新旅程

灰河谷新档的玩家适格但尚未觉醒，当前MP与法力上限均为0。属性、装备、Perk、药剂、知识、残魂、法阵或读档不能绕过资格。书本仍授予原有知识，不删除旧档已知动作、材料与快捷栏。旧监狱验证场保留独立模式。

离镇口粮旧械包沿用`river.pack`的同一领取收据，增加真实驿路短刀1，并移除原晶砂3、树液3；食物、水与炭屑仍用原库存边界领取。短刀是`river_sabre`装备，不是剥取工具`field_knife`；新玩家按O穿戴到主手，空主手时引导再次提醒。旧领取者不补发。附近一次性布料包仍为原来源，留布料1可手工修复压印台，不额外赠送材料。

手册与北路记录先指导武器、涂附、喷剂、投瓶和手工检修。首次出征仍要求`river.fire`、`archive.index_press`、`river.dossier`，回镇报告得原1属性点；不要求觉醒或施法。武器课程保留真实金币与知识条件，不强制法师买课，也不凭教程赠知识。默认键位仍读取菜单映射；界面不暂停世界。

## 可选的试感与觉醒

档案窖在`(-780,-520)`放置旧试感台，Resource为`content/awakening/archive.tres`，空间由MapFeature节点持有。需要`archive.index_press`与`river.dossier`；没有新建平行任务进度或资格表。

1. 固定6秒试感成功，仅记录`awakening.archive.trial`，不觉醒、不扣永久属性。可离开继续普通旅程。
2. 再次调查显示明确长期条款；自愿开始固定4秒接受，完成前可取消，移动、受伤、敌人靠近或条件失效会中断。
3. 当前代价为生命上限10、体力上限10，智力10时开启基础60MP容量。接受不立即补满当前MP；本版无重修。只结算一次，重复调查不再支付。

场所与方法定义只读；`AwakeningService`接入既有现场作业与世界claim。唯一资格与实际永久代价归`ActorMagicState`，由角色上下文与ManaComponent引用同一实例；claim、当前MP和已知法术都不能替代它。派生上限继续由共同属性/成长投影读取。作业界面显示概要，展开可滚动阅读完整条款。

## 普通物品与主动魔法

普通喷洒准备0.25秒，随后每0.5秒从选定UID消费一剂，**0MP**，前方120距离、60度锥形；松开即停，不能偷偷换瓶。普通喷洒不借法术恩赐、脚下法阵、熟练度或智能跟随元素施加额外强化，不发布伪施法事实。显式选择的魔法强化仍需觉醒及其实际额外费用，失败不静默回退普通形式。

涂附和投瓶仍使用真实物品；药剂、装备与材料不因人物未觉醒而失去用途。主动法术即使被修正为0MP也需要资格。已觉醒者的无材料基础法术可以存在，但缺料不自动换源。具体物品、UID、事务与中断边界以[物品动作与真实来源](ITEM_ACTIONS_AND_REACTIONS.md)为准；该专题中的v6和旧MP记录属于历史实现，不能据此恢复普通喷洒的魔法费用。

## 保存与兼容

`magic`记录包含`schema`、`awakened`、`aptitude`、`hp_cost`、`stamina_cost`、`mana_base`、`source_id`、`legacy_exempt`。**对象存在就严格校验所有核心字段**，不把空字典、缺字段、矛盾代价或未来版本当作无魔力默认值。只有整个旧记录缺失`magic`时允许旧原型兼容；新格式进度有`magic_schema`，区分空的新旅程与旧档。未来`magic.schema`返回不支持状态并保护原文件。完整存档契约见[存档扩展](SAVE_SYSTEM.md)，不能用SaveRecord的普通可选字段默认值放宽这一资格记录。

恢复旧角色容器与知识，不以新模板覆盖已存在物资；涂层到期和药剂余量继续使用原UID与游戏时钟。觉醒资格、永久代价和基础容量持久，正在作业、准备来源、法阵与瞄准等瞬态不跨读档恢复。休息小时与日程继续联动，不靠数秒准备凑出一天。

## 地方人物、水路与信仰

普通守卫、猎人、弓手与镇中服务人物不默认施法，移除凝神知识时同步清理旧loadout；兽类不适格。少量刻阵术士与水工术士保留传承、实际技能和有限资源。已有存档角色从自己的记录恢复，不重新用模板清洗知识。

三处水利因果保持独立：工区排污泵改善湿地原水源并提供泵芯；矿道调压器与泵芯用于镇中调和台；沉水泵站总闸的恢复供水/封存压力是另一处世界选择。导流触点的手工办法消耗金属碎料2、晶砂1、站定6秒，沿用原分流阀前置，不自动完成其他水路。

神祇真实存在，地方习俗只少量写入客栈门灯、作坊匠训与为亡者留名；这不是新增神赐服务。信仰、适格、觉醒与神赐独立。苔石祈坛的状态名“恩赐”不证明神迹，残魂术法余能不等于完整死者人格，普通制造不凭空抽取灵魂。
