# NPC交谈、关系与服务

2026-11-10（上海）。本轮把交互接到真实角色、世界时钟、个人关系和库存上，首批落地萨芙、河谷训练师与艾妲三位镇民。沿用灰河谷地图、战斗和任务规则，新增21个话题与3份有限人情委托。

## 玩家流程

靠近人物按F交谈，鼠标选择话题；话题和详情独立滚动，支持搜索与小窗口。闲谈、能力见解、服务、人情委托和成果回应共用一个入口。已谈过的内容会标记，重要信息写入J的见闻记录。对话不中断世界模拟，玩家仍可能受伤。离开界面后人物继续原日程；有效交谈时人物停步面向玩家，时钟与当值条件照常推进。

- **萨芙**在整修铺柜台旁：可谈物资来源，交易、整修、店内排产，接受一次2木炭换8币的委托。个人信任达到10后，购买价按基础买价九折向上取整，且始终高于卖价；出售原价。柜台保留便捷交易入口，每次仍检查店主本人存活、关系、当值、距离与安全。
- **河谷训练师**：讨论体力、武技和法阵准备，进入原有付费课程或P成长页。1烤饼换3币的人情委托使用训练师实有货币；他起初没有报酬资金，玩家购买课程后，学费进入其行囊，才可能兑现这份委托。完成断桥交涉可谈及实际成果、获得一次认可。
- **艾妲**在委托板东南：提供路线与档案线索、进入河谷委托页，接受一次2草药换6币的委托。熟悉后愿意谈更远的档案消息；修复木桥可获得一次认可。原公共委托板与正式河谷委托的报告规则继续保留，人情委托单独要求当面交付。

人物的21个话题包括3条要求力量或智力12的能力见解。交谈检查**有效属性**，临时增益到期后会再次拒绝不满足条件的请求；与永久Perk要求基础属性的规则不同。听到路线、档案位置或作战建议不会获得技能、配方、探索完成或地图发现；必须继续亲自调查。

## 关系与记忆

`RelationService`继续独占态度和派系关系，新增有向个人信任（−100至100）。初识、熟悉（10）、信任（25）只是分数显示；信任不覆盖实际敌对态度。人情交付加10；登记了真实世界成果的回应话题首次交谈加10。重复聊天、重复出示同一成果和重复交付不发信任、货币或成长经验。

玩家对服务角色造成合格有害接触时，沿用共同敌对规则；首次由非敌对变为敌对，个人信任降低30。NPC会按共享动作/体力规则反击，拒绝服务。角色不是无敌设施：死亡进入既有持久死亡、实物遗骸与掉落流程，不会因重进补货或复活。未完成的人情委托会在日志注明委托人死亡，不能向另一人领取报酬。

对话记忆只保存已读话题和接受/完成的人情状态。正式任务完成、发现、知识仍归原来的`ExplorationProgress`，不复制为另一套任务权威。

## 条件与事务

打开与每次选择都检查当前角色、区域、死亡、敌对、真实距离、墙体视线、附近危险和动作状态。服务与人情接受/交付额外检查NPC实时日程。夜间可闲谈，交易和授课暂停；不把NPC尚未走回家的位置当成仍在营业。准备菜单中的过期选择不会远程执行。

接受人情只登记，不预扣或预留物资。交付调用`InventoryService.exchange`，双方先移出实际应交物资，再接收全部产物，保留UID与实例属性，允许腾出的空间参与交换。缺料、NPC缺钱、满包和失去可访问背包时拒绝，不能半付款、复制报酬、丢物或完成委托。关系和完成收据在库存通知发布前提交；库存观察者不能再次领取这笔报酬。落地背包不算可交付物资。

三份人情各完成一次，不会按日补奖励。NPC库存仍为首次初始化，之后只来自交易、课程收费、交付、加工等真实变化；休息推进时间和日程，不刷新资金或货架。

## 所有权与扩展

沿用Godot场景组合与显式注入，参考官方4.6[场景组织](https://github.com/godotengine/godot-docs/blob/4.6/tutorials/best_practices/scene_organization.rst)。

| 所有者 | 职责 |
|---|---|
| `NpcProfile / NpcTopic / NpcCatalog` | 不可变Resource定义：角色、日程、话题、条件、实际交换与服务标识 |
| `CampaignSession.conversations` | `NpcConversationService`持有本旅程话题/人情记忆，查询共同关系、库存和世界事实；不依赖灰河谷游戏对象 |
| `RelationService` | 态度、派系与个人信任；交谈UI不直接改分数 |
| `ServiceNPC : SharedActor` | 真实身体、共同角色组件、日程运动和交谈注视；不保存话题或任务权威 |
| `GrayriverResidents` | 内容装配：挂载角色并把批准的服务请求接到原商店、训练、委托和成长入口 |
| `NpcConversationScreen` | 查询、真实输入和结果展示；实时更新已有控件，不因库存或日程变化销毁鼠标悬停/焦点目标 |

新增同类居民/话题/人情先编写`content/social`资源并登记目录。复用已有服务时在内容适配器绑定对应执行器；新增服务语义先实现领域消费者，再登记可用标识，不把任意脚本或Callable写进存档。训练师的位置与日程读取已有`TrainingCatalog`，不再保留第二份训练师挂载代码。

目录校验角色定义、日程覆盖、ID唯一性、合法属性、支持的服务与实有物品。存档在Session快照中新增可选`conversations`和关系`dispositions`；旧档缺失时为空记忆/零信任，旧角色、课程知识与库存不重建。恢复前校验话题、重复记录、人情状态与有限分数；恢复完整替换并清除临时会话。会话只保存内存token与区域generation，换区、读档、关闭或替换界面后不能继续使用旧会话。

当前扩展边界：首批镇民交谈与既有野外命名人物交涉并存，旧交涉仍由`GrayriverStories`处理原证据/停战规则。追随者指令、目击犯罪与执法、配音和更多居民内容尚待后续扩展。本轮验证见[NPC交互验证](NPC_INTERACTIONS_VALIDATION.md)。

2026-11-10续：人物服务改为显式独立配置，人情可在J追踪并查询真实已知采集点，话题方向改为类型化地点引用；镇民按RETREAT/DEFEND区别自保。以[世界衔接](WORLD_SYSTEM_COHERENCE.md)为当前扩展契约。
