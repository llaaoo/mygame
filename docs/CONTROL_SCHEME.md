# 战斗、探索与鼠标整备操作

2026-11-07。当前默认操作以本文和游戏内操作设置为准；旧交付文档中的 E 搜刮、仅 Q/R 施法属于历史布局。

## 设计依据

参考 Bethesda 的[《上古卷轴5》PC 官方手册](https://assets.ctfassets.net/rporu91m20dc/1poliwondakI2QwKQMY2QI/b79ecee4541dd1ba7c7a85b453f0e9b2/manual_skyrim-le_pc_en-us.pdf)与[收藏和数字快捷键说明](https://help.bethesda.net/app/answers/detail/a_id/21354/~/how-do-i-favorite-items-in-the-elder-scrolls-v:-skyrim)：角色菜单承载管理，鼠标选择物品和法术，常用项再绑定快捷键。制作依托设施，组合由玩家准备。CDPR 的[控制设置支持页](https://support.cdprojektred.com/en/cyberpunk%20/pc/gameplay/issue/2407/i-am-experiencing-issues-with-controls)提供检查与恢复默认设置的做法。

本项目保留左键攻击、右键格挡、F交互的既定规则，把施法安排到 Q/E/R 和数字键，把低频整备放到 Tab 鼠标菜单。参考的是操作分工，没有照搬某款游戏整套键位。

## 当前默认键位

| 操作 | 默认输入 | 行为与边界 |
|---|---|---|
| 移动 | WASD | 不变 |
| 武器攻击 / 重击 | 左键 / Ctrl+左键 | 点击界面不攻击世界 |
| 格挡 / 取消施法 | 按住右键 | 保留实际装备与中断规则 |
| 常用施法 | Q、E、R | E与1共用编组第一槽；Q/R保留原独立槽，不增加额外技能或自动连招 |
| 扩展施法 | 1—6 | 1是E的别名；从K或Tab→技能编组选择已学动作，未编组槽不施法 |
| 显式消费恩赐 | Shift+施法 | 保留强化意图，不能再兼任默认冲刺 |
| 闪避 / 冲刺 / 放包 | Space / Alt / B | 不改变体力、负重或动作承诺 |
| 附近交互 | F或点击屏幕交互按钮 | 走同一动作请求，仍需在范围内、目标有效 |
| 现场作业 | F开始/取消、C切换方法 | 保留耗时、受伤和移动中断 |
| 常用物品 | Z/X或7/8 | 同一快捷栏前两槽，默认烤饼和清水；不会吃双份 |
| 其余物品 | 9/0 | 默认茶和炖汤；支持原有物品绑定、瞄准和取消 |
| 战利品全部取走 | 遗骸面板T或鼠标按钮 | 世界中T不执行搜刮；容量不足的留在原处 |
| 统一整备 | Tab或右下角远征菜单按钮 | 编组、来源、配方、附近设施、物品、装备、委托、知识和设置 |
| 直接入口 | K/M/N/I或O/J/G | 编组/来源/补给/装备/委托/地图；也可从统一菜单用鼠标进入 |
| 返回 / 保存 / 恢复 | Esc / F5 / F9 | 返回当前界面；沿用实际保存恢复规则 |

新旅程只开放已掌握动作，不替玩家塞入未学法术。E可以编组法术；学习后仍沿用原槽位填充与存档。技能栏展示实际主键，悬停与编组页显示别名。快捷物品也可直接点击右下角按钮。

## 鼠标整备与系统边界

Tab新增“整备与制作”：鼠标打开技能编组、释放来源、饮食背包，查看已学制作配方。靠近镇中工作台时可点“使用附近工作台”再选加工；烹饪、饮水、人物和遗骸同样可通过屏幕中的附近交互按钮访问。菜单查询不生产物品、不自动布阵或更换来源；不新增远程设施权限。

附近交互保存弱引用，提交前重验目标、距离和角色状态。UI通过`PlayerInputController.request_interaction → Action → ActorActionController → Interactable/InteractionProvider`提出请求；库存、制作、饮食和施法继续由既有领域服务结算。点击界面不能同时触发近战，文本输入或模态菜单不能触发世界施法。

键位归`InputBindings`所有；物品快捷键也进入同一可改键设置。布局版本3迁移旧E交互/搜刮默认值与数字1默认值，保留合法自定义和键位互换。世界与遗骸面板有不同输入上下文；世界动作之间拒绝重复绑定，左右键和已有菜单快捷键保留。逻辑/物理键码统一比较，防止从真实键盘捕获的事件绕过冲突检测。先保存设置再应用运行时映射，写入失败保持现状；恢复默认不触碰旅程存档，改键和恢复后的按钮标签即时刷新。

## 验证与限制

`test_controls_workflow.gd`使用真实键鼠事件，在960×600窗口检查E/1各一次施法、菜单文本输入隔离、鼠标进入编组、附近工作台、真实制造支付、快捷物品与取消、过期目标拒绝及点击不漏出近战。该测试恢复正常AI与模拟，但固定角色再生以核对费用，并通过受控位置、已知配方和材料建立UI场景，不代表自然探索或战斗平衡验收。

`test_input_bindings.gd`覆盖旧布局迁移、合法自定义、键位互换、冲突、上下文共享、恢复默认及写盘失败；`test_frontier_expedition.gd`验证遗骸菜单E不施法/搜刮、T实际取物。`test_world_pointer_input.gd`另用`Input.parse_input_event`更新全局鼠标状态，验证附近交互和物品按钮能够工作且不会漏出武器攻击；不能只靠GUI分发证明这个边界。原有键盘蓄力、格挡取消与小窗口编组测试继续保留。

本轮没有手柄、轮盘、完整无障碍设置或未经测试的手感结论。云端图形与干净提交全套回归结果见[本轮验证记录](validation/combat_exploration_controls.json)。
