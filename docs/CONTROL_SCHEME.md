# 当前操作与统一快捷槽

Ctrl+Shift+左键可释放主手元素附魔，真正挥出/离弦才消耗整层涂层；普通武技保留涂层，缺少来源明确拒绝，不花额外MP。普通附魔命中逐步积累燃烧/中毒，见[武器附魔](WEAPON_ENCHANTMENT.md)。

2026-11-07。Q/E/R与1—0是13个独立的动作/物品快捷槽；左键攻击、右键格挡、F交互。游戏内界面不暂停或减速世界，打开背包仍可能受伤。

## 战斗中的来源选择

例如将铭刻放Q、喷洒放E、火花放R：M → Q → 点击火石阵 → Q站定布阵 → 留在阵内用R触发火球。之后M → Q → 霜盐阵，或M → E → 选择具体毒性喷剂，继续按对应键执行。中键按住式提供相同功能，不占用左右键。

选材只改变目标槽，不消费、不施放、不改其他槽。快捷栏用介质/修饰简称、元素色、冷却和悬停信息显示当前来源。材料短缺保持灰显及稳定位置，不自动改成免费凝能阵；同种喷剂显示瓶编号和余剂量，空瓶/丢失后不会自动换另一瓶。选中缺少实物的喷剂不能确认。

火花、震荡、水引也可通过轮盘/K固定适配修饰；“基础”明确不加材料。例如两个水引槽可分别用霜盐和雷晶粉，互不覆盖。只对当前结果适配的修饰付费；不适配时明确说明不会消费。额外修饰与主介质分开，默认不添加；不适配旧修饰的移除在确认前说明。

轮盘优先记住上次使用的可选材槽，中心清楚显示按键与动作；轮盘内按任何已编组的可选材动作键可以切目标。未知或非施法物品快捷项不会被误改。正在引导、蓄力、投掷或铭刻时打开选择会取消未完成部分，已支付的脉冲不退款；旧释放事件不能使用新来源。

M、K和背包“选择这瓶喷剂”共用`QuickslotLoadout`。高级材料说明页的“配置”也转到同一轮盘；动作未编组时，K预选该动作。旧全局材料接口保留给原型/AI与旧调用适配，新的玩家流程不靠全局配置覆盖固定槽。

## 实时管理与落地物品

数量框或搜索框聚焦时，Esc仍关闭行囊返回战斗；展开的下拉或右键菜单先自行关闭。物理格挡、减伤格挡、破防与闪避在角色处给出结果文字；失衡、投掷准备及恢复期间，HUD显示受限状态。

完整界面接管战斗输入，角色站定但后摇、失衡恢复、体力、生命法力、状态、需求、世界时间与AI继续推进。受击显示红色告警；死亡、离区关闭失效界面。锁定剧情/恢复提示仍不能被I/K绕过，但不会暂停世界。旧房间模式显式暂停与测试中的引擎暂停仍按其自身规则处理。

纸娃娃预览只读取实际装备和背包，不创建可战斗角色。物品网格只列真实拥有的物品，显示口袋、背包、已穿戴或附近落地来源；点击身体槽位筛选适配装备，详情支持比较、卸下、绑定快捷槽。满包可交换装备，不能收纳的卸下请求明确失败；装备可直接丢到地上，不需要先腾背包格。

“丢弃一件 / 所选数量 / 整叠”和拖拽丢弃会生成真实物资袋，F打开并选择拾取。整件装备、喷剂保留UID，材料拆分生成新UID，合并遵循真实堆叠规则；数量、涂层绝对期限和瓶中剂量不重置。保存、重进和跨区域往返都保留；无法携带的留在原处。丢弃绑定实物后快捷项不可用，拾回同UID后恢复。

## 改键与兼容

设置可重绑“战斗选材轮盘”，默认中键；M仍是键盘菜单入口。左右键和菜单保留，世界动作拒绝冲突；配置布局v8移除V及自定义的独立武技释放键，保留无关自定义；Ctrl保留作同连招切换，E与1仍不合并。屏幕中间九槽与右下四槽是同一模型，所有13槽都可放动作或物品。

旅程现为v9，库存仍为schema1；v1—v8快捷槽迁移保留。轮盘/K的按槽选择、个人定时效果与实际冷却保存，现场法阵、瞄准、引导和临时能量不随读档恢复。材料切换保留技能实例、升级与共享冷却。

行囊按物品UID保留控件，库存通知不会反复重建正在点击的物品或无关的数量编辑框。真实数量、位置或装备改变时仍会更新并重验操作；世界保持运行。

开场面板及Esc系统菜单提供“重新开始灰河谷”：确认后归档旧旅程，建立全新主/备份并重建场景。取消保留当前进度；操作偏好及独立监狱槽不重置。它与保留成长的“重置河谷遭遇”用途不同。

## 武技、整修与按小时休息

武技由[连招窗口](WEAPON_ART_ROUTES.md)发动：轻击→重击打开1.1秒窗口；末击有效命中时，同一组合还可选接势变式。每个武器类型与相同序列最多装备两招，轻点Ctrl切换，不续时间；Ctrl+左键短按速发、长按重发。连续轻击命中路线保留0.9秒独立窗口，收招末350毫秒可提前输入，原收招完整保留。

K的“武技”页配置连招槽与查看条件；学习后自动装入空余连招槽，玩家可以移除或替换。同一招式的变式共享原冷却。旧存档保留知识并生成默认配装，独立武技快捷槽释放；V不再释放武技。Q/E/R与1—0继续独立绑定法术或真实物品。
F与镇中整修铺交互，用鼠标卖出、买回、拆解或强化所选装备；装备先卸下。F与篝火交互，选择游戏小时再开始休息；数秒准备可中断，成功后日期/时钟与计时状态一同推进。弓用左键攻击、实物箭在离弦时消费；弓不格挡。具体规则见[系统深化](SYSTEM_DEPTH.md)。

## 精准格挡与物理对策

普通物理攻击到来前0.18秒内开始右键格挡，可获得0.85秒手动反击机会；下一次左键或近战武技使用该机会，自动出招不会发生。重新尝试至少间隔0.65秒。慢招/高格挡压力的红色起手适合侧闪或拉开距离。贯步刺/蓄力穿射可打断未被挡住的准备，横扫可将敌人推向既有地面介质；全部保留真实体力、箭和碰撞约束。详见[武器纵深](COMBAT_DEPTH.md)。

## 攻击承诺与空间

当前刀剑、长矛、战杖各三段普攻，弓两段。每段手动左键，HUD显示动作名和接续窗口；可在后摇末段提前输入。末段结束重新起手，防御、闪避、施法、打开界面或主手UID变化会断开接续；长按左键为独立重击。具体距离、特点与费用见[武器普攻连段](WEAPON_COMBOS.md)。

普攻、重击与武技在后摇中逐步恢复移动，起手与有效阶段保留原有限制。后摇内最后350毫秒可提前输入下一动作，其余短缓存150毫秒；只保留一次手动请求，HUD显示待尝试提示，正式执行时重验费用与来源，不能靠按住左键自动连段。详见[武器操作响应](WEAPON_RESPONSE.md)。

刀剑小步衔接、长矛锁向前踏、战杖宽扫、弓拉弦时减速；每段仍需实际按键。四种武技起手站定，攻击有效阶段不能用闪避取消，收招允许支付体力闪避。暖红菱形表示高格挡压力，虚线表示远射锁向，渐退细弧表示恢复。横扫可把目标送进自己铺设的危险地面，目标有短暂位移恢复；重复命中不续满当前失衡。完整规则见[对策与站位](COUNTERPLAY.md)。

整修铺新增“店内排产”，菜单持续展示真实店存、工期和阻塞原因。课程可显示实物/探索等学习条件；确认时重验，课程和技能书共用武技知识限制。食品计时与属性同源，死亡清理后再计算恢复。详见[SYSTEM_EXTENSIBILITY](SYSTEM_EXTENSIBILITY.md)。

## 智能跟随与整备反馈（2026-11-08）

新学到并自动编入的法术操作，以及K的默认新编组，采用明确的“智能跟随”。成功布火阵后，跟随槽中的调谐、汲取和投射会选择各自资源目录中的首个火系形式；霜、雷等同理。火花/水引/震荡仍按真实现场组合，不自动追加可选材料。具体喷剂保持逐瓶选择。

滚轮在世界中切换最近使用的动作；正在瞄准时切该动作。M轮盘固定当前可用来源，K可固定来源或恢复智能跟随。手动选择只改这个槽，其他跟随槽继续读取最近成功施法。快捷栏“随”标记与悬停说明显示模式，轮盘只显示当前满足真实材料、场地、知识、法力与冷却条件的具体形式，基础与材料修饰可并列，不重复显示智能跟随伪选项；K仍保留完整整备目录。轮盘显示形式费用和实际消耗。没有相应元素形式、缺少材料或法阵时会拒绝，不切成其他元素、替代材料或免费形式。准备/蓄力中切换取消原请求，仍需重新按键。读档、死亡、离区清除最近元素；固定选择和智能模式本身保存。旧空选择API及旧绑定保留原兼容语义。

制造详情使用真实产出名称与持有量，结果说明口袋/背包位置，点“整理”直达实物；仍需玩家手动移入口袋。缺料施法显示拒绝原因及口袋/背包余量。整修铺保留连续交易的选中实物，支持所选数量与整叠交易；工期完成的店货通过排队通知和J知识记录提醒，仍需购买。读记录后J定位该条记录，页签与选中条目保留，重新打开清空旧文本搜索。训练师拒绝显示实际原因与当值时段，学习后可直接打开武技编组。

世界滚轮会验证最近来源是否仍为可选材动作，并跳过与智能项实际形式相同的一格；改绑为物品不阻断其他有效槽。M/K仍提供明确的跟随/固定模式选择。地面调谐提供真实地表形式，仍需已学对应组合、Shift及脚下介质，准备中地表消失则拒绝，不回退免费凝神。

## 行路者手册（2026-11-09）

五个主页面共享顶部导航，鼠标一次切换；行囊返回保留搜索和选中实物。行囊详情直接点Q/E/R或数字槽按钮绑定，技法页先选择内容，再按目标快捷键或点右侧槽。绑定不执行动作，E与1独立。单件物品隐藏数量输入，批量整理仍可选择数量；右键有丢弃一件。

点击战斗栏中的槽位直接进入该槽的选材；非选材项进入技法编辑，点击本身不施法。轮盘左侧可用鼠标换动作，右侧显示费用条件，中央选择具体来源。保留M/中键/滚轮及正常世界攻击格挡。详见[界面与操作](UI_AND_INTERACTION.md)。

左键蓄力阈值0.32秒，最多准备2秒；普通攻击和武技都不在按下时先出轻击。有效窗口内按下可短时保留当时的段落/路线，取消不会恢复旧窗口；闲置蓄力最多抵扣0.32秒起手，动作后摇不能用于抵扣。右键格挡、闪避、其他动作、菜单、换装、失焦、控制、死亡和读档取消未释放意图。规则、变式与证据见[按住式武器操作](WEAPON_HOLD_INPUT.md)。


## 出售与实时选材（2026-11-09）

整修铺列出已穿戴装备并提供显式卸下入口，失败原因显示在详情。出售按选定UID结算：先在事务副本取出货物和货款，再接收双方所得；卖掉整件腾出的格子可收货款。部分出售仍需真实空间，店家资金与库存有限，不补钱、不自动卖穿戴装备。详情按钮在窄列中裁切并提供悬停全文，描述正常换行。

战斗轮盘每次打开紧凑排列可用形式；打开期间每个扇区身份固定。来源消失留下空扇区并撤销悬停，具体瓶变动须重新选择，松键不能选到替代来源；重开重新紧凑排列。确认仍重新查询条件。世界继续运行，低法力/冷却中可在K整备未来形式。
