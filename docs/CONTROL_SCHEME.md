# 当前操作与统一快捷槽

Shift+已绑定武技键可释放主手元素附魔，真正挥出/离弦才消耗整层涂层；普通武技保留涂层，缺少来源明确拒绝，不花额外MP。普通附魔命中逐步积累燃烧/中毒，见[武器附魔](WEAPON_ENCHANTMENT.md)。

2026-11-07。Q/E/R与1—0是13个独立的动作/物品快捷槽；左键攻击、右键格挡、F交互。游戏内界面不暂停或减速世界，打开背包仍可能受伤。

| 操作 | 默认输入 | 当前规则 |
|---|---|---|
| 移动 / 闪避 / 冲刺 | WASD / Space / Alt | 轮盘中仍可移动、格挡、闪避；闪避关闭轮盘并取消未确认选择 |
| 攻击 / 重击 / 格挡 | 左键 / Ctrl+左键 / 按住右键 | 选择、拖拽和关闭界面的点击不穿透成攻击 |
| 独立快捷槽 | Q/E/R、1—0 | 每键可放法术动作、已学武技或真实物品；E与1独立 |
| 按住式选材 | 按住鼠标中键 | 按目标动作键选槽，鼠标划向介质，松开中键确认；移回中心或Esc取消 |
| 点击式选材 | M | 同一轮盘，按动作键选槽，点击扇区确认；M或Esc取消，点击轮盘外取消 |
| 多介质 / 多瓶 | 轮盘内滚轮 | 最多8个固定扇区一页；同种喷剂固定占一个扇区，悬停该扇区滚轮切换具体瓶；其他位置滚轮翻页 |
| 强化 | Shift+动作键 | 显式消费适配恩赐；轮盘预览跟随当前Shift意图，仍不自动准备条件 |
| 完整编组 | K | 选择动作/物品，再选目标槽；可固定主介质、额外修饰和具体喷剂；右键清槽 |
| 统一行囊 / 穿戴 / 补给 | I / O / N | 同一界面，分别聚焦全部、装备、补给与材料；身体槽位显示真实穿戴 |
| 物品管理 | 单击 / 双击 / 右键 / 拖拽 | 单击详情；双击使用或换装；右键操作菜单；拖入对应装备槽换装，拖入明确丢弃区落地 |
| 拆分与批量整理 | 详情数量输入框 | 选择数量后移动到口袋/背包、拆分或丢弃；保留容量与脱战限制 |
| 放下整个背包 | B | 与丢弃单件不同；已放下的背包不能远程整理或收纳装备 |
| 附近交互 / 现场作业 | F；C换方法 | 地面物资、设施、人物与遗骸用同一范围重验；作业保留耗时与中断 |
| 遗骸取物 | 面板T或鼠标 | 容量不足的留在原处 |
| 菜单 / 委托 / 地图 | Tab / J / G | 实时界面；地图内中键、右键拖动，滚轮缩放，左键放路标，中键不会打开选材 |
| 返回 / 保存 / 恢复 | Esc / F5 / F9 | Esc先关闭当前界面，否则打开实时系统菜单；保存实际地点与世界状态 |

## 战斗中的来源选择

例如将铭刻放Q、喷洒放E、火花放R：M → Q → 点击火石阵 → Q站定布阵 → 留在阵内用R触发火球。之后M → Q → 霜盐阵，或M → E → 选择具体毒性喷剂，继续按对应键执行。中键按住式提供相同功能，不占用左右键。

选材只改变目标槽，不消费、不施放、不改其他槽。快捷栏用介质/修饰简称、元素色、冷却和悬停信息显示当前来源。材料短缺保持灰显及稳定位置，不自动改成免费凝能阵；同种喷剂显示瓶编号和余剂量，空瓶/丢失后不会自动换另一瓶。选中缺少实物的喷剂不能确认。

火花、震荡、水引也可通过轮盘/K固定适配修饰；“基础”明确不加材料。例如两个水引槽可分别用霜盐和雷晶粉，互不覆盖。只对当前结果适配的修饰付费；不适配时明确说明不会消费。额外修饰与主介质分开，默认不添加；不适配旧修饰的移除在确认前说明。

轮盘优先记住上次使用的可选材槽，中心清楚显示按键与动作；轮盘内按任何已编组的可选材动作键可以切目标。未知或非施法物品快捷项不会被误改。正在引导、蓄力、投掷或铭刻时打开选择会取消未完成部分，已支付的脉冲不退款；旧释放事件不能使用新来源。

M、K和背包“选择这瓶喷剂”共用`QuickslotLoadout`。高级材料说明页的“配置”也转到同一轮盘；动作未编组时，K预选该动作。旧全局材料接口保留给原型/AI与旧调用适配，新的玩家流程不靠全局配置覆盖固定槽。

## 实时管理与落地物品

数量框或搜索框聚焦时，Esc仍关闭行囊返回战斗；展开的下拉或右键菜单先自行关闭。物理格挡、减伤格挡、破防与闪避在角色处给出结果文字；失衡、投掷准备及恢复期间，HUD显示受限状态。

完整界面接管战斗输入，角色站定但后摇、失衡恢复、体力、生命法力、状态、需求、世界时间与AI继续推进。受击显示红色告警；死亡、离区关闭失效界面。锁定剧情/恢复提示仍不能被I/K绕过，但不会暂停世界。旧房间模式显式暂停与测试中的引擎暂停仍按其自身规则处理。

纸娃娃预览只读取实际装备和背包，不创建可战斗角色。物品网格只列真实拥有的物品，显示口袋、背包、已穿戴或附近落地来源；点击身体槽位筛选适配装备，详情支持比较、卸下、绑定快捷槽。满包可交换装备，不能收纳的卸下请求明确失败；装备可直接丢到地上，不需要先腾背包格。

“丢弃一件 / 所选数量 / 整叠”和拖拽丢弃会生成真实物资袋，F打开并选择拾取。整件装备、喷剂保留UID，材料拆分生成新UID，合并遵循真实堆叠规则；数量、涂层绝对期限和瓶中剂量不重置。保存、重进和跨区域往返都保留；无法携带的留在原处。丢弃绑定实物后快捷项不可用，拾回同UID后恢复。

## 改键与兼容

设置可重绑“战斗选材轮盘”，默认中键；M仍是键盘菜单入口。左右键和菜单保留，世界动作拒绝冲突；配置布局v5继续保留合法旧自定义，E与1仍不合并。屏幕中间九槽与右下四槽是同一模型，所有13槽都可放动作或物品。

旅程现为v9，库存仍为schema1；v1—v8快捷槽迁移保留。轮盘/K的按槽选择、个人定时效果与实际冷却保存，现场法阵、瞄准、引导和临时能量不随读档恢复。材料切换保留技能实例、升级与共享冷却。

行囊按物品UID保留控件，库存通知不会反复重建正在点击的物品或无关的数量编辑框。真实数量、位置或装备改变时仍会更新并重验操作；世界保持运行。

开场面板及Esc系统菜单提供“重新开始灰河谷”：确认后归档旧旅程，建立全新主/备份并重建场景。取消保留当前进度；操作偏好及独立监狱槽不重置。它与保留成长的“重置河谷遭遇”用途不同。

## 武技、整修与按小时休息

K增加“武技”页：训练师学习或口袋中阅读技能书后，选择武技再点击独立快捷槽。武技要求对应主手武器，消耗体力，弓技消耗箭，不扣MP；原法术来源轮盘保持只服务法术。装备详情可展开武器动作与实际强化属性。

F与镇中整修铺交互，用鼠标卖出、买回、拆解或强化所选装备；装备先卸下。F与篝火交互，选择游戏小时再开始休息；数秒准备可中断，成功后日期/时钟与计时状态一同推进。弓用左键攻击、实物箭在离弦时消费；弓不格挡。具体规则见[系统深化](SYSTEM_DEPTH.md)。

## 精准格挡与物理对策

普通物理攻击到来前0.18秒内开始右键格挡，可获得0.85秒手动反击机会；下一次左键或近战武技使用该机会，自动出招不会发生。重新尝试至少间隔0.65秒。慢招/高格挡压力的红色起手适合侧闪或拉开距离。贯步刺/蓄力穿射可打断未被挡住的准备，横扫可将敌人推向既有地面介质；全部保留真实体力、箭和碰撞约束。详见[武器纵深](COMBAT_DEPTH.md)。

## 攻击承诺与空间

刀剑小步衔接、长矛锁向前踏、战杖宽扫、弓拉弦时减速；每段仍需实际按键。四种武技起手站定，攻击有效阶段不能用闪避取消，收招允许支付体力闪避。暖红菱形表示高格挡压力，虚线表示远射锁向，渐退细弧表示恢复。横扫可把目标送进自己铺设的危险地面，目标有短暂位移恢复；重复命中不续满当前失衡。完整规则见[对策与站位](COUNTERPLAY.md)。

整修铺新增“店内排产”，菜单持续展示真实店存、工期和阻塞原因。课程可显示实物/探索等学习条件；确认时重验，课程和技能书共用武技知识限制。食品计时与属性同源，死亡清理后再计算恢复。详见[SYSTEM_EXTENSIBILITY](SYSTEM_EXTENSIBILITY.md)。
