# 当前操作与统一快捷槽

2026-11-07。本页替代先前E/1共槽与Z/X别名布局。当前规则：Q/E/R与数字1—0各自独立，全部可以放动作或物品。设计、内容盘点与架构审查见[施法体系review](SPELL_SYSTEM_REVIEW.md)。

## 默认输入

| 操作 | 输入 | 规则 |
|---|---|---|
| 移动 | WASD | 沿用角色移动 |
| 武器攻击 / 重击 | 左键 / Ctrl+左键 | 点击界面不攻击世界 |
| 格挡 / 取消准备 | 按住右键 | 保留装备要求，中断未提交施法/物品准备 |
| 独立快捷槽 | Q/E/R、1—0 | 每个键一个槽，均可绑定动作、食物、抹布、投掷瓶、具体喷剂或装备 |
| 强化意图 | Shift+动作键 | 显式消费适配恩赐；不自动补充前置条件 |
| 闪避 / 冲刺 / 放包 | Space / Alt / B | 保留费用和动作承诺 |
| 附近交互 | F或屏幕交互按钮 | 同一请求重验目标和距离 |
| 现场作业 | F开始/取消、C换方法 | 保留耗时、受伤和移动中断 |
| 遗骸取物 | 面板T或鼠标按钮 | 容量不足的留在原处 |
| 整备菜单 | Tab或右下角按钮 | 鼠标进入快捷栏、来源、配方、物品与装备 |
| 直接菜单 | K/M/N/I或O/J/G | 快捷栏/本次来源/补给/装备/委托/地图 |
| 返回 / 保存 / 恢复 | Esc / F5 / F9 | 沿用实际保存恢复规则 |

R与6初始保留火花；E初始为空，不复制1。1—5沿既有发现学习填入动作，只填真正空槽，不覆盖物品编组。7/8/9/0初始是烤饼、清水、茶和炖汤，均可改成其他物品或动作。Z/X无默认绑定，可在操作设置自行选择；历史合法自定义继续保留。

## 用鼠标编组

打开K或Tab→快捷栏编组。左侧“基础动作/可用物品”选择内容，再点右侧任一槽；右键清空。物品页区分口袋、背包、件数、喷剂余量和装备实例；绑定不移动物品、不补充余量。N或装备详情也可选择目标键，再点“绑定所选快捷槽”。

基础动作可继续跟随M的本次选择，也可以在K先选具体介质及可选修饰，再绑定到槽。例如Q固定火石阵、E固定霜阵：两者共享铭刻冷却，却独立读取自己的来源和费用；不需要每次进M切换。固定方案不自动布阵、找残魂或接后续技能。物品/材料不足或来源失效时拒绝，不偷偷替换。

喷剂物品快捷项固定该瓶UID，按住逐剂消费，空瓶停止；投掷按住瞄准、松开出手，右键/Esc取消；抹布和食品保留耗时；装备仍受脱战、容量和动作限制。右侧四个按钮也可鼠标操作，是同一快捷模型的视图。

## 改键与持久化

操作设置保护左右键和菜单键，世界动作之间拒绝重复绑定；保留菜单上下文隔离。保存设置成功后才应用，失败保持现状；恢复默认即时更新标签，不改库存或世界成果。布局v4将旧E/1默认别名迁移为独立键位，合法自定义保留。

旅程v7统一保存动作/物品快捷槽与可选固定介质，v1—v6的Q/R和数字技能保留，旧belt只导入一次。清空的槽重进保持为空；引用失去的瓶/装备显示不可用，不自动替换。M本次选材、施法准备、瞄准、引导、现场法阵和临时能量不在读档时恢复。

当前图形/真实输入与干净归档验证见[记录](validation/unified_quickslots.json)。受控UI测试不是自然通关或最终手感验收；没有新增手柄/轮盘系统。
