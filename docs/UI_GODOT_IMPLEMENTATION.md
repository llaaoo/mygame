## 已进入实际游戏

- **一条13槽快捷栏**：Q/E/R与1—0按原独立来源排列，动作和物品都走 `QuickslotLoadout`。移除 `FrontierHUD` 另一套四槽渲染和鼠标执行入口，不复制或迁移绑定数据。
- **当前形式持续可见**：HUD从现有 `CastPlan` 显示按键、结果、总费用及固定/跟随；选材关闭后仍保留。额外范围、材料与恩赐解释移到悬停/选择层。当前实物失去条件时仍显示原身份与拒绝原因；不会换成另一瓶或免费形式。未觉醒者隐藏整行法力，魔法槽显示锁定。
- **点击先查看**：可选材动作直接打开该槽的真实形式；物品/空槽在现有轻层里显示详情，不使用、不施法。食品、涂料等可显式点“使用该物品”，仍向原输入适配器提交请求；瞄准/持续类物品回世界用原快捷键，避免点击UI把投掷朝向变成按钮方向。
- **行囊分开阅读与执行**：纸娃娃、实物、详情三栏；装备/使用、比较、更多和原位绑定固定在独立操作区。绑定需先展开，再点13个独立目标中的一个；成功后收起，不跳K。数量只在整叠多件时出现。转移/拆分/丢弃放在“更多”或右键，仍为同一个库存事务。
- **实物辨识**：小窗采用单列、大窗双列；同名喷剂直接显示真实剂量与瓶号。列表控件保持UID身份；搜索、所选实物、列表/详情滚动在关闭与返回时保留。角色、地区和存档切换仍沿用原生命周期。
- **配装比较**：只读实际装备定义及已存在实例派生定义，展示重量、同槽数值、费用变化方向、不同武器的连段类型和真实弹药要求。不临时换装，不伪造角色总DPS，不转移涂层。
- **统一输入范围**：Tab/Shift+Tab在当前管理页循环焦点；世界Tab仍开整备。搜索不触发战斗或导航；展开后恢复同UID对应操作焦点。Esc先收起未提交的绑定；实际受伤后的警告期间直接关闭行囊返回世界。关闭、选材和失焦继续走原按住抑制，旧松键不补发。
- **主题与预算**：沿用 `GameUIStyle`/Theme，接入原型墨绿、米灰、黄铜配色，普通按钮至少40px。资源、快捷栏、当前形式、需求、地面提示和菜单入口分区。纸娃娃仍读真实穿戴与角色外观目录，没有新外部素材。

## 状态与事务所有者

| 信息/意图 | 既有权威 | UI的职责 |
|---|---|---|
| 实物、剂量、涂层、穿戴、地面归属 | InventoryService / InventoryActions | 读取实际UID，通过既有请求操作 |
| 快捷绑定与按槽选材 | QuickslotLoadout | 只绑定所选动作/物品；不维护第二本快捷栏 |
| 当前可用形式、总费用与失败 | CastPlan / QuickslotMaterials | 预览与确认共用同一查询，实际执行再次验证 |
| 临时当前槽 | MaterialWheel.last_source | 键鼠选择与动作输入更新同一个游玩上下文，HUD与滚轮都读取它 |
| 窗口过滤、滚动和展开 | ActorInventoryScreen视图上下文 | 只保存界面状态，不进入旅程资源记录 |
| 战斗、时钟、AI、恢复 | 原模拟与执行器 | 完整页只接管输入，轻层仍允许原约定防御/移动 |

本批还解决了原来的来源分歧：HUD可能展示G中刚选的R，而世界滚轮优先改上次按过的Q。现在当前槽归一个临时上下文；当前是物品时，滚轮不会悄悄去改之前的法术。

## 验证与证据

专门入口：`python3 tools/run_tests.py --tests ui_vertical_input`。以隔离持久化档案、明确的物资/知识/觉醒/位置夹具驱动真实键鼠，启用正常AI与世界模拟；它不是自然新档首玩或盲玩。

覆盖未觉醒法力隐藏、13槽身份、物品只读查看、指定瓶离开口袋后拒绝、定义比较、固定动作区、原位绑定、Tab/文本范围、关闭重开上下文、960×540/960×720/1440×900/1920×1080的125%字、真实形式选择/资源失效、取消蓄力和磁盘重进。

图形平台为Linux Xorg/X11、Godot4.6.3、gl_compatibility、Mesa llvmpipe软件渲染。原生指针事件按窗口变换换算，记录请求尺寸、实际窗口和逻辑视口；图形截图不当作正常远征通关、硬件帧率或听感证明。Xorg驱动有“不支持切换V-Sync”的平台警告；音频Dummy，声音未验收。

实际图像与报告见 [验证目录](playtests/ui-godot-2026-11-12/)。本批的原生构图用于操作/布局，不是新的美术资产或自然游玩奖励。正式游戏默认预算、地图、配方、敌人和存档封装未改变。原生89项断言通过；干净归档全套157/159，两个旧UI验收更新后在新干净归档2/2通过，执行代码相同。报告保留两次结果与159项覆盖映射，不称为单次全量绿色。

## 下一批边界

这完成首条正式操作路径，不代表十三个原型视图全部迁移。三目标准备清单、UID收藏/待售与批量交易、分级消息历史、独立HUD尺度、地图传闻分类和其他管理页的大规模改版仍按[对标次序](UI_AAA_BENCHMARK.md)推进。继续接现有库存、发现、制造与交易服务，不把HTML数据或样例数值复制进游戏。

布局采用官方4.6推荐的[嵌套Container](https://docs.godotengine.org/en/4.6/tutorials/ui/gui_containers.html)与[明确焦点范围](https://docs.godotengine.org/en/4.6/tutorials/ui/gui_navigation.html)。原位绑定和操作区不是靠整体缩放世界腾位置；手柄继续暂缓。

## 布局比例与响应式整理

完整管理页共用外边距，并将宽屏工作区限制在1600逻辑像素；HUD仍按实际视口布局。行囊三栏以穿戴26%、实物34%、详情40%为分配目标，先满足各自可读的最小宽度。穿戴区足够宽时将九槽排成两列，窄屏保留单列滚动；角色和独立物品大图区继续读取真实实物。主操作改为等宽两列，避免多一字就产生孤立的一行按钮。

制造、手札、对话等共用页加宽侧栏，列表/详情按36%/64%分配；底部辅助操作靠右，避免跨整页的长条按钮。列表与详情允许在低矮窗口收缩到80像素并滚动，不能以固定的最小阅读高度撑出屏幕。窄屏导航省去常驻键位后缀，悬停仍显示当前绑定，快捷键功能保留。

技艺目录与详情按34%/66%分配，13槽绑定行和提示居中。角色页加宽分支与详情，成长树按实际画布居中，节点高度读取当前字体尺寸，连线取实际节点边缘；属性列表居中并限制阅读宽度。小窗口的成长树可独立横向/纵向滚动，不缩小文字或隐藏节点来假装适配。
