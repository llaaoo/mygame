# 灰河谷界面与操作

2026-11-09。当前实现以“行路者手册”为统一界面：深色岩板、暖灰文字、黄铜选择线和原绘河流等高线。保持2D生存远征的个性，统一信息层级与常用操作。此次没有引入新的外部素材；装饰只绘制界面，不参与世界随机数、碰撞或玩法。

参考成熟RPG的交互原则：Skyrim的物品/角色比较，BG3的实物与上下文操作，Destiny的稳定导航与详情列，以及Outward的独立快捷槽、实物准备和持续风险。这里只借用适合本游戏的操作模式，不表示达到这些作品的全部美术、动效或无障碍水平。

## 统一导航

整备与制作、行囊、技法、委托与旅程、行路图共享顶部导航。一次点击切换；原来的I/O/N、K、J、G与Tab世界入口保留。行囊返回时恢复其筛选、搜索和选中UID；日志保留页面上下文，当前追踪委托与可交付项排在前面。整备与日志的侧栏只保留相关子页，移除重复的装备/补给主导航。

`ExpeditionNavigation`是共享Control，接收当前页和注入的Callable，不保存战役或物品真值。`GrayriverGame.open_interface`只负责组合已有页面；`GameUIStyle.begin_modal/end_modal`继续管理输入归属和关闭。通用界面通过注入接入，旧验证场未注入时不展示灰河谷导航。设施和交互对话仍保留现场上下文，导航不会把制造、交易或休整变成远程操作。

输入按Godot4.6官方[事件传递](https://docs.godotengine.org/en/4.6/tutorials/inputs/inputevent.html)及[焦点导航](https://docs.godotengine.org/en/4.6/tutorials/ui/gui_navigation.html)核对：控件处理鼠标事件；菜单快捷键只处理未被输入框等消费的事件，不抢文本编辑、选择器或原生焦点移动。仍保留既有的按住输入抑制和UI点击防穿透。

## 行囊

- 穿戴、物品、详情三个区域始终并列。每列独立滚动，小窗口不再把详情放到背包下面；实物纸娃娃按可用宽度缩放。
- 分类和容器过滤显示选中态；点击物品立即更新选中边框。材料使用各自语义图标；空页提供操作说明。
- 使用/穿戴/卸下等主要操作置顶。一次点击目标快捷键即可绑定实物；装备与喷剂保留具体UID，E与1等槽位保持独立。此操作只绑定，不使用或施法。
- 数量明确标注；单件隐藏数量框。批量转移、拆分、所选数量丢弃及整叠丢弃仍使用原事务；右键保留“丢弃一件”。属性比较、动作说明等展开查看。
- 食品即时展示目录中的饱食/饮水/疲劳变化。旅途状态和恢复规则可从穿戴列查看。材料用途读取现行操作与已知配方，可直接转到对应技法配置，仍需亲手选择、绑定与施放。

## 技法与选材

技法页使用两列内容卡、独立配置列和可滚动的13槽列表。选中动作、武技或物品后，既可点目标槽，也可直接按其当前绑定键。没有选择时按键不重新绑定；菜单中不执行动作、不扣材料或MP。尚未掌握的动作保留学习限制。

世界中的战斗快捷栏可点击进入该槽的配置/选材，不用先开M再找槽；左右键点栏位都只打开准备，世界中的左键攻击、右键格挡保持原规则。轮盘左侧提供可滚动的动作列表，中央选择来源，右侧说明费用与条件。鼠标点击左侧只换槽，不误作点击轮盘外关闭。HUD入口传入已有防御朝向，轮盘继续保留移动、格挡与闪避。

轮盘与冷却/资源栏分区，小窗不遮住冷却。缺少实物仍明确显示，不自动换材、补阵、换瓶或连招。额外说明不影响选择与提交边界。现场作业增加独立标题与主按钮，长说明仍独立滚动。
