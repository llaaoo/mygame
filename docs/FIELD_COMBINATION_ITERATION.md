# 现场组合迭代

以98bd11b为基线，按五轮交付：单次材料与动作表达、撤离与资源记录、敌人读招、回廊前哨、教学与整章试玩/桌面导出。组合由现场事实与基础动作产生，不增加预案、自动补条件或连招宏。

## 第一轮：单次材料与动作表达

- 快捷栏主图标固定为基础动作，结果显示在次级预览；解释从动作、有效条件、材料/恩赐/装备与费用，最后到结果。
- 可选材料仅用于下一次实际适配并成功提交的动作，然后清除；不适配不消费也不清除。失败回滚保留选择，离区、死亡、读档清除。
- `serialize()`保留临时选择供事务与即时检查，`serialize(true)`仅保存库存。旧自动绑定迁移后清除，首次显示说明，不损失材料。
- 必需媒介保持原规则。组合结果不可装备、拖入槽位或从基础输入入口直接执行；补上ConditionalCastController公开准备入口的约束。
- 原测试中重复消费同一素材的场景改为显式重新选择，旧持久绑定断言改为仅保留库存，仍检查原效果和费用。

验证：新增material_intent涵盖预览纯净、取消、执行拒绝回滚、成功清除、不适配保留、输入/读档防绕过和旧绑定迁移。其余检查继续回归。

## 第二轮：现场撤离与资源记录

菜单返营关闭暂停后开始3秒站定撤离，沿用作业中断。实体出口、死亡与读档仍是各自独立入口，撤离不治疗或补料。

实际回复记录自然、食品、饮水、茶、技能、掉落与休整；溢出不计，混合自然回复按当时各来源速率比例分摊实际恢复，归因之和等于真正恢复量。MP事务失败不发布回复凭据。记录作业尝试、完成与中断，以及施法条件解释和地面/命中反应；这些记录不能执行或作为预案加载。旧记录缺省兼容。

新增retreat_ledger检查菜单解除暂停、3秒、实际伤害取消、资源保持、溢出、事务失败、来源分摊和存档。整章资源实测统一在第五轮的最终规则下进行，不以中间版本短样本替代。
