# 灰河谷系统深化：当前契约

2026-11-07 UTC。承接[实施边界](SYSTEM_DEPTH_PLAN.md)，本轮深化已有地图上的物资、时间、战斗和知识循环。剧情、副本、任务和解谜仍沿用当前MVP。

## 可以怎样玩

- F与镇中篝火交互，选择休息1、3或6个游戏小时。数秒是可被移动、受伤和取消打断的准备；成功才扣口粮与清水，并推进选定小时。右上角显示日期和24小时时钟。
- 林缘倒木产炭屑/树液，矿道晶脉产晶砂/金属碎料，湖岸产霜盐；采集后外观变暗，再生分别需6、8、8个游戏小时。原有食物、水源和加工点继续保留。
- 镇中整修铺可出售或买回具体装备、拆解闲置装备、强化到+3。店家有有限货品和河谷币，不因休息、重进或重新打开界面补货。先卸下装备再整修。
- 手册新增木杆箭、石肤药剂和醒神药剂配方。箭由炭屑和金属碎料加工；制造仍检查知识、实际材料和产出空间。
- 训练师06:00—22:00授课，用河谷币学习武技，再去K的“武技”页绑定Q/E/R或数字槽。镇中布料包另有一本贯步刺武技书：放进口袋，站定阅读，完成才消费。已学会时不浪费书。
- 买弓、备箭、穿戴后用左键射击；右键不提供弓格挡。武技与物品仍共用现有13个独立快捷槽，E和1互不替代。

## 时间和休息

`InventoryService.clock_seconds`为战役持久时钟，`WorldTime`只做日期与昼夜投影。当前倍率沿用每现实秒一个游戏分钟，即一天24现实分钟；暂停和离线不推进。1/3/6小时休息额外推进60/180/360秒模拟时间，另有正常进行的准备时间。

每三小时向上取整消耗一份烤饼和清水；野外已修复前哨只可短休一小时。附近敌人或有害状态拒绝休息。成功后自然恢复照常推进，另每小时恢复20%生命、25%法力、降低15疲劳，补给补充饱食与饮水。营地粗食保留为生存兜底，不直接恢复生命法力，也不制造库存食品。

时间跳跃以一秒步长推进既有模拟Ticker，避免把短期恢复或状态延长到整段睡眠。涂层使用绝对期限；食物、药剂、法阵、采集倒计时、武技冷却和服务日程会一起变化。NPC物理准备取消、恢复继续，服务NPC按日程到工作/休息位置；不把几小时的delta施加到角色移动。未装载角色的需求和食品药剂按保存时间戳衰减，离开再回来不会续满。

## 物资与装备循环

| 去向 | 当前规则 |
|---|---|
| 出售 | 一次卖一件所选UID；普通装备基础售价至少8币，买价为售价两倍；强化每级增加2币售价 |
| 拆解 | 销毁所选装备，得到2+强化等级份金属碎料；产出容不下则完全拒绝 |
| 强化 | 第n级费用5n币+2n碎料，最高3级；主手每级攻击+1，其余槽位每级生命上限+4 |
| 制箭 | 炭屑1+金属碎料1→木杆箭6；箭必须在口袋中才可射击 |
| 石肤药剂 | 苦叶2+守护粉1+清水1→药剂1；90秒受伤倍率0.85 |
| 醒神药剂 | 苦叶2+晶砂1+清水1→药剂1；解毒并提供90秒毒免疫 |

买卖搬动同一实物，涂层、强化和喷剂余量不重置。强化只改变实例属性，通过运行副本计算装备加成，绝不改共享Resource。库存先在私有快照验证全额费用、身份与容量，成功才统一更新所有权索引与发布事实。双向转移必须先移除双方旧索引，再建立新索引。

装备当前来自探索、敌人实际穿戴/战利品或有限商店；本轮没有新增整套装备锻造树。货币也是普通真实库存物品，没有独立钱包。

## 武器与武技

`WeaponMoveset`和`MartialTechnique`是不可变Resource；连段位置、衔接时限、知识和冷却在角色实例中。`ActorActionController`执行物理动作，`CombatExecutor.report_hit`统一结算接触。每段都必须由新输入提出，不自动连招。

| 武器 | 普通攻击节奏 | 代表武技 |
|---|---|---|
| 刀 | 三段，较快起手，末段伤害和冲击提高 | 破势斩：较慢起手，70冲击，抓格挡或收招 |
| 矛 | 两段，窄扇面，102—112距离 | 贯步刺：145距离，需维持朝向与间距 |
| 杖 | 两段，较慢宽扫，高冲击 | 压阵横扫：175度扇面，65冲击，长恢复 |
| 弓 | 单次拉弓，物理箭矢，墙体遮挡 | 蓄力穿射：更长起手、680射程和较高伤害 |

武技分别消耗26/25/30/24体力，共享同种武技6秒冷却，不消耗MP；弓技另需一支箭。要求学习且穿戴对应武器，换武器不能绕过冷却。失衡、取消、超出衔接时限或更换武器会重置连段。重击仍沿用动作承诺和体力规则。

弓起手锁定具体箭叠；实际离弦才消费一支，起手被打断保留弹药。箭叠或武器失效时拒绝射出，不换另一叠。箭矢命中复用伤害、格挡和状态链，起射时的武器涂层随箭携带；不额外生成可回收箭。穿戴与详情显示实际强化属性和武器动作参数。

## 法阵、食物与药剂

灰河谷凝能阵默认120秒，每次组合消耗40秒存续；材料阵180秒，每次消耗30秒。自然流逝与组合消费共同扣除预算，使用不会续时；装备延时与一次灰烬修饰仍叠加。原型验证场保留旧充能规则。阵内标签、G/K来源说明与预览展示当前规则。

同一事务失败只退此次实际预留时间，保留已经自然流逝的部分。剩余时间不足一次额度时，成功使用消耗全部余量。阵过期或离区会清理；读取存档不会恢复现场法阵。

食物180—240秒提供持续恢复，并有烤饼耐力+2/炖汤耐力+3；两者互相替换。药剂90秒且同组互斥，石肤和毒免疫不能同时保留。它们与法术恩赐使用同一个BuffManager；食品药效保存剩余时间，休息/切区/重进不重新计满。食物增耐力同时影响体力与生存韧性。

法术的5—10秒短期恩赐保留其战斗窗口：用于临时近战附加、元素亲和以及Shift消费。食物和药剂负责较长期准备，避免所有增益都依赖法术或都退化为常驻属性。药效、食物和武技不是独立的第三套状态/伤害框架。

## 敌人和扩展边界

正常敌人加入墙体视线、短期视野记忆与最后可见位置；绕路时不追踪墙后玩家实时坐标。根据可见轻击起手选择短格挡，面对长起手/高冲击选择侧闪；防御受1.3秒决策间隔和真实体力限制。攻击格挡目标可选择重击。低体力撤步恢复；先避危险地面，再考虑准备，看到近处施法准备会施压。武器距离读取实际动作，弓类角色支持实物弹药和近身退距。

保留真实涂附、投掷、喷洒、清毒和法阵组合费用，不读取玩家输入或背包来预判。AI提出的闪避也必须进入物理执行器，不能只有策略返回值而无实际动作。

后续优先做更多正常AI遭遇的数值/手感验证、武器动画与命中表现、训练师进阶/技能书获取条件，再扩充任务副本。尚无完整商业经济模拟、NPC采集生产链、离线世界演算或完整武器技能树。跳过的睡眠时段推进计时和日程，不逐帧模拟远处AI战斗。验证见[记录](SYSTEM_DEPTH_VALIDATION.md)。
