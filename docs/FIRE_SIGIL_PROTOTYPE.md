# 火阵与火花组合原型

> 当前项目默认启动探索 MVP，见 [当前版本说明](./MVP_RELEASE.md) 与根目录 README。本文保留独立火阵原型的行为说明；开局直接授予技能仅适用于旧 `main.tscn` 回归场景，探索版需要阅读记录学习。

> 2026-11-04：按用户的 Outward 参考修正：基础动作是火花，火球是火阵条件下的组合结果。本阶段只推进技能和组合，不新增装备。

## 试玩

使用 Godot 4.6.3 打开 `main.tscn` 单独运行旧原型。运行整个项目会进入探索 MVP。没有图形桌面时可执行下方无界面测试。

| 默认输入 | 行为 |
|---|---|
| 按下并松开 5 | 脚下铭刻火阵：准备 0.8 秒，成功后扣 8 MP，冷却 8 秒 |
| 按下并松开 6 | 火花：准备 0.25 秒，阵外在身前产生近距离火花，不发射远程投射物，扣 4 MP |
| 自己的火阵内按下并松开 6 | 火花触发定向火球：扣 12 MP，消耗一次触发量，组合冷却 2 秒 |
| 准备时闪避 | 取消准备，不消耗 MP 或法阵次数 |

火阵半径 96、持续 15 秒、两次触发，每个角色只持有一个；新阵合法创建后替换旧阵。技能栏显示实际动作与费用，法阵显示剩余次数和时间；槽位也显示键位和技能说明。技能可以在现有编组界面重新配置，冷却按动作/法术组合规则 ID 保留，不能通过换槽刷新。

铭刻时明显移动、准备中受伤、换掉准备中的技能、死亡或房间切换会取消动作。火球准备中离阵、法阵过期也会取消，不能偷偷降级为普通火花。取消后有 0.3 秒组合动作恢复。法力不足不扣资源。

火阵本身没有伤害；火球使用现有投射物和 CombatExecutor，不额外释放普通火花，也不凭空在干地生成燃烧面。火球可以击毁油桶，继续走已有销毁、油面与燃烧反应。暂停时准备、法阵、冷却和中央模拟都停止。

## 实现边界

- `SpellCombinationRule` / `SpellCombinationResolver`：只读主动规则与判定，不复用命中后的 synergy 来选择主动结果。
- `ConditionalCastController`：SkillManager 下的个人准备会话、稳定冷却、条件版本校验和提交；先专门承载这一条链，尚非完整通用能力框架。
- `FireSigil`：有所有者与版本的临时空间条件。当前一个角色一个引用即可，不建设全局空间注册框架。
- `SkillExecutor`：继续执行火花与火球结果；支持世界原点目标、转换后的父节点坐标；效果初始化后才启动生命周期。
- 旧 30 法术及 run 奖励目录保留；铭刻和火花作为额外原型动作放在默认 5/6 槽。

火球标记为组合结果，不能直接装备/施放，不作为可装备技能奖励；默认右手也改为基础火花。阵内火球不会同时触发近距离火花或全阵范围爆发。

旧喷发资源保留作底层 AoE 回归，不再作为当前法术组合规则结果；基础火花资源 ID 保留 ignite，玩家可见名称已统一。

当前直接授予火阵法术组合规则，尚未接入探索解锁、知识日志或持久能力进度。旧项目的局外进度自动恢复、一般技能强化归属、完整背包暂停来源管理等不因这条链完成而宣称全部修复。未实现冰阵、附魔、护盾和完整受击结果协议。

## 验证

在仓库目录设置可写 XDG 路径后运行：

```bash
cd /workspace/mygame
export XDG_DATA_HOME=/tmp/mygame-fire-test-data
export XDG_CONFIG_HOME=/workspace/.mygame-env/config
export XDG_CACHE_HOME=/workspace/.mygame-env/cache
mkdir -p "$XDG_DATA_HOME"
godot --headless --path . --script res://tests/test_fire_combinations.gd
```

测试使用真实主场景、技能管理、法力、物理碰撞和油桶反应，覆盖：

- 阵内组合/阵外基础动作、定向击中远处目标，不误伤侧方目标；阵外火花只影响近处、正确费用与触发次数。
- 所有者与法术组合规则权限、法力不足、共享冷却与换槽、离阵取消。
- 暂停、中断、无效位置不替换旧阵、过期、区域清理。
- 火球打爆油桶并生成燃烧反应，世界原点目标与非原点父节点变换。

原有地图、run、装备、技能目录、强化、存档、UI 与玩法脚本继续作为回归测试。图形界面的手动战斗观感仍需有桌面时试玩调整。

早期原型的计时器退出清理问题已随 MVP 的生命周期调整处理：投射物/AoE 寿命、受击无敌和敌人攻击冷却使用暂停感知更新。最新原型回归与探索集成运行未再出现该计时器告警，当前验证范围见 [MVP 实现说明](./MVP_RELEASE.md)。
