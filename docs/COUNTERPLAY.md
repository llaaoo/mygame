# 对策、站位与材料协同

2026-11-07 UTC。承接[武器纵深](COMBAT_DEPTH.md)，本轮深化现有动作和真实地面系统；[实施范围](COUNTERPLAY_PLAN.md)与[实测记录](COUNTERPLAY_VALIDATION.md)分别记录计划和证据。地图、敌人数、掉落预算及技能数量未扩充。

## 攻击承诺和武器区别

`AttackProfile.step_distance`描述有效攻击阶段沿接受动作时朝向的前踏。每帧只移动本帧实际覆盖的有效阶段，使用角色物理碰撞；起手、恢复、取消、失效武器均不会补走剩余距离。前踏不锁定或追踪目标，不增加命中次数，也没有自动连段。

| 武器 | 当前段数与前踏 | 操作特点 |
|---|---|---|
| 刀剑 | 三段，4/6/8距离 | 正向斩/反向斩/窄面直刺，出手保留40%移动 |
| 长矛 | 三段，10/16/20距离 | 逐段延伸、变窄，出手15%/15%/10%移动 |
| 战杖 | 三段，0/4/0前踏 | 宽扫/短顶/反向推扫，出手10%/20%/10%移动 |
| 弓 | 两段，无前踏 | 稳弦/短窗口快射，出手10%/15%移动；每箭真实消费，不能格挡 |

表格于2026-11-09按[当前武器连段](WEAPON_COMBOS.md)更新；后摇平滑恢复移动，不沿用出手倍率锁完整段。

四种已有武技起手期间站定：破势斩挥出时前踏8，贯步刺前踏28，横扫与蓄力穿射没有前踏。伤害、体力和弹药成本沿用原预算。装备详情展示前踏与攻击移速，武技说明同步实际规则。

高格挡压力起手除了暖红色扇面，还有菱形标记；远射准备显示锁向虚线；收招以角色周围渐退细弧表示。前踏以短线表示，武器运动、方向和接触继续读取同一动作定义。这里只增加形状和阶段反馈，没有新增音效、美术动画或全局慢动作。

## 控制有机会，也有恢复

- 已开始的同一段失衡不被后来命中续满或延长；伤害与稳定性消耗照常结算。结束后仍有原来的0.6秒冲击失衡保护。
- 贯步刺/穿射打断准备，使用受击前的准备和控制快照；冲击已经取消准备时仍能正确识别这一击的打断。恢复保护期间仍可受伤，但不再次受到这种准备打断。
- 每个目标被合格横扫击退后有0.9秒位移恢复；期间伤害仍成立，只拒绝新的击退。普通取消、不同攻击来源或重新选择目标不能清除这段恢复。
- 击退仍通过物理碰撞移动；盾、闪避、无敌及无实际伤害的接触继续阻止它。死亡、离区、休息和重进清理瞬态控制。
- 麻痹等状态仍由既有BuffManager管理其持续与恢复，本轮没有把它们复制成另一套控制框架，也没有授予全面免疫。

## 敌人根据真实空间决策

战术模式的MOVE现在接回`EnemySurfaceAwareness`。此前旧移动分支会使用危险转向，战术分支却直接提交原方向；现在两者都采用每0.25秒、最多8方向的地面/碰撞评估，保留请求移动幅度。铺火、毒地和冰面能改变敌人的接近路线，避险不会免除实际状态和伤害。

敌人只有在看到朝向自身、位于距离/扇面内的真实起手后，才进入已有反应延迟和防御判断。朝向别处的重击不会诱发无意义闪避。侧闪先检查左右实际碰撞和地面风险，避免固定朝一个方向撞墙。

物理射手和借阵火球会检查当前射界，使用与真实箭相同的碰撞层和接触者解析；前面有同伴、其他身体或墙时，先侧移寻找射界，再尝试攻击。两侧都堵住时允许等待。近战同伴过度挤在目标同侧时也会找侧位，保留上一轮正在挥击时让位的规则。

这些查询不花箭/MP，也不生成物资。攻击一旦承诺，之后移动的身体仍可能挡住飞行物；它不是友军穿透或命中保证。弓兵行为使用受控装备测试，本轮没有给原地图新增弓兵。实际刻阵术士仍支付现存火石、充能与法力。

## 材料与物理命中的边界

火抹布、树脂喷剂、火花、地面蔓延与横扫继续独立操作：玩家先铺介质、手动点燃，再把目标打入危险区域，或用危险区域改变敌人路线。近战涂层触发脚下介质反应，现改在命中完成且实际造成未格挡伤害之后进行；拒绝的接触不能提前点燃油地。旧近战适配入口采用相同资格。

地面火焰会蔓延，自己也可能受到影响；准备中的动作会被打断。材料并不保证优于普通攻击，也不能代替观察术士预警、控制距离和及时撤离。同档混合遭遇会记录成功、失败、消耗及剩余资源，不用单次样本推断整体平衡。

## 架构与后续

Resource继续只保存可编辑定义；ActorActionController拥有动作/位移窗口与物理推进，HitContext保存单击前置快照，CombatExecutor负责资格与统一命中，EnemyCharacterBrain保存各自观察和站位决策。UI只展示查询，原库存、快捷槽、制造、生存、经济及存档权威不变。

统一runner加入`counterplay`、`counterplay_input`、`counterplay_encounters`。前两项覆盖边界和真实键鼠组合/保存；后一项从同一游戏生成存档恢复相同有限整备包，使用现有守备兵与术士原始上限和正常AI。该遭遇的摆位与整备包是受控夹具，另以原有71步正常新档路线检查自然获取、训练和返镇。全面装备平衡、自然首玩时长与更多混合阵型仍需后续样本。
