# 现场组合首章实测与验收

2026-11-06，Godot 4.6.3。先复跑原45项，再按五轮扩展到50项；各轮独立分支验证后提交、推送、合并。没有添加预案、连招宏、自动补阵或自动吃喝。Windows/Linux为本地包，不联网发布。

## 方法与实际边界

图形试玩通过外部键鼠输入操作普通游戏窗口，观察器只读取状态与信号。没有改角色上限、库存、敌人、伤害、知识或进度。初始角色100HP/60MP、四属性10；途中用正常获得的4点把耐力升到14，生命上限120，其他属性保持10。没有佩戴装备。关卡、补给、任务和冷却水路均通过正常交互完成。

先走新档主线及支路，验证三处机关、建设、任务与首领，再从正常获得的存档复制相同检查点做独立对照。另补一次不中途读档的新档完整资源记录，区分实际恢复、消耗与溢出。原发现补给、食品、回复与掉落常量未调整。

这些是熟悉路线的输入辅助样本，不是首次玩家测时或统计平衡结论。菜单暂停时间不计入模拟用时；没有通过等待或刷怪凑20—30分钟。完整运行日志留在执行环境，仓库保留精简数据[同库存对照](validation/field_chapter_trials.json)和资源记录。

## 已完成的现场流程

- 营地读材料手册，外院读火阵；基础动作可独立施放，离阵不会被自动补阵。
- 档案室用火花→震荡处理晶簇，开启返营升降机；冻结及破冰由后续同档试战单独验证。
- 祈堂学习凝神与回响，主动撤离3秒回营。探索发现可一次性恢复生命法力，重读不再奖励。
- 回廊用真实费用建成前哨并短休；先水引清理脚下污染，再火花→水引→震荡解封泵，E取泵芯。泵修复与前哨保持独立。
- 回廊封匣和机房调压器复用水→火形成实际蒸汽；分别保持半秒解封，调压器仍需现场取件。
- 机房切换分流阀，从干地选择一次雷晶粉水引，让实际水路导电启动晶闸；材料成功消费后选择清空。三处检修捷径均带来实际返场收益。
- 回营组装调和台，五项委托均正常交付；回访、试战不重复发放已领材料与属性点。
- 关隘原捷径继续工作，冷却水路影响首领；主线完成后正常返营，返营不自动补满。首次路线后回访读齐全部11个动作。

补充营地演示：手动铭刻火阵8MP，脚下火花两次分别产生火球术、各花12MP并各用一充能；充能耗尽后再按同一火花动作，只产生4MP火花。没有自动续阵或直接装备火球。演示独立于整章资源样本，见[实际事件](validation/field_fireball_demo.json)。

现场也保留了失败：污染伤害会打断准备，离封匣过远的火花不会作用到它所在格；近距离、同一实际地面格上的水与火才完成蒸汽条件。已发出的范围效果不会因敌人死亡立即消失，离场仍需观察危险。

所有样本同一存档、120HP/60MP、耐力14、其他10、无装备、相同库存及生存状态。档案室32/32/28HP敌人使用原有“本区试战”，实战AI、碰撞和避险开启，击杀没有经验、掉落或残魂。每次独立加载同一磁盘检查点。

实际记录包含冻结地面、震荡破冰及命中前frozen/wet状态消费、导电、水变毒、毒地引燃。污染样本主要通过地面完成兑现，不将它虚报为每个目标都触发命中引爆。四种结果都来自手动基础动作，记录标签没有执行能力。

额外撤离样本：同档试战后用一次霜盐水引控制追击，退至干燥入口站定3秒，现场撤离成功；花7MP/霜盐1、实际承伤14。返场保留原清理与永久机关，试战离区结束，不自动生成新试战或领取奖励。材料不足时普通近战和原出口仍可用。

结论：组合功能可用，冻结可创造撤离窗口，导电与污染保留自身风险；在这组脆弱守卫的直接清场样本里，普通近战更省资源。没有把“全部完成”解释为四种配置已经平衡。普通动作保留价值，也不能据此宣称准备成本已得到足够回报。

结束饱食约97.61、饮水84.54、疲劳4.63：沿已知路线取得一次性补给、主动食用与休整后，生存压力偏低。发现补给仍提供原60点请求恢复，但整轮真正接受的探索回复只有54HP；不能把每个发现都乘60充作收益。

首轮含一次中途读档的探索约494.3秒（8分14秒）模拟时间、零死亡，返营15HP。其最初观察器没有逐来源记录回复，因此用上述不中断复测填补完整计量，不据早期缺失数据推造恢复来源。

## 验收结果与仍需校准

功能回归覆盖基础结果防直施、一次材料/失败回滚、预览因果、撤离完成和中断、敌人前摇/朝向/距离/取消、前哨费用/防重/读档与真实火源、发现状态和回复来源。地面256格和导电48格预算继续由原专项回归检查。

首章的学习、成长、补给、委托、首领与返营已实际走通。准备充分、部分食品耗尽、主动撤离返场均有实际样本；本次对照检查点已没有烤饼库存，仍能通过基础战斗及手动选择完成遭遇。死亡返营和旧档兼容由自动化实场景覆盖。

20—30分钟目标尚未通过首次玩家验收：熟悉路线的两次模拟有效用时约6分22秒／8分14秒，明显偏短，不能把调试、菜单阅读或停顿补成关卡时长。下一轮应单独校准遭遇与远征收支：为控制、掩护与地面布置提供更值得准备的情境，复核一次性发现恢复60与较低敌人血量的影响；保留普通动作及无耗材返程，避免通过等待或反复刷怪补长度。本轮保持原恢复/掉落/食品常量，只给出对照依据。
