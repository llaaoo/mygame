# 短按、长按与鼠标武技

2026-11-09。当前主入口如下；Q/E/R和1—0继续是独立的物品/法术/动作快捷槽。

| 输入 | 松开时提出的动作 |
|---|---|
| 短按左键 | 当前普通轻击段 |
| 长按左键 | 当前武器独立重击，结束普通轻击段 |
| Ctrl+左键，短按 / 长按 | 当时有效连招路线的速发 / 重发武技 |
| Ctrl+Shift+左键，短按 / 长按 | 同一武技形式，并显式消耗当前主手整层元素附魔 |
| 按住右键 | 格挡，取消未释放的武器准备 |
| V（可改键） | 兼容速发武技入口，不占快捷槽 |

长按阈值为0.32游戏秒，准备上限2秒，超时取消且不自动出招。按下不先打一记轻击，不支出体力、箭矢、附魔或武技冷却。松开只提交一次动作；体力和冷却在动作接受后结算，箭与附魔在实际挥出/离弦时提交。已接受动作仍保留完整有效期和收招承诺。

按下时锁定主手UID、普通连段位置或武技路线/family令牌，以及是否释放元素和具体涂层状态。松开时采样瞄准方向；之后保持原物理动作的锁向规则。中途松开Ctrl或Shift不会换招，后来再按Shift也不能偷偷把普通武技变成元素释放。已失效的窗口不能靠按住重开；没有路线的Ctrl+左键只报告拒绝。

为避免长按吞掉弓的短接续窗口，合法按下会保留当时的普通段落/武技路线，最多到2秒准备上限；只对这次请求有效。正常计时继续推进，取消不会把消耗的时间补回窗口。后摇末端允许准备与原350毫秒单动作缓存衔接，发动仍等前招完成，不能跳过收招。已经在闲置期间蓄力的时间最多抵扣0.32秒起手；忙于上一招的时间不抵扣，最少仍有0.08秒实际起手。

右键、闪避、其他动作、菜单、轮盘、换装、控制、失衡、失焦、离区、死亡和恢复存档均有取消边界。菜单和蓄力期间世界保持正常速度。旧鼠标松开不会在关闭菜单后补招。

## 重发的取舍

重发仍是原武技的变式：相同知识、冷却、武器要求和附魔释放机制。常规路线和接势路线各有显式重发Profile，体力较高、承诺较长，并非只套统一伤害倍率。

| 武器 | 重发常规 / 接势 | 主要差异（相对于各自速发） |
|---|---|---|
| 刀剑 | 蓄势破盾 / 蓄势截断 | 格挡压力3倍、冲击90，较窄扇面；34体力 |
| 长矛 | 蓄势贯冲 / 蓄势追贯 | 更远狭窄刺击、更大碰撞前踏，保留打断准备；33体力 |
| 战杖 | 蓄势震扫 / 蓄势回震 | 更远推移，牺牲速发宽扇覆盖，保留碰墙与推移恢复规则；38体力 |
| 弓 | 满弦穿射 / 满弦追隙 | 更远、更快箭矢和较大冲击，仍只用一支真实口袋箭；32体力 |

普通轻击→重击打开常规路线；命中式轻击路线打开接势。精确窗口、命中资格和优先级见[武技路线](WEAPON_ART_ROUTES.md)。元素版本沿用原武器的同family物理命中/元素波和库存提交，不增加额外法力或第二次材料扣款。

## 架构和接入

- PlayerInputController只收集真实边沿并提出Action，保留同物理帧内完整短按；UI消费和生命周期取消会清理待处理边沿。
- ActorActionController持有本角色瞬态准备、年龄、起手抵扣和一次性保留；WeaponArtState持有真实动作历史，WeaponComboState只持有普通段落。没有新的快捷槽、库存或伤害权威。
- MartialTechnique的`charged_profile`和`charged_followup_profile`为只读AttackProfile。抵扣只修改运行时副本，不改变共享Resource；库存、体力和CombatExecutor继续走原链。
- InputBindings布局v7移除旧默认Ctrl+左键重击，迁移到手势。旧独立重击键、武技自定义键和其他合法绑定保留。Ctrl+左键受鼠标动作保留规则约束，不可绑到法术槽。

## 验证范围

`weapon_hold`用受控时钟与一个静止敌人验证八种重发分支、精确阈值、体力/箭矢、真实格挡压力、拒绝无费用和普通段落保留。`weapon_hold_input`用实际Godot鼠标/按键事件验证四武器的速发与重发、晚窗口按下、修饰键快照、真实抹布/涂层、无自动攻击，以及防御/菜单/超时/换装/控制/失焦通知和F5/F9取消。后者恢复正常模拟与所有敌人AI，装备、知识和安全测试位置由fixture提供；不作为自然开荒、真人手感或目标设备性能证明。
