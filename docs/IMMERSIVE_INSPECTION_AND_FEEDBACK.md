# 轻量交互、战斗读屏与物品样本

普通现场记录、遗骸与地上物品默认使用侧边抽屉，给实际人物和周围世界留下观察区。完整行囊、制造、交易、成长和重要世界决定保留各自的管理界面。所有展示继续读取原权威，不增加预览库存、第二套Buff或物品外观所有权。

## 阅读与搜取

- F阅读仍提交原发现/知识规则，再显示简短记录；完整用法和J日志可以继续查看。
- F搜取遗骸/地上物品，按具体UID显示物品、数量、剂量与涂层。点“取走这一项”或T尽量取走可携带部分；剩余物资原地保留。T不自动剥取专业部位，不承诺整批全成全败。
- 点击专业部位先在抽屉内展开知识、工具、耗时与产物，明确“开始专业处理”后才交回原现场作业控制器。未学会、工具失效或放不下产物仍由原查询拒绝。
- “展开整理与详情”进入原完整遗骸页；地上物品可进入完整行囊的地面来源。没有一键换装或自动选择另一份同名物品。
- Esc、收起按钮或点击抽屉外返回世界。抽屉接管输入，菜单点击不攻击；角色控制恢复沿用原按住取消边界。**轻量指画面覆盖更少，打开期间不提供移动/攻击操作，也不暂停世界。** 选材轮盘的既有移动/防御规则不变。
- 来源超距/失效、切区或真实受伤会收起轻量界面。普通生命/上限刷新不作为受伤；接受后的动作不因收起退款。
- 临时结果在抽屉固定消息行显示，避免盖住人物和读到的内容；重复F提示与当前不可操作的快捷栏、菜单入口收起。关闭后恢复原HUD，不停AI或隐藏真实伤害。

QuickLootView只保存展开/显示状态；遗骸仍调用GrayriverLoot.take，地面仍调用InventoryActions.take，库存由InventoryService提交。列表结构按UID保持稳定，秒数/余量只更新既有标签；按住鼠标时不重建目标。

## 四种反馈归属

| 信息 | 显示 | 原权威 |
|---|---|---|
| 尚未达到阈值的异常 | “积累·中毒40%（未生效）”，独立于动作/缓存说明 | BuffManager.buildup |
| 已经施加的状态 | 名称、对应图形、剩余时间/进度；有害状态优先，最多六项，其余悬停展开 | BuffManager的实际实例 |
| 主手附魔 | “涂层·火附魔·剩余秒数”，详情保留原效果解释 | 主手实际UID的coating与截止时间 |
| 地面法阵 | “火阵余能·剩余秒数/次数”及每次触发消耗，弧线随实际余能更新 | FireSigil.remaining/charges/use_seconds |

近距敌人标签复用相同积累/生效语言，继续先检查距离和视线，不增加透墙状态雷达。法阵数字只在玩家自己的附近法阵显示，法阵远离画面仍按原时钟消耗与清理。没有调整状态数值、阈值、伤害或法阵预算。

HUD状态区按与生命区相同的底部锚点排布；以局部offset计算相邻关系，避免窗口尺寸改变时混用尚未更新的画布坐标。图标与数值不会挤进快捷栏。可点击的附近交互放在右下窄列、菜单入口上方，并按法术说明的实际右边界限制宽度；不能为了避开下方文字而把按钮移进中央瞄准区，导致左键攻击点开观察面板。F键与鼠标入口仍提交同一请求，长标题由悬停显示。

## 插画、穿戴与地面

当前16件现有物品接入一张原创AI生成图集：刀、矛、杖、弓、皮甲、盾、靴、烤饼、清水、火石、药草、布料、油瓶、火抹布、炭屑与金属碎料。来源、输出条款和散列见[素材记录](../content/art/items/grayriver/SOURCE_NOTICE.md)。

小图和大图引用同一格；完整图片约1.75MB压缩PNG、1254² RGBA，未增加每物品一张大图的重复存储。大图的可选`illustration_region`不进入实物/存档，越界不采到另一件物品。作者接入见[物品表现](ITEM_PRESENTATION.md)。

实际穿戴、纸娃娃和遗骸继续共用ActorEquipmentVisual及真实UID。盾面桥徽、皮甲缝线/腰带和靴底细节在共享渲染中补全；样本杖头和靴的显示色与插画协调，未改变属性。地上袋/缓存箱的小图读取容器当前实物，取走后随真实余量刷新。遗骸使用当前实例派生装备，不能由角色模板补出外观或掉落。

插画不会自动变成角色逐方向动画；当前人物仍用现有像素身体和几何装备层，未声称已制作16套穿戴帧、3D模型或全部物品插画。没有新物品、奖励、敌人或地图预算。
