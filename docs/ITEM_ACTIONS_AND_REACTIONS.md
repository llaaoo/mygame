# 物品动作、喷洒与真实来源

2026-11-07。当前灰河谷使用本规则；旧验证场保留旧动作数据用于回归。

涂附属于使用物品，不占技能槽；投掷属于操纵实物。法术的核心输入是铭刻、喷洒、火花、震荡、调谐与汲取。具体药效、阵型和临时能量来自材料或已经存在的条件。玩家仍需逐个操作，不存在自动补阵或组合宏。

## 操作与用途

| 操作 | 成本与操作 | 主要作用 |
|---|---|---|
| 武器涂附 | N选择抹布使用；站定1.2秒，成功才消费1份；无体力/法力成本 | 给当前主手的具体武器附着60秒效果；换装、交易、掉落仍跟随该武器 |
| 投掷 | N把油瓶/毒瓶/麻痹瓶绑定到7/8/9/0；按住瞄准、松开出手；右键/Esc取消 | 准备0.5秒、恢复0.4秒，发射时消费整瓶和8体力；飞行速度480、最大距离360，撞墙提前落地，落点半径60 |
| 喷洒 | M选喷剂；K编组喷洒后按住对应技能键，松开即停 | 准备0.25秒，随后每0.5秒消费该瓶1剂＋基础2 MP；前方120距离、60度锥形；移动速度45%，不能同时攻击或格挡 |
| 铭刻 | M选凝能、火石、霜盐、雷晶粉或守护粉 | 只创造真实法阵；凝能无材料、1次充能，其余消耗实物、2次充能；之后另行手动触发 |
| 调谐 | M选择纯粹凝神、回响墨、守护粉，或某一种脚下法阵 | 纯粹凝神不借阵；回响墨产生印记；守护粉产生护盾；选定阵型不存在则拒绝，不改用其他来源 |
| 汲取 | M明确选择真实残魂或某种自身法阵 | 每次消耗一个残魂或一次法阵充能，转换成45秒临时能量；同类基础3层（魂类保留既有装备容量修正），换类型替换；不会制造永久材料 |

基础费用仍经过现有属性、装备与恩赐规划，M显示本次总价。喷洒药效由喷剂定义，原料品质不再增加另一笔隐式单剂材料费。

投掷适合隔着距离一次投送、预先铺设较持久的地面介质；喷洒要求近距离持续暴露，可以转向、节省部分余量，地面残留仅2秒。两者均对接同一命中/状态/表面反应系统，也都检查墙体。范围判断使用目标位置和地面格中心，地面表现受现有64单位网格精度限制。

## 实物与联动

- 毒抹布：毒性萃取＋布料；火抹布：树脂＋炭屑＋布料。涂层不叠加，新涂层替换旧涂层。同名中毒刷新，使用最新药剂的强度，不叠加中毒层数。没有麻痹抹布。
- 油瓶、毒瓶、麻痹瓶分别消费树脂、毒性萃取、麻痹萃取制造；发射后即使未命中也不退瓶。投射物未能生成则连同体力一起回滚。
- 清水、树脂、普通毒、浓毒和麻痹喷剂：每瓶3剂。除清水喷剂只用清水外，其余各用对应原料1份＋清水1份制造。制作时装水，喷射时不直接抽取水囊。
- 普通毒每秒3伤害、持续5秒；浓毒每秒6伤害、持续8秒。清水清洗，树脂留油地，麻痹限制行动1.5秒。麻痹不能反复刷新，结束后有2秒同类控制免疫。
- 火花、震荡与手动调谐继续响应已有法阵、地面、状态；守护阵补齐粉末来源。汲取的阵能可用Shift＋火花/震荡手动兑现一层；残魂能量沿用既有魂术反应。
- 布料来自镇边独立、一次性的布料包和守备兵实际携带物资。手册与炼毒记录教授新增配方；已读记录仅回补知识，不重发物资。NPC通过同一接口涂附、投掷、喷洒，物资用掉后不会在尸体上补货。

## 身份、存档与中断

喷剂始终逐瓶占格，以UID和`doses`记录余量。N、整理和尸体搜刮允许选择具体瓶子；涂层装备也逐件列出，武器和尸体上的颜色读取实际涂层。喷剂不接受材料回收，不作为完整原液进入其他配方。

一次持续喷洒固定一个UID；该瓶空了立即停止，保持按键不会自动开启下一瓶。每个脉冲独立提交，已经喷出的剂量不退；下一脉冲缺法力、缺瓶、来源改变或效果不可用时不多扣资源。受伤、失衡、闪避、界面打开、死亡、离区和读档中止动作；涂附还要求主手UID保持不变。

涂层到期时间读取CampaignSession的游戏时钟。放在背包、被交易或离开原区域仍计时；暂停菜单与离线不计时。v6存档保存时钟、逐件属性及四个物品快捷键，继续读取v1—v5。瞄准、持续动作、准备来源与临时能量不跨区域或读档保留。旧回响铭印编组归并到调谐，元素法阵和旧毒雾编组沿用之前的统一迁移。

## Godot职责划分

- `ItemData.use_profile → ItemUseDefinition`是可编辑的物品用途定义；`SpellOperationData / SpellPayloadData`定义动作和来源。共享Resource不持有角色引用，不被施放过程改写。
- `ActorComponents`场景注入`ActorContext`；`ItemActionController`和`SprayChannel`只依赖角色能力、区域与库存，不持有灰河谷游戏对象。UI和AI提交相同的请求。
- `InventoryService`独占UID、余量、涂层和容器变更；`CastTransaction`共同管理实物、体力、法力、状态与场地充能。预览只读，失败恢复UID和属性。
- 施法顺序：基础动作 → 主介质/明确来源 → 真实条件与反应 → 单次修饰材料 → 恩赐/装备与总费用 → 校验和提交。`SpellSourceResolver`过滤所选阵型；灰烬仍能作为一次修饰延长统一铭刻，不与主材料混在同一个选择里。
- `ConeCoverage`共用角度、距离和视线判断；`ThrownDose`负责物理飞行和落地传递。伤害与有害状态仍进入`CombatExecutor`，地面交给`SurfaceManager`，不在UI或投射物中直接扣目标生命。
