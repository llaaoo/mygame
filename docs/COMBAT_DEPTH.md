# 武器纵深与战术节奏

2026-11-07 UTC。沿用[系统基座](SYSTEM_DEPTH.md)，本轮重点是让已有武器、武技和准备资源在战斗中形成用途。剧情/地图保持当前MVP，实施边界见[计划](COMBAT_DEPTH_PLAN.md)。

## 手动防御与反击

右键普通格挡仍按原规则支付体力，盾可挡住正面物理伤害，武器格挡保留减伤后的伤害。开始格挡后的0.18秒内挡住普通物理攻击，会额外免除该击冲击，并得到0.85秒反击机会。下一次玩家亲手提出的近战/近战武技消费机会，伤害×1.25、冲击×1.4；没有自动出招、免费补体力或法力。

精准尝试间隔0.65秒，同一次格挡只可成功一次；持续轮询或快速松按不重置。重击和破势斩具有较高格挡压力，无法凭精准时机获得反击机会，适合闪避、拉开或用足够体力承受。过期、失衡、取消、死亡和离区清理瞬态机会；菜单保持世界运行，不延长机会。该状态属于动作窗口，不是永久增益或第三套Buff框架。

## 四种武技的具体用途

| 武技 | 当前用途 | 对策与代价 |
|---|---|---|
| 破势斩 | 正面格挡的体力压力×2.1；保留70冲击 | 26体力、慢起手；目标侧闪或拉开会使其落空 |
| 贯步刺 | 145距离；未被挡住且造成伤害时，取消目标准备并锁定0.35秒 | 25体力、窄角度；应抓涂附、投掷、喷洒、拉弓或法术起手 |
| 压阵横扫 | 宽扇面；合格命中施加64距离/0.18秒的击退 | 30体力；盾、闪避和无敌阻止位移，墙体限制实际移动，可与已有地面介质配合 |
| 蓄力穿射 | 实物箭离弦后命中可打断准备；保留远射程与较高伤害 | 24体力+1箭，较长起手；墙体/格挡/闪避仍有效 |

命中继续经过`CombatExecutor.report_hit`。`HitContext.strike`携带不可变AttackProfile，格挡资格先判定，额外物理效果在最终伤害成立后结算，反馈读取最终HitResult。准备状态在受击前采样，防止普通受伤取消了准备后，武技无法识别本来命中的起手。旧敌人警告准备通过ActorContext查询/取消能力接入，打断后旧回调不能再完成。

箭矢在离弦时固定伤害和涂层；飞行中换装备不重算箭伤。攻击准备期间武器UID失效会取消这次动作，起手中断保留尚未离弦的箭。

## 动作与反馈

身体仍读取实际穿戴；攻击时由动作执行器绘制同一件武器的起手、挥击/刺击/横扫/拉弓与恢复，颜色读取涂层。起手警示与有效接触区采用相同距离和扇面；慢招与高格挡压力用暖红色提示。轨迹只是表现，命中、防重和墙体检查仍由共同执行链决定。没有全局命中停时、菜单暂停或额外视觉伤害。

常驻HUD只在有效期显示反击机会。精准格挡、打断和击退显示已结算反馈。攻击、格挡、闪避或反击机会期间隐藏中心交互提示；敌人战斗名牌收起观察行囊说明和MP数值，保留名称、资源条及正在准备的动作。

## AI节奏与小队

`CombatTemperament`是Resource规则；各EnemyCharacterBrain保存独立观察、短格挡承诺、防御间隔和攻击后空隙。压力型、距离型和守备型使用现有角色模板，差别由时间与站位取舍产生。

- 先看到真实起手，再经过0.18—0.22秒观察；不读取玩家输入、下一动作或背包。观察短促攻击时可能来不及防御。
- 轻击选择短格挡，慢招/高压力选择侧闪；防御间隔1.8—2.2秒。动作已承诺时不能瞬时转防。
- 攻击完整恢复后再留0.25—0.55秒空隙，沿侧面移动，并按实际武器距离调整后撤。体力低先拉开恢复；可用随身水和现存物品，不无限喝水刷新。
- 近处可见同伴正在挥击时，其他近战先侧移；每个角色仍独立支付资源、执行碰撞。只看附近且可见的同阵营同伴，远程不会被强制串成一列。
- 原有视线、最后可见位置、避危险地面、清毒、涂附、喷洒、法阵与施法费用继续生效。

## 少量装备取舍

工头甲新增20%冲击抵抗，同时体力每秒回复-2，保留原减伤/移速代价。绑腿靴使实际闪避费用降低10%，保留原移速加成。效果通过穿戴UID的EquipmentManager贡献读取，对玩家和敌人相同；出售、掉落、强化和读档仍保留原物。装备比较页显示这些数值，平坦恢复值不按百分比估算装备评分。

制造、生存、出售、拆解和训练沿用上一轮基座。本轮用“火石准备—战斗—实物战利品—出售换训练—穿戴后再次交战”验证循环；没有增加大批物品、武器技能数量、属性树或地图任务。后续再依据更多实战设计进阶训练与知识获取条件。

## 验证方法

`test_combat_tactics`验证破防、真实准备取消、墙体击退、精准窗口/手动反击及装备取舍；`test_tactical_ai`验证观察延迟、防御间隔、资源恢复、可见小队走位和收招空隙；`test_tactics_input`以真实右/左键对正常AI验证精准格挡和反击。受控夹具的装备/站位不计作正常预算平衡证据。

`tools/playtests/combat_depth_route.json`供`first30_probe`执行正常新档远征，所有动作通过实际键鼠、导航和UI。工具编组武技也点击K面板；战斗脚本只是测试输入，不进入产品控制器。记录游戏时间、墙钟、受伤、MP、体力、物资和已接受动作。自动化按已知路线执行的时长不代表玩家20—30分钟自然探索。
