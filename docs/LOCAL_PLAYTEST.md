# 灰河谷 · 本地试玩

Windows x86_64：解压后运行EmberPrison.exe。Linux x86_64：解压后运行`./EmberPrison.x86_64`（如缺执行位，先`chmod +x EmberPrison.x86_64`）。二进制与同目录PCK一起保留，不需要编辑器或联网。SOURCE.json标识源码版本；构建副本只关闭编辑器插件。

默认进入灰河谷：一张连续野外，三个独立遗迹内部。WASD移动，左键近战，右键火花，空格闪避，E调查。G打开/关闭地图，J日志，N补给，M本次材料，K编组基础动作，O手动装备，Esc暂停。F5保存当前地点，F9读档。

首次在河谷镇读施法手册、领取离镇口粮。井水、炉灶、篝火、工作台、训练与委托板都需要亲手使用；离镇不会自动吃喝或补货。向北进入林地寻找火阵与档案窖，继续西北可到矿道；向东经过旧驿站与中部断桥。北侧石桥、南侧浅滩始终可通行，不需要修桥或指定消耗品。湖与河流深水不能步行穿越。

组合由真实条件产生：先铭刻火阵，站在阵内再用火花才触发火球。快捷栏保持基础动作，没有组合预案、自动布阵或连招按钮。普通动作保留适配恩赐，Shift请求释放；节律护手提供部分消费。M选择素材，实际适配成功才消耗并清空；取消、失败或不适配保留。离区、死亡、读档清空本次选择，库存不变。

材料制造需要找到对应加工知识，食谱在旅途中学习。镇中米菈需要真正交付食品，完成后开放药圃，并可回委托板报告。采集冷却不会因切区或读档刷新。魔法水面不能直接变成水袋饮用水；井、泉和水源站遵守污染、冻结与导电条件。

敌人橙色扇形是锁向近战前摇，直线是远程提示，圆圈是首领范围预警。侧移和距离可以使攻击落空，冻结仍只是减速。火、水、雷、毒可改变地面；蒸汽减轻投射物直击，危险地面也会伤害玩家。

修复木桥改变真实通路；清理旧驿站后可建设前哨，提供短休和需燃料/实际火源的锅位。档案窖图纸、工区泵芯、矿道调压器用于镇中调和台，部件解封后仍需靠近E取件。排污修复改善湿地水质；实际连通导电启动工区水闸，才能调整水轮并影响以后进入的监狱首领。

菜单撤回镇中需要解除暂停后站定3秒，移动、攻击、施法、受伤可打断；成功不治疗或补货。死亡返镇按现有死亡恢复规则处理。篝火可主动短休/充分休整，粗食保障补给耗尽时仍有重新出发的途径。

灰河谷使用存档3，原监狱验证场使用存档2。暂停菜单可以进入旧验证场，重新启动程序回到灰河谷。存档位于Godot用户目录`Study`，不要删除已有存档；Linux可用XDG_DATA_HOME等变量隔离新试玩目录。

已击败敌人、领取奖励、设施与桥梁永久保存。Esc重置河谷遭遇用于重复试战，不再提供击杀奖励，也不撤销永久成果。G只标出已发现地标；J记录实际阅读与世界变化。详细实测与验证限制见PLAYTEST.md。
