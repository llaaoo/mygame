# 余烬监狱 · 本地试玩

Windows x86_64：解压后运行EmberPrison.exe。Linux x86_64：解压后运行`./EmberPrison.x86_64`（如缺执行位，先`chmod +x EmberPrison.x86_64`）。二进制与同目录PCK必须一起保留；不需要Godot编辑器或联网。SOURCE.json标识构建源码版本。构建在干净的源码副本中仅禁用编辑器插件，运行规则与源码一致。

WASD移动，左键近战，右键火花，空格闪避，E调查。1震荡、2凝神、3霜阵、4水引、5火阵需先探索学习；K仅编组基础动作，O手动装备，M选本次材料，N补给，J日志，Esc菜单。

组合要亲手创造条件：先放火阵，站在阵内再用火花，才产生火球。快捷栏显示基础动作，次级预览说明真实来源和费用。没有组合预案、宏或自动补阵。普通动作保留适配恩赐，Shift请求释放；节律护手可消费剩余时长的一半，另加费用。组合结果不能直接装备。

M材料选择仅下一次实际适配成功后消费并清除；不适配、取消或失败保留。离区、死亡、读档清除选择，库存不变。雷阵等基础动作的必需媒介仍照常消耗。旧自动绑定停止生效。

营地西侧口粮袋只领一次；N主动吃喝，篝火主动休整，返营不补满。现场操作不暂停，移动、攻击、施法、受伤会打断，成功才扣料。菜单返营解除暂停后需站定3秒；实体出口、捷径和死亡返营使用各自规则。

先读营地材料手册，再去外院看火阵记录。档案室与祈堂扩展基础动作；火药库支路通向回廊/机房。每处先观察地面和干燥落脚点：水可洗毒/凝霜，冰可被震荡打碎接回水路，雷沿连通水传播，火与水形成蒸汽、毒可引燃。蒸汽减轻投射物直接命中，自身也受危险地面影响。

敌人橙色扇形是近战前摇，移动到侧后或范围外可躲开；直线提示远程出手方向，圆圈提示首领范围落点。提示期间不追踪，普通冻结只是减速。攻击仍可能落空，不保证命中。

回廊清理后可在入口侧建设检修前哨：炭屑2、谷粮2、站定3秒。提供野外短休和锅位，不送食品、不自动点火；锅旁干柴可用火花点燃，但自己不要站入火面。排污泵另行修复可改善水质。调和台任务仍是读图纸、解封、现场取件、回营组装。

J只列已发现补给与建设、已到达区域捷径及解封未取部件。实验页的四个名称只是记录标签，不会应用任何配置或执行动作。已清区域可用Esc试战，耗材照常消耗，击杀不再发奖励，永久进度保留。

存档在Godot的用户数据目录`Study`中，与编辑器运行共用相同应用名；如要独立新档，可先备份原存档或使用独立系统账户。不要删除自己的原档。Linux可通过XDG_DATA_HOME等变量隔离试玩目录。

当前为首章原型。Windows包已检查PE/PCK结构，尚需Windows设备实机运行；Linux包已做导出后启动检查。20—30分钟为首次探索目标，熟悉路线的输入辅助试玩不能替代首次玩家耗时。详细实测、资源收支与已知问题见源码docs/FIELD_CHAPTER_PLAYTEST.md。
