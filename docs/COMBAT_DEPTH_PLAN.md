# 战斗纵深与远征闭环：本轮实施

2026-11-07 UTC。承接系统深化后的建议，优先完成武器手感与战术AI，并用已有物资/装备/学习循环验证用途。

- 四种武技各有用途：刀提高正面格挡压力；矛命中可打断准备；杖未被挡住时击退且受墙体阻挡；弓技命中打断，保持实物箭与MP隔离。
- 精准格挡有短窗口和重新尝试间隔；成功只授予下一次玩家手动近战的限时反击机会，不自动攻击。保留普通持盾防御与真实体力成本。
- 命中效果继续走report_hit，扩展单次命中上下文携带不可变物理动作定义。格挡/闪避/无敌拒绝的命中不得推人或打断；死亡、离区、菜单和存档不恢复临时反击/位移状态。
- 武器姿态和轨迹读取实际动作阶段、朝向和穿戴；起手、攻击、恢复可区分，表现范围与接触一致。无全球暂停或命中停时。
- AI具有Resource定义的观察延迟、防御间隔、短防御承诺和攻击后的空隙；低体力先恢复。追击、控制距离、法术准备和小队轮换使用可见局面，不读取输入或免费生成物资。
- 装备做少量实际取舍：工头甲抵抗冲击但减慢体力恢复，绑腿靴降低闪避体力。继续保留实际UID和掉落。
- 内容沿用地图、敌人、资源和预算。正常AI走一条整备—北路交战—拾取—返镇交易/学习的可重复路线，记录游戏时间、墙钟、受伤、MP、体力与材料；自动化用时不能代表玩家20—30分钟自然探索。
- 先有意义的领域/真实输入回归，再原生云端图形与正常预算战斗。代码稳定后提交归档首次导入/全量测试，推送PR并合并，Actions保持停用。

Godot4.6的Node alternatives与Scene organization继续适用：Resource只描述规则，RefCounted保存AI观察状态，Node负责物理/绘制；不增加第二套伤害、物品或技能栏框架。
