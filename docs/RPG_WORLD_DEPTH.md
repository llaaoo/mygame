# 灰河谷：角色、远征与世界回应深化

本轮承接《上古卷轴5》《物质世界》与《哥特王朝》对照审查。目标是把知识、战斗、旅程、经济和社会后果接成可验证的灰河谷旅程。现有真实UID、库存事务、区域生命周期、共同战斗与存档模块保持权威。

设计继续遵循Godot 4.6官方场景组织和节点替代建议：
- https://github.com/godotengine/godot-docs/blob/4.6/tutorials/best_practices/scene_organization.rst
- https://github.com/godotengine/godot-docs/blob/4.6/tutorials/best_practices/node_alternatives.rst

## 实施顺序和验收

1. 知识与成长：专业剥取进入实践成长；通用条件覆盖动作、组合、武技、专业知识和Perk，对话/课程/任务复用；保持原所有者与旧条件语义。
2. 敌人与遭遇：可观察的领地警告、警戒传播与最后见到的位置，小队前后排职责和失去优势后的退守；预警、来源、费用和范围必须真实，不能共享玩家实时隐蔽坐标。
3. 远征与失败：返程有明确游戏时间/补给选择，保持可中断准备及无物资时的恢复路径；失败留下可恢复的行囊回收处境，不重复处罚、生成资源或改变旧原型规则。
4. 狩猎与经济：多处有限狩猎机会、知识条件委托、实际商人需求与有限供给，原料加工形成持续用途；物资、钱袋与加工仍走共同库存。
5. 角色与社会：少量可选择的身份、身份权限与实际战斗/远征用途；私有容器、目击警告、真实物品追回/赔偿与和解形成完整案例，存档与角色死亡可持续。
6. 任务与探索：同一目标有知识/交涉/环境/战斗等可验证途径，成果影响服务、路线或关系；知识/身份与NPC日程联动，不复制任务进度。
7. 表现和验收：警戒、威胁、作业与返程费用可读；真实键鼠、正常AI、库存/事件失败边界、历史档和冷重进；提交归档首次导入及完整回归；Actions保持停用。

天气、追随者、完整潜行开锁和大型社会模拟沿用审查中的后置安排。本轮以已有灰河谷空间和类型化内容完成上述闭环，不声称达到参照作品的全部规模、美术或长期平衡水平。实际结果和限制在完成后补记。

## 当前实现与所有者

| 能力 | 唯一状态所有者 | 定义与组合入口 |
| --- | --- | --- |
| 已学知识 | 原Progress、MartialArts、FieldcraftKnowledge、SkillMasteryManager各持有自己的知识 | `ConditionQuery.knows`只查询；基础操作复用SkillManager的旧技能映射/实际知识判定，组合读取原已学规则，WorldCondition区分动作/组合/武技/专业/Perk，不复制已学表 |
| 狩猎实践 | FieldcraftKnowledge的原部位UID收据 | 实际`corpse_harvested`事实进入原成长入口；同UID跨读档不重复加经验 |
| 领地与协同 | 每个活敌人的EnemyAwareness；当前区域的弱引用EncounterCoordinator | EncounterData.tactics可编辑Resource。沿用原角色，不复制角色模板；最后目击点、警告、搜索均为瞬态 |
| 身份 | RelationService.affiliations | 两种一次性互斥誓约；与战斗阵营分离。CharterDefinition配置前提、武技和描述；箱子的affiliation_id配置权限 |
| 物品与归属 | InventoryService的真实容器、UID和实例属性 | LawService只记纠纷、目击、赔款与收据，不持有第二套库存。转移时先赋归属标记再计算合堆/容量 |
| 返程与败退 | 原持久时钟、需求、库存；ExpeditionState只记待完成救援 | ExpeditionRules配置距离/时间报价和救援代价；FieldWork承担可中断准备；跳时复用休息时钟与加工，不推进物理位移 |
| 差事与加工 | 原NpcConversationService、ProductionService | 同一差事最多三批，间隔六游戏小时；原提供者有限钱袋付款，原料加工后仍归店家 |
| 整修 | 实际装备UID的upgrade_path/upgrade_level | 四个EquipmentRefit Resource，第一次整修固定方向；装备投影与共同战斗消费实际数值，不修改共享装备定义 |

新增`law`、`expedition`保存模块；fieldcraft的实践收据、relations的身份和conversations的周期收据为可选默认字段，封装版本保持不变。旧档不会自动学会知识、加入身份或生成剥取成果。新增固定箱子只在容器不存在时初始化，既有空箱、钱袋、尸体与待回收背包均不补货。

## 灰河谷可玩的闭环

1. 在镇中读“猎路与供给”，进作坊领取有限入门书和小刀；书需要真实使用，训练师提供取牙、摘腺的进阶课程。
2. 西北山脊有三只额外猎犬，湿地有三只额外伏兽；前两只山脊猎犬同群。警告圈内先给2.5秒撤离机会，进入95范围或主动攻击引发防卫；同群且360范围内、互相可见的同伴收到过去位置。遮挡后按最后目击点搜索，六秒后结束，不读取遮挡后的实时玩家位置。
3. 山脊小营地新增重杖与弓手组合。前排只有在弓手活着、可见、仍持弓且口袋有箭时保护射线前方；弹药耗尽或同伴死亡后回到原共用战斗决策。不是新增无限援军/免费箭矢。
4. 兽皮/牙/腺是有限专业产物。兽皮、毒腺可交知识门槛的供给差事，或出售；兽皮/牙/腺接入原三种制造，也可给店家供料后排产。售价的缺货加价只补到店内真实目标库存，批量总价逐项覆盖需求，不对整叠重复加价；买价高于可获得的出售加价。
5. 亲手剥皮至少一次可在训练师处加入猎队，获得“逐退箭”和猎队实物箱权限；处理断桥纠纷并学会破势斩可选守路队，获得“驱逐斩”和对应箱权限。本旅程二选一，不改变敌我战斗阵营。武技仍需弓/实箭或刀剑；K把新路线放进原每组合最多两招的配装，Ctrl切换。
6. “巡林取证”可凭两次剥皮、两次摘腺，或处理山脊营地来报告；后两种方式分别增加艾妲或商人的个人信任。报告只能结算一次，后续补齐其他方式不再领奖。
7. 装备原平衡强化保留；武器可选压制型（冲击更高、体力费更高、耗兽牙），护具可选稳固型（抗冲击、移速下降、耗兽皮）或轻装型（闪避更省、生命较低、耗布料）。方向第一次确定；拆解仍回收有限碎料，保留原抹布涂层/UID契约。
8. 远离威胁及有害状态后，Esc选择现场返镇，再选择备粮返程或两倍时间的徒步求援。准备3/5秒不是行程时间；完成才消耗实物并推进世界小时。前者吃喝一至两份，后者无需额外物资但疲劳+25；没有休息的固定治疗，原本的自然回复仍可进行。
9. 野外败退留下原旅行背包，口袋与穿戴保留，M显示待回收点；救援推进两小时。不在读档后生成新背包；死亡界面退出后，待救援记录在重新进入时只结算一次，不能通过退出规避代价。镇内/安全室内不加野外救援费用。
10. 萨芙摊旁的封存货箱明确属于他人。只有260范围内的活服务NPC、同时看到取用者及货源才通报；未被看见仍保留实物归属。被通报后物主暂停服务，训练师誓约要求结清纠纷；再次当面擅取会被阻止，并尝试追回可归还实物。与物主、艾妲或公署调解台处理：完整原物归还或真实赔偿，结清不自动恢复信任。带标记物不能出售、拆解、强化或作为通用配方付款洗白。
11. 已接受的兽皮/毒腺差事提供者死亡后，可由登记的艾妲在实际当值、附近且安全时代办；支付仍来自原死者遗产，取走遗产中的钱会令委托缺款。生产者死亡仍取消排产，不复活、转移或补齐钱袋。

## 扩展边界

- 新遭遇在EncounterData上配置tactics/group；同生物继续引用同一个角色Resource，警戒状态不能写回定义或存档。当前只处理玩家入侵与同组观察，不声称包含完整声音感知/隐蔽数值/全城报警。
- 新身份增加CharterDefinition、目录登记、条件、实际可学武技与权限容器；不是另建职业点数或第二棵Perk树。当前只有两个灰河谷案例，原Perk基座保持可扩充。
- 新供给差事配置repeat_hours/maximum_deliveries/conditions/successor_actor_id，仍需原NPC真实库存、当值和交付。不是无限经济模拟；商人不会自动补款。
- 私产需显式配置allow_theft/access_actor_id；默认私有箱仍拒绝拿取，不把全地图公共物资改成赃物。此轮没有守卫追捕、监狱、全城赏金、开锁或完整潜行。
- 强化方向由EquipmentRefit目录及实际数值消费者决定。新增效果先接执行器与说明，再登记资源；不允许只有文案加成。
- MVP任务展示多条已实现条件路线；没有新增通用任务脚本语言、无限程序化委托或大量新地牢。天气、追随者、完整潜行开锁和大规模内容继续后置。
