# 章节试玩复核：组合收益、探索回报与操作反馈

2026-11-05。基线：`main`，`4dbac0c`。本轮范围为试玩复核与文档，没有调整玩法代码、数值或内容。

后续处理状态与验证见[试玩问题迭代](./PLAYTEST_FIXES.md)；以下保留当时的复现结果。

## 结论

九区域探索、学习、机关、装备、委托、死亡、通关与保存恢复已经连通。本轮最需要迭代的是组合的投入回报、捷径的实际用途，以及施法前后的解释。继续扩充内容可以复用当前系统，但应先处理下述问题，否则新增组合仍容易被普通近战替代。

## 试玩方法与边界

- 使用隔离的新存档，从100 HP / 60 MP、四项属性10开始；自然获取经验、动作、材料和装备，没有分配属性点，没有提高角色上限。
- 通过真实操作系统键鼠输入驱动正常游戏窗口；部分导航与点击由输入脚本辅助。敌人主动AI、碰撞、冷却、回复、掉落、施法准备和资源扣除保持正常。观察脚本只记录状态、实际施法、实际伤害、死亡和截图，不注入战斗结果。
- 先后使用守阵者指环、节律护手，费用按当时实际装备记录；其他装备获得后未装备。
- 走过全部9个区域，清理全部普通遭遇及冷却水路分支的首领，经历1次首领战死亡，完成通关出口与返营；没有重置遭遇来提高属性或重复领取补给。
- 多次暂停用于查看画面和记录。因此下文短战斗样本只能说明该输入方式能取得这些结果，不能当作真人首次通关时长、熟练度或构筑平衡排名。没有完成四套配置各一次整章通关。
- 使用软件渲染与Dummy音频；本轮不评价目标硬件帧率和音效。直线输入被可见障碍挡住时绕行，不把辅助导航失败记为游戏软锁。

## 需要优先处理的问题

### 1. P1：免费战斗返营削弱了三条机关捷径的回报

**实际复现**：在回响礼堂与3名存活敌人交战，受伤至43 HP，暂停菜单的“返回营地”仍可用。点击后立即回到100 HP / 60 MP，已获知识与发现保留，没有额外撤退费用。

档案室与蓄水机房的新检修捷径也能正常使用，但营地没有与这三条新增机关捷径对应的返场入口。当前营地已有的机房入口来自旧水路选择，属于另一条链路。新机关奖励的单向返营能力与暂停菜单重叠。

**建议**：优先让三条检修捷径在营地生成对应的返场入口，让解锁直接缩短后续实验和回访路程。战斗返营是否需要脱战或可打断准备，应与希望保留的便利程度一起决定。

相关实现：[暂停菜单](../gameplay/exploration/expedition_ui.gd)、[角色恢复](../gameplay/exploration/exploration_progress_service.gd)、[区域与捷径](../gameplay/exploration/mvp_game.gd)。

### 2. P1：普通近战的快速兑现压过了不少组合投入

**实际样本**：

| 遭遇 | 实际操作与结果 | 限制 |
|---|---|---|
| 外院两名35 HP近战 | 近战输入约4.58秒完成，累计受到9点伤害，未花MP | 包含追击与点击；不是首次玩家平均用时 |
| 火药库两名敌人 | 普通近战约5.32秒完成，累计受到14点伤害，结束86 HP / 60 MP | 击杀回复与自然回复正常 |
| 排水回廊两名30 HP敌人 | 先放一次凝霜水引，再各用一次有效30伤近战收尾 | 远程攻击和地面仍会伤到玩家；冻结并非硬控 |
| 冷却后的210 HP首领 | 满血重试，普通凝神后近战约5.19秒完成；7次有效30伤，承受4次15伤，剩40 HP | 未用伤害恩赐、药剂或闪避；未测试未冷却的280 HP版本 |

首领第一次残血尝试确实失败了，贴身施法也会被打断。不过，在同一冷却分支满血重试时，持续近战就能快速结束战斗。组合需要准备、MP、材料、站位，有时还承担自伤；普通敌人却常在1—2次近战内死亡，留给冻结、掩护和导电的发挥时间很短。

**建议**：先用同一遭遇、同一血量与装备对比近战和组合，校准普通攻击伤害、攻击承诺时间、敌人受压窗口与掉落恢复。调整现有遭遇的远近站位和进攻间隔，让控制能拆开追击、蒸汽能创造接近窗口、导电能处理成组目标。普通施法与近战仍应有稳定用途。

相关实现：[近战命中](../entities/components/combat_component.gd)、[敌人及掉落](../entities/enemy/enemy.gd)、[关隘配置](../content/exploration/gate.tres)、[首领配置](../content/exploration/boss.tres)。

### 3. P2：瞄准其他动作时，主要预览仍显示火花

**实际复现**：按住水引键并移动落点，地面出现水引范围，底部醒目预览仍为“火花→火花·4 MP”；装备后也出现相应火花费用。快捷槽的小数字和材料详情可以显示其他费用，但主要提示没有跟随当前瞄准动作。

代码中主要提示默认查询`ignite`，只有已进入准备的`pending`才替换动作。因此地面瞄准阶段尤其容易误导。

**建议**：将正在瞄准的动作、目标位置与Shift意图提供给技能栏；准备阶段继续使用实际施法计划。让主要提示回答当前这次操作的结果、费用、材料与阻止原因。

相关实现：[技能栏](../ui/skill_bar.gd)、[施法输入](../entities/player/components/player_input_controller.gd)。

### 4. P2：节律护手比较页显示未替换的费用占位符

**实际复现**：获得护手后，在营地O装备页查看详情。预计变化显示“每份再加%d MP”，同时日志记录：

```text
ERROR: String formatting error: unsupported format character.
build_summary (res://gameplay/exploration/expedition_equipment.gd:113)
```

**原因**：带格式化参数的字符串同时包含未转义的`50%`，使费用格式化失败。护手可以装备，部分消费也实际生效，问题在说明生成。

**建议**：修正百分号格式化，并增加一项面向最终显示文本的检查，确认额外费用为3 MP且不残留占位符。

相关实现：[装备说明](../gameplay/exploration/expedition_equipment.gd)。

### 5. P2：法阵耗尽后，远程结果退回近身火花的提示偏弱

**实际复现**：回响礼堂布火阵，连续右键攻击远处敌人。实际提交记录依次为：火阵9 MP、火球14 MP、火球14 MP、火花5 MP、火花5 MP。后两次已经无法攻击原来的远处目标，仍正常扣费。

火花回退符合当前组合规则，问题是形态和射程突然变化时主要依赖较小的文字变化。玩家容易把失败理解为没有瞄准、输入没成功或法术失效。

**建议**：充能耗尽时给一次清楚的短提示，并立即更新有效范围与结果图标。保持基础火花可用，避免重复操作时无意中消耗MP。

相关实现：[条件施法](../gameplay/abilities/combinations/conditional_cast_controller.gd)、[技能栏](../ui/skill_bar.gd)。

### 6. P2：学习说明集中，实际验证与回访机会偏弱

第一次材料手册就解释了多种介质、材料制造、Shift、装备借阵与以后才学会的凝神。后续毒理记录又集中解释毒雾、孢子、毒性冰霜、材料顺序、毒契和护手。内容正确，但早期难以把阅读内容对应到一两次明确操作。

实际回访时，已清区域没有敌人、机关已经锁定完成；新能力主要用于空场实验。暂停菜单可以重置遭遇，但会重置整轮清场进度，回访的局部试验不够方便。

**建议**：把每次首次阅读的主要提示收束为一条当场可试的规律，完整说明保留在日志。给现有试验区提供可重复、无奖励的目标或局部遭遇重试，让新学知识能立刻比较“保留、完整消费、部分消费”，同时保留已有知识、机关和领取状态。

相关内容：[营地](../content/exploration/camp.tres)、[回廊](../content/exploration/drain.tres)、[机房](../content/exploration/cistern.tres)。

### 7. P3：已通关存档冷启动仍显示完整新手开场

保存、结束进程并重新启动后，知识、材料、装备编组、清场和领取标记都正确恢复，但仍弹出“先读营地手册，再去外院学习火阵”的初始说明。对已经完成这些内容的存档，这个入口没有指出当前可以回访或试验什么。

**建议**：按进度区分首次说明与继续游戏提示，展示未交付委托、可回访地点或试验入口。

蒸汽投射物减伤数值、所有免疫边界、所有机关替代解法、四件装备全部组合和旧房间模式没有在本轮逐项实机重测。上一实施轮36项自动化回归通过是基线证据，本轮没有修改逻辑，也没有用那组结果替代实际试玩。

## 建议的下一轮顺序

1. 修正当前动作预览与护手费用说明，补充法阵耗尽反馈。先让玩家可靠理解每次操作。
2. 为三条新增捷径补充营地返场用途，让机关成果改变实际路线。
3. 在现有敌人和区域中校准近战、准备与组合的风险收益；优先复测满血冷却首领和30 HP追猎者。
4. 收束首次教学，加入不重复发奖的局部试验方式，再比较四种战术的实际成本和完成表现。
