# 灰河谷首次远征闭环

2026-11-11，北京时间。目标是在现有基座上形成一次可重复验证的完整冒险；30–45分钟是包含首次阅读、探索、整备和返程的设计目标，不是脚本辅助操作或真人通关的已验收时长。

## 玩家路线

手册介绍“首次出征：林下档案窖”。在J的委托记录手动追踪，领取一次性口粮、按实际配方制作火石，再从北路西侧阅读火阵笔记。亲手选择火石阵、布阵、用火花组合后，搜取敌人的实际装备；可先返镇整备，也可继续前往山脚档案窖。

档案窖的西侧书架提供初始整备掩体，南北两路有不同接敌位置，东侧书架可分割射界。敌人的行动、装备与剩余物资继续使用共同角色规则。东北压印台提供水引→震荡与布料现场作业两种办法，完成后开放搬运竖井；原西侧出口始终无耗材可退。名册仍沿用原有安全调查条件。具体地图接口见[档案窖](ARCHIVE_ADVENTURE.md)。

带名册与机关成果回镇报告可获得一次1属性点。多余战利品可出售或拆解，再加工耗材、安排下一次远征；这些操作继续走InventoryService，不增加冒险专用货币、奖励池或第二份库存。任务只检查实际探索事实，不强迫使用火阵、出售特定装备或消耗指定瓶；制作、组合、交易与余量由独立验收记录证明。

## 系统衔接与约束

- 新任务由不可变Resource定义，手册解锁，进度仍归ExplorationProgress；已有旅程可接入，不重置旧知识或发现。
- 敌人观察读取本遭遇EnemyAwareness.rules，领地警告展示同份对策说明。标签受距离与视线门控，F仍为原近距离交互；界面与警告不会停止AI。
- 共用档案返程落点与初始敌岗保持声明的安全间距，两个返门引用同一MapArrival；不能为新门另写绕过规则的传送逻辑。
- 现有三敌、六记录、装备和素材预算保留；新增机关无物资奖励，新增首远征委托仅1属性点。旧地图预算fixture保留并精确比较已有内容。

## 验收方式

[真实输入路线](../tools/playtests/grayriver_adventure_loop.json)用导航方向发WASD、指定测试目标瞄准，再发送实际键鼠。它不是游戏中的自动战斗功能，也不是自然发现或真人手感验收。正常AI、新档、默认物资与真实成本必须保留；位置/知识/材料夹具只用于另行声明的集成边界检查。

每段记录敌人、战斗用时、受伤、实际施法/物理动作、耗材和MP；核对战利品UID经过搜刮、穿戴、出售、制作后的归属。F5生成存档后退出整个进程，再以同一隔离数据目录启动，核对装备、机关、报告、防重、瓶UID与剩余剂量。

最终执行与限制以[本轮验证报告](playtests/adventure-loop/REPORT.md)为准，完整回归结束前不宣称通过。手柄支持暂缓，GitHub Actions保持停用。
