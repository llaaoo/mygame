# 首次远征：普通人的准备与成长

目标是支撑新角色首小时的流程，不以辅助运行时间证明一小时内容量。复用真实库存、现有任务/人情、武技、制造和成长系统，没有新增教程进度、平行钱包或强制觉醒条件。

- 入场可选择“查看出发清单”；Tab准备清单首项为“首次远征 · 整备与成长”。HUD在镇中提示缺少的关键准备；已有自定路标和其他委托优先。
- 清单查询当前穿戴、可携食水、检修布料、实际学会的武技、已交付报告与未花成长点。消耗后会重新提示；不是做过一次就永久打勾。面板在世界继续运行时更新现有标签，不重建悬停按钮。
- 知道课程不等于学会。破势斩仍需当面向当值训练师支付8币，不耗MP，学会后用K核对连招。可先用萨芙原有的炭屑2换8币差事，或艾妲草药2换6币加客栈谷物1换2币。玩家可以保留材料，直接以普攻探索。
- 新增客栈差事仅一次；谷物进入苇娘真实库存，2币取自客栈原有16币钱袋，不增加货币预算。日程、空间、危险、当面距离及防重复交付仍由原服务复验。
- 先从西侧读猎营记录，在安全处准备，档案窖可以撤退分段推进。布料1手工压印与取得名册即可交付，旧试感台仍为可选内容。
- 首次出征沿用原有1属性点，报告记录下一步整备建议；P分配实际点数，K核对武技。多余装备要比较后再售卖、拆解或强化，补给和休息消费真实物资，之后由玩家在J选择下一条委托。

FirstExpeditionGuide只是章节查询投影，由FrontierGuidance装配。它不消费物资、不学习技能、不领奖或持久化额外状态。界面只打开原有操作页面，地图标记跨区域时先指向当前区域的出口；不会传送、远程交易或提前揭示未探索的遗迹。

ExplorationQuestData.completion_hint是可选作者文案，记录在实际报告中，已完成任务详情也可显示；不更改存档版本或重发旧任务奖励。新增人情话题通过原NPC记录保存。

验证记录在本轮playtests目录归档；受控固定位置/AI的费用和持久化集成测试，与正常AI原生输入复测分别描述，不能相互冒充。
