# 武器附魔与武技释放：实施计划

2026-11-08 UTC。扩展已有火抹布、毒抹布与四种武技，不新增独立元素武技或组合宏。

- 抹布仍是实际物品操作，完成后给具体武器UID涂附60秒，新涂层替换旧涂层。普通攻击/实物箭附加对应元素伤害，合格命中积累异常，达到阈值才施加已有燃烧/中毒；已生效状态不靠普通附魔无限刷新。
- Shift+已绑定武技键显式请求释放附魔，不改变普通武技。招式起手可中断，实际挥出/离弦才消耗整层选定附魔；拒绝、缺箭、来源失效或起手中断不能偷扣，也不偷偷降级成普通招式。
- 四种现有武技提供短扇斩、窄束刺、前进横扫波、箭矢命中扩散四种几何形态，同一形态读取火/毒Resource。火波点燃实际油面，毒波积累毒素；仍有墙体、闪避、格挡、同次命中防重及真实体力/箭矢成本，不花MP。
- 库存服务独占涂层及箭矢提交，角色动作保存单次来源快照；战斗执行器结算附加伤害，BuffManager持有目标异常积累，状态与表面系统继续复用。积累衰减、存档/跨区时间与免疫有明确规则。
- UI显示具体武器附魔、剩余时长和强化武技用途；真实键鼠验证Shift采样、波形/墙体、来源中断、效果与消耗，并做实际保存重进、正常AI样本、提交归档首次导入/全量回归。按AGENTS提交、推送、PR合并，Actions保持停用。

沿用Godot4.6官方Node alternatives/Scene organization：可编辑定义使用Resource，目标积累为角色持有RefCounted，区域波形为Node2D；不引入第二套伤害、库存、快捷栏或状态框架。
