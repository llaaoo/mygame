# 实时选材与行囊架构

2026-11-07。本轮解决战斗频繁进配置页、看不清穿戴、满包无法清理及界面暂停世界的问题。沿用地图、敌人、配方和成本，不新增技能宏或自动准备。当前键表见[操作方案](CONTROL_SCHEME.md)。

## 玩家流程

- 按住中键，按动作快捷键选槽，鼠标划向介质后松中键确认；M提供点击式替代。选材不会施法，之后按原快捷键执行。轮盘期间可移动、格挡、闪避，闪避取消轮盘。瞄准方向固定为打开时方向，避免选材鼠标改变防御方向。
- 同类喷剂共占一个稳定扇区，悬停滚轮切换具体瓶，显示瓶号、余剂与费用。不可用来源留在原位，丢失实物不自动换瓶；无材料类型只能明确选择。
- 火花、震荡、水引可选择适配的可选修饰；铭刻等操作选择主介质，保留相容的独立修饰。两个同动作槽可固定不同来源。
- I/O/N打开同一行囊，分别聚焦全部、装备、补给。身体九槽读取实际穿戴，单击部位筛选装备；双击使用/换装、右键菜单、拖拽穿戴，详情可比较、数量转移、拆分和绑定快捷槽。
- 丢弃一件、所选数量、整叠或拖到明确丢弃区生成真实物资袋，F靠近取回。满包可交换装备、直接丢弃已穿戴物；收纳失败则留在原处。
- 所有当前战役菜单都不暂停或减速。完整菜单接管输入但后摇、受击、状态、生存和AI继续；受伤显示告警，死亡/离区清理界面。锁定提示不能被其他快捷菜单绕过。

## 所有者与请求边界

| 组件 | 职责 | 不持有 |
|---|---|---|
| `QuickslotLoadout` | 唯一绑定、来源、版本与保存状态；改来源保留原SkillInstance和升级 | 全局临时来源的第二份权威 |
| `QuickslotMaterials`（RefCounted） | 已掌握操作、费用、口袋实物、相容修饰的只读查询及显式选材 | 库存扣款或效果执行 |
| `MaterialWheel`（CanvasLayer） | 同一查询的扇区/瓶切换、目标槽与输入生命周期 | 材料库存、冷却或自动连招 |
| `ActorInventoryScreen` / `PaperDollView` / `InventoryItemTile` | 实物网格、身体预览、拖拽与数量输入 | 可战斗的预览角色、模板赠送装备 |
| `InventoryActions`（RefCounted） | 显式注入角色、Session、权限/换装/保存请求；重验范围与所有权 | 对GrayriverGame类的依赖或独立容器 |
| `InventoryService` | UID、容器、穿戴、拆并、丢弃与转移的唯一写入边界 | 可被UI任意改写的投影库存 |
| `CampaignSession` / `GroundItems` | 活动区域真实cache的挂载和F交互；离区卸载节点 | 节点内部复制的战利品清单 |

K、轮盘和背包选瓶都写同一槽位。旧Workshop配置入口转到轮盘，未编组则转K预选动作；旧全局材料方法保留原型/AI适配。施法仍走CastPlan、重校验和原事务，共享动作冷却不因换槽或换料重置。

## 实时输入与生命周期

`GameUIStyle.begin_modal/end_modal`只协调界面所有权和`ui_blocked`，不写`SceneTree.paused`。玩家动作控制器在输入被接管时仍`advance(delta)`，清除新输入但保留已承诺的攻击与恢复。选材打开取消未提交蓄力、喷洒或物品准备，已付脉冲不退；确认仅改槽来源。快捷输入压制旧按住/松键，同时保留确认后同帧真正的新按键，关闭点击不穿透成攻击。焦点丢失也取消输入；嵌入式子窗口使右键菜单/下拉仍遵守同一GUI焦点。

旧房间模式的显式暂停与测试引擎暂停保留；不能用PROCESS_ALWAYS补跑一个被全局暂停的物理世界。设计参照Godot 4.6官方[暂停与处理模式](https://docs.godotengine.org/en/4.6/tutorials/scripting/pausing_games.html)及[场景组织](https://docs.godotengine.org/en/4.6/tutorials/best_practices/scene_organization.html)：空间表现用Node、运行值/服务用RefCounted、依赖在组合根注入。

## 持久化与失败

沿用旅程v7与库存schema1，基础动作可保存显式修饰；现有迁移继续生效。落地物以`ground.*` cache保存区域和有限坐标；整件装备/瓶转移保留UID，部分材料拆分分配新UID，同属性合并守恒。剂量与涂层绝对期限不重置；离区卸载投影，返回再挂载。容量不足、旧UID、无效数量、超距、已放下背包均拒绝或仅取可携带部分，余物留在来源。每次成功请求走已有保存队列。
