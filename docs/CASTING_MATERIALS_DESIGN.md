# 法术联动、施法材料与世界交互

> 2026-11-04：当前实装15条条件配方、7种施法成品、7项加工配方和6处法术机关。包括法阵、施法者准备状态、目标状态与地面反应。

## 当前施法结构

基础动作、条件配方、最终效果、素材修正依次解析，仍由既有 SkillManager / SkillExecutor / CombatExecutor 执行。组合结果不能直接装备。探索入口的火、霜、雷三类法阵可以并存，每类最多一个，同类重建更新；默认持续15秒、两次触发。相容结果一起响应，总费用相加；具体设计动机见 [Outward参考复盘](./OUTWARD_INTERACTION_REVIEW.md)。

| 法阵 | 火花 | 震荡 | 凝神 |
|---|---|---|---|
| 火阵 | 火球，12 MP | 火阵喷发，14 MP | 余烬战意，10 MP |
| 霜阵 | 寒霜弹，10 MP | 寒霜新星，12 MP | 霜行，10 MP |
| 雷阵 | 雷矢，11 MP | 雷环，13 MP | 雷息，10 MP |

各组合另消耗一次法阵触发。火/霜铭刻各8 MP；雷阵9 MP且需要雷晶粉1。雷阵在蓄水机房的清场记录中学习，需用K编入快捷槽。雷矢会连锁附近最多3个敌人；雷息持续9秒，移速+15%，并强化后续雷矢/雷环。

水引在营地手册中学习：5 MP，在瞄准方向前方120距离创造半径105的水域，持续12秒，无直接伤害；默认安排到空闲的4号槽。泼洒树脂同处学习：2 MP和树脂制剂1，创造同尺寸油面，需在K中编组。

## 回响与连续准备

静默祈堂清场后的“回响刻板”教授回响铭印、五条支援/攻击配方；排水回廊清场后的“毒理记录”教授毒雾及孢子配方。两个动作需要在K中编组。新记录分别提供初始墨、粉和萃取，旧存档也可直接探索取得。

回响铭印消耗6 MP和回响墨1，赋予12秒一次性印记。印记随施法者移动，成功转化才消费，不占用或替换法阵。自身会显示印记/护盾与剩余时间。

| 准备状态 + 后续动作 | 结果与本次费用 |
|---|---|
| 回响印记 + 火花 | 回响三重矢，三发奥术飞矢；12 MP |
| 回响印记 + 震荡 | 回响脉冲，自身周围115半径、最多三次命中；14 MP |
| 回响印记 + 凝神 | 共鸣护盾，8秒承受伤害降低40%；10 MP |
| 回响印记 + 水引 | 回响复苏，每秒恢复6点生命共4次，至多24点；9 MP，替代本次铺水 |
| 回响印记 + 毒雾 | 腐蚀孢子，穿透两次并留下毒区；12 MP及毒性萃取1，替代本次铺雾 |
| 共鸣护盾 + Shift＋震荡 | 守护爆破，消耗护盾，周围135半径范围攻击；8 MP |

上述状态配方本身消费对应准备状态；与相容法阵同时匹配时，两类结果共同产生，分别消费准备状态与对应法阵次数，总法力和适配素材相加。回响脉冲持续1.45秒，间隔0.55秒，Body和Hurtbox不会重复计数。护盾与其他凝神增益互斥，回响复苏与印记可独立存在。

同一状态作用域内，显式Shift释放时守护爆破优先级40，回响转化30；同级按稳定ID排序。因此护盾和印记同时存在时，Shift＋震荡先消费护盾，印记留给下一次动作；普通震荡按其他适配配方执行，保留护盾。每个圈独立匹配法阵配方，相容结果不被状态配方覆盖。互斥增益按优先级选择一个，同级取后布的圈，只为保留结果付费。技能槽悬停显示本次全部结果与总费用。

准备中状态过期、被移除、同ID被刷新/替换时都会取消，不降成普通动作，也不误扣法力或额外素材。已成功施放的回响铭印，其墨不会因之后放弃转化返还。离开区域、死亡返营和读档会清理这些临时准备。

## 恩赐的保留与兑现

余烬战意、霜行可在普通适配施法时保留并增加20%伤害；雷息保留已有35%雷击命中增益。按住Shift施放适配伤害动作，消费恩赐换取更高伤害与燃区/穿透/散射/范围形态，额外3 MP，随后失去原持续收益。共鸣护盾也可选择保留防御或Shift＋震荡主动消费。细节、材料叠加与回滚见 [Buff依赖与兑现](./BUFF_CASTING_DESIGN.md)。

## 法术之间的联动

| 顺序与条件 | 当前结果 |
|---|---|
| 水引 → 寒霜弹/寒霜新星 | 对潮湿目标额外30%伤害，消耗潮湿，施加冻结减速 |
| 冰霜 → 火球 | 对冻结目标额外60%伤害，移除冻结 |
| 水引 → 火球 | 对潮湿目标额外30%伤害，移除潮湿 |
| 水引 → 雷矢/雷环 | 对潮湿目标额外45%伤害 |
| 雷息 → 雷矢/雷环 | 雷息存在时额外35%伤害，可与潮湿联动 |
| 毒雾/毒性冰霜 → 火球 | 对中毒目标额外75%伤害，消费中毒，可与融化共同触发 |

这些规则由既有 SkillSynergyData / SkillSynergyResolver 配置和解析；额外伤害继续通过 CombatExecutor 的无递归额外伤害入口。该首版未引入任意法术拼接编辑器，支持的顺序和条件以上表为准。

角色状态与地面状态分开处理：目标潮湿决定命中联动，脚下水域决定后续地面变化。水引或冰霜命中可以移除燃烧状态；水引还能解除中毒。

同一次命中的反应额外伤害与主伤害通过CombatExecutor完整结算；同一动作共同产生的效果共享来源标识，能够共同作用于真实生命。其他独立命中仍受无敌时间保护。护盾减伤在HealthComponent统一应用，持续伤害也受影响。

| 地面条件 + 法术 | 当前变化 |
|---|---|
| 水域 + 冰霜 | 冻结5秒，踏入施加减速 |

| 水域 + 火焰 | 蒸汽3秒，踏入短暂减速 |
| 油面 + 火焰 | 燃烧8秒，沿原有传播规则反应 |
| 冰面 + 火焰 | 融化成5秒水域 |
| 带电水面 + 冰霜 | 冻结4秒 |
| 燃烧地面 + 水引 | 水域取代火焰；向燃烧区泼树脂会维持燃烧 |
| 毒区 + 水引 | 水域取代毒区，同时清理踏入者的中毒 |

| 毒区 + 冰霜 | 冻结4秒 |
| 水域 + 毒性 | 变为8秒毒区 |

冻结、带电与蒸汽到期后保留4秒水域，再恢复干燥。地图覆盖层直接显示模拟中的水、油、冰、火、带电、蒸汽和毒区。毒雾每次6 MP和毒性萃取1，在前方120距离创造半径110的10秒毒区，无直接伤害，命中或进入施加现有中毒状态。地面危险会影响玩家；离开区域清理这些临时状态。

六处法术机关不阻断主线，奖励原料与成品：

- 外院“荆棘药箱”：火焰打开，阵外火花或余烬战意期间的近战挥击也适用。
- 排水回廊“热冲击封匣”：冰霜→火焰，或水引→雷电，两种解法。
- 档案室“沉眠导能晶簇”：雷电激活。
- 静默祈堂“三相共鸣锁”：冰→火→回响，或水→雷→回响。
- 重卫关隘“守护誓碑”：回响铭印→凝神→Shift＋震荡，用守护爆破命中。
- 排水回廊“毒性蒸馏器”：毒性→火焰。

机关通过真实命中事件读取元素，水引零伤害命中也有效。E查看提示；中间步骤跨区重置，完成状态与一次性奖励持久保存，重置遭遇不重复发奖。

## 材料与取舍

余烬战意在原有近战加成之外赋予火元素命中：可融化、毒焰引爆、点燃油桶/油面或开启火元素机关，挥击不重收施法材料。增益清理后失去该性质。

按M为每个基础动作选择一种可选强化。素材只在对应结果出现时使用，例如给火花配置树脂只强化火阵内产生的火球，阵外火花不消耗树脂。

| 成品 | 使用对象 | 当前效果与额外费用 |
|---|---|---|
| 铭刻灰 | 火/霜法阵 | 持续时间15→25秒，次数不变；每次铭刻1份，额外2 MP |
| 树脂制剂 | 火球 | 飞速降低20%，命中留下半径80、6秒燃烧区；每发1份，额外4 MP |
| 霜盐 | 寒霜弹/寒霜新星 | 寒霜弹多穿透1个目标；新星半径125→155；每次1份，额外2 MP |
| 雷晶粉 | 雷阵、雷矢 | 雷阵每次必需1份；可选强化雷矢为三发28度散射，每发伤害70%，整次只用1份，额外4 MP |
| 回响墨 | 回响铭印、回响三重矢 | 铭印每次必需1；可选让三重矢每发穿透1个目标，整次用1份，额外3 MP |
| 毒性萃取 | 毒雾/孢子、冰霜结果 | 毒雾/孢子每次必需1；可选让寒霜弹/新星同时施加中毒，额外3 MP |
| 守护粉 | 凝神增益、共鸣护盾 | 持续时间+4秒，每次1份，额外2 MP；不增强印记和复苏 |

泼洒树脂必需树脂制剂1；雷阵必需雷晶粉1；回响铭印必需回响墨1；毒雾及其孢子转化必需毒性萃取1，均不能关闭。法阵的必需媒介与之后触发时的可选强化分别消费。基础火/霜法术可选择不配置素材。

已选择且适配的材料不足时拒绝施法，不能静默降为普通版本；玩家可在M明确选择“无可选强化”。技能栏悬停提示和材料页显示当前条件下的实际结果、法力、材料用量及不足原因；准备中的提示同样使用已锁定计划。

## 获取与营地加工

营地“施法材料手册”教授两种工具并提供一次初始原料和成品，旧存档也可领取。火药库有炭屑，回廊有晶砂，祈堂有树液；机关与雷阵记录也有材料奖励。

| 加工成品×1 | 原料消耗 |
|---|---|
| 铭刻灰 | 炭屑1 |
| 树脂制剂 | 树液2 |
| 霜盐 | 晶砂2 |
| 雷晶粉 | 晶砂1 + 炭屑1 |
| 回响墨 | 晶砂1 + 树液1 |
| 毒性萃取 | 树液2 + 炭屑1 |
| 守护粉 | 铭刻灰1 + 晶砂1（需要先加工铭刻灰） |

营地工作台提供加工，M可从营地打开同一界面。常规施法使用预备成品，无需战斗中加工。固定来源仅可搜刮一次，休息、死亡、重进和重置遭遇不补满材料；当前章材料是有限资源，仍可用无素材的基本法术完成战斗。

## 提交与持久化

CastingSupplies持有库存与按动作配置，CastingMaterialData描述适配对象和修正，资源模板保持不变。预览不扣材料、不发射法术；运行时副本承载穿透、范围、散射、命中表面等变化。

多结果预览合计全部费用，可选素材只对适配的结果收取，动作必需材料只收一次。施法准备结束重新核对完整结果、各法阵版本、素材选择、总费用与库存；接受后协调扣除法阵次数或准备状态、法力和材料。状态通过BuffManager版本号重校验，同名刷新也不会复用旧计划；失败回滚恢复原剩余时间与叠层。中断、资源不足、素材配置改变、区域变化不扣费；执行失败退回已扣成本；成功释放打空仍然消费。所有结果先暂存效果实例与Buff，全部接受后才激活和发施法事件；后一个结果执行被拒时不会留下前面的免费效果。投射物命中只产生效果，不再次扣背包。

MVP原有槽2的扩展section保存库存、素材配置和机关领奖，旧存档缺少字段时按空库存迁移。清场和读档不免费回补消耗品。
