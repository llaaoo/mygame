# 灰河谷操作、表现与工具整改

2026-11-11，北京时间。沿用现有 Godot 4.6.3 项目、真实 UID 库存、施法事务与模块化存档。本轮使用 Design Game Studio 的现有项目/试玩流程、Game Studio 的界面规范及项目 Godot MCP；Figma 的 OAuth 未接通，没有声称读取或产出设计稿。手柄支持按用户要求暂缓。

## 战斗选择与信息层级

- 开启选材时仅有 1–3 个合法形式，使用紧凑列表；更多形式保留径向轮盘。切换动作槽时重新确定呈现方式，同一次选择中的布局和选项身份不随材料、法力或现场变化而重排。失效位置保留空位，确认仍重验真实来源；选择不施法、不花材料。
- 窄逻辑视口将选槽与说明堆叠到选择区上方；径向绘制与鼠标命中使用同一缩放变换。实际窗口像素与逻辑视口分开验证，不把编辑器拒绝的窗口调整算作通过。
- 现场作业由 PlayerFieldWork 提供结构化展示值：结果/游戏小时、可中断准备秒数、耗材与不足原因。长规则按需展开，内容可滚动，方法选择与开始/取消按钮保持可达。世界时钟、敌人和受击继续运行。
- K 页动作卡显示基础 MP 和有意义的冷却，最终费用仍由当前 CastPlan 决定；不展示没有用途的零升级路线计数。

## 键位与可读性

菜单入口登记为 InputMap 动作，由 InputBindings 持有默认键、改键和偏好保存。旧整数路由只接收规范化的菜单意图；物理旧键不会继续开菜单。菜单键与战斗/现场作业键不共用同一个物理键，防止关闭界面时残留的全局 Input 边沿触发动作。菜单可以使用独占的修饰组合；捕获组合时忽略单独的修饰按下。Esc、F5/F9及Ctrl切换意图保留，旧版明确设置的 Shift 快捷键继续保留。

主要导航、HUD、操作帮助和新显示的日志说明读取当前菜单绑定；历史发现记录和实物/槽位名称不经按键文本替换。改键失败保留原映射。

画面、动效与声音页提供 100% / 110% / 125% 字号按钮。字号修改共享 Theme、普通控件和阅读正文，不改变世界缩放、镜头或模拟速度；对现有界面立即生效，新界面从同一偏好生成。偏好采用临时文件与替换，写入失败不破坏旧文件、运行值或可见字体。

## 武器表现

剑的斩击、矛的刺击、杖的横扫与弓的拉弦使用不同的装备无关身体帧序列和原生姿态；轻/重击区分准备幅度，姿态沿真实动作的准备/有效/恢复阶段采样。面向偏移仅作用于视觉 rig，角色根、时序、命中和消费不变。补上战杖第三段 `sweep_reverse` 的缺失片段，避免回退为闲置动作。

武器轮廓读取实际穿戴与涂层，弓上的箭只在真实弹药仍存在且尚未释放时显示；离弦后的箭归实际投射物。hound/crawler继续使用自己的无武器 bite 帧。原始素材、许可与散列不变。重建顺序是 `tools/build_actor_animation_assets.py`，随后 `tools/build_beast_animation_assets.py`；生成结果可重复。

## 性能与生命周期根因

独立聚焦窗口和 headless 的同一 24 AI 场景原先都只有约 6–7 FPS。临时隐藏地形没有改变这一现象，不能据此将原因归为地形或软件渲染。隔离回调计时定位到 EnemyCharacterStatus：离屏标签也在每 0.1 秒逐次追加中文文本，引发反复排版。

现在先判断标签显示距离，再查询显示状态；用局部字符串构造完整文本，仅在变化时赋给 Label。资源条仍刷新，AI、状态和世界计时不受显示门控影响。隔离对照中，正常 24 AI 的 headless 为 141–145 FPS，原生软件渲染约 33 FPS；最终集成数据与平台限制见本轮验证记录，不能外推为所有设备帧率。

MCP 最终退出释放工具回调、日志订阅与元数据，普通 transport stop 继续可重启；State Charts 修正自类型默认数组导致的脚本保留，并保留 Inspector hint、元素检查与嵌套资源保存读取。已稳定启动的编辑器退出不再遗留原有六个资源；立即退出仍可能留下 GUT 的既有启动计时器，独立记录。详见[本地清理补丁](dependencies/editor-cleanup-patches.md)。

## 制作登记与审计

`CraftingCatalog → content/crafting/catalog.tres` 是现有 26 个配方的统一登记入口，移除材料列表、额外 ID 列表和法术目录中的重复登记。配方定义共享，已学知识、库存和加工仍由原角色/服务拥有；登记不授予知识，不改变配方 ID、材料或产量。

引用审计区分当前入口、旧入口、校验链、其他入边和真正零入边。校验链包含传递引用，不能把不可从产品入口到达解释为没有调用；任何分类都不是可安全删除清单。
