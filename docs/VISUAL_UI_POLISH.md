# 灰河谷界面与视觉规范

## 当前方向

以现代动作RPG的信息层级、稳定的输入边界和克制的暗色界面重做当前2D原型。石墨底色、青灰强调、黄铜焦点、暖白正文；Noto中文字体统一字重与排版，Lucide线性图标表达动作类别。场景仍是2D像素画面，本轮不宣称具备3D AAA模型、动画或制作规模。

## 信息层级与界面

- 常驻只保留左下生命、法力、体力、稳定，底部快捷槽，顶部地点和右上单个追踪目标。完整主属性放到等级悬停信息；有效属性仍读取角色查询结果。
- 健康生存状态、普通干地不显示额外面板。饥饿、缺水、疲劳和异常地面出现时才提示；N仍提供完整需求与计时。状态采用小图标、剩余秒数和层数，详情悬停查看。
- 施法预览在瞄准、准备和悬停时出现；实际反馈短暂显示后收起。预览仍按真实来源、普通/Shift计划计算，费用与拒绝原因不因界面收起而省略查询或改变执行。
- Tab使用侧栏导航、搜索列表、独立详情；材料用途和规则采用展开说明。装备比较、UID与余量仍由原领域服务提供。
- K为内容、详情、目标槽位三栏。来源详情和13个独立快捷槽各自滚动，长说明不能将目标槽推出窗口。Q/E/R与1—0仍可绑定动作或真实物品。
- 工作台展示配方列表、选中产出、每种原料的持有/需求和单项加工；已学配方优先。未学配方可查看，不能加工。搜索、选择和刷新不消费材料。
- M先选基础动作，再查看当前结果与配置；介质页只展开当前介质的费用、效果与可用修饰，其他介质在列表中。M没有绕过K固定来源，也不自动补条件。
- 通用阅读弹窗将正文与多项行动分栏滚动；少量选择仍在正文下方，保持键盘焦点、Esc与锁定提示。关闭、菜单切换、鼠标点击继续走已有输入/取消边界。

## 场景表现

灰河谷使用 Kenney Tiny Town 替换纯色草地、部分道路、树、屋顶、墙、木桶、路牌、井和铺石。地貌以连续色调过渡替代大块硬色矩形；坐标变化稳定，不使用玩法随机数。只提交镜头附近的地面纹理，摄像机移动跨阈值才重绘。

河流与湖泊的缓慢波纹由独立Shader绘制，桥梁位于水面上方；岸线、道路、障碍碰撞、导航与浅滩介质仍使用原坐标。独立色调Shader统一像素图集和装饰，低强度边缘暗角在HUD下方；装饰不截获鼠标、不发放物品或产生额外领域状态。

角色身体增加轮廓、分层色和步态，武器、盾、护甲、涂层、背包仍绘制实际穿戴。没有换成预先画着武器的角色图，以免破坏所见即所得。交互目标用附近提示与地面聚焦，减少浮空文字；干柴火位说明只在附近出现。篝火和炉灶视觉读取真实休整标记/火源状态，视觉不会制造免费热源。

原有真实地面介质、投射物、法阵充能/寿命、恩赐光环和命中特效继续复用既有表现与领域规则，没有改变范围、伤害、配方或预算。

## 实现边界

- `ui/themes/grayriver.tres`与`GameUIStyle`负责全局主题；`InterfaceIcons`只选择显示符号。
- `ExpeditionScreen`提供复用的导航/搜索/列表/详情/页脚场景。Hub和Workshop填充查询结果，领域服务独占资源与进度写入。
- `FrontierArt`只裁切和绘制纹理；地理、碰撞、导航与介质维护仍归原服务。`ActorStatusView`接收显式角色上下文，兼容战役在HUD进入树后完成绑定。
- 引入素材的许可、来源、修改与散列见[第三方素材](../content/art/THIRD_PARTY_ASSETS.md)。游戏内也提供署名入口。
- 界面信息需要可读、可滚动且说明真实后果；不将调试类名、引擎操作或实现细节放进正常玩家流程。

## 验证与重现

`tests/test_visual_interface.gd`直接启动隔离新档，以真实键鼠检查战役资源绑定、情境HUD、13槽独立滚动、M来源页、地图、800×600窗口内菜单；保留正常AI、角色属性和资源，不授予内容或瞬移。

`controls_workflow`、`unified_quickslots`、`world_pointer_input`继续覆盖鼠标菜单/加工/物品、独立E/1、固定来源、取消、UID和保存恢复、鼠标按键不穿透。`ui_system`覆盖长文滚动、焦点、窗口缩放、模态取消与锁定提示。`rpg_attributes`改为核对属性悬停文案中的有效敏捷，避免要求HUD重新常驻全部属性。

真实渲染截图可在已有Linux显示服务下重现：

```bash
CONTROLS_VISUAL_OUTPUT=/tmp/grayriver-ui \
XDG_DATA_HOME=/tmp/grayriver-ui/data \
XDG_CONFIG_HOME=/tmp/grayriver-ui/config \
XDG_CACHE_HOME=/tmp/grayriver-ui/cache \
godot --path . --rendering-method gl_compatibility --audio-driver Dummy \
  --script res://tests/test_visual_interface.gd
```

截图及本轮实测结果见[验证记录](validation/UI_VISUAL_OVERHAUL_2026_11_07.md)。这是界面、输入和视觉覆盖，不代表自然通关、完整战斗平衡或目标设备性能验收。云端使用Xorg dummy与Mesa llvmpipe软件渲染；仅VSync切换不受驱动支持。GitHub Actions继续停用。

完整回归从已提交的`git archive`导出无`.godot`缓存副本运行`python3 tools/run_tests.py --suite all --jobs 3`。
