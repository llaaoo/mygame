# 画面、技能特效与界面优化

## 视觉方向

保留现有像素角色与监狱场景，统一暗石地面、黄铜边框与克制的元素光色。火、水、雷、毒使用元素目录的颜色，凝霜使用水系形态色；战斗结果仍由原有规则计算。

## 已完成内容

| 部分 | 当前表现 |
|---|---|
| 场景地面 | 错缝石砖、轻微色差与裂纹取代大网格线；单个绘制节点负责装饰 |
| 区域取景 | 镜头约束在区域边界，入口不再露出大片默认灰色；窗口较大时保持居中 |

| 投射物 | 占位图替换为动态火核、冰棱、电弧与毒珠，附带短尾迹；混合性质用次级色点提示 |
| 范围与命中 | 范围波纹、边界、碎片与短暂命中火花；形状半径读取原有范围配置 |
| 法阵 | 细双环、符文刻度、充能点与剩余寿命弧线，沿用原有半径与充能结算 |
| 恩赐 | 角色脚下显示对应颜色的寿命光环，Buff栏增加缺省图形、元素色与更清楚的持续时间 |
| 瞄准 | 投射物与恩赐准备使用各自元素色，地面落点继续采用施法计划的实际介质色和范围 |
| 技能栏 | 显示当前计划的MP费用与元素色条；保留冷却遮罩，准备中显示进度条；普通/Shift悬停信息压缩到可读尺寸 |
| 战斗信息 | 区域目标、底部操作速查、脚下地面性质与短通知分别展示，减少中心遮挡 |
| 交互物 | 远处保留图标；出口、人物保留方向/身份提示；靠近显示完整标题与E提示，距离复用实际交互范围 |
| 日志与配置 | 弹窗随窗口调整，正文换行与独立滚动；按钮可滚动，支持默认键盘焦点并跳过禁用选项；保留不可中断弹窗限制 |

技能栏悬停优先回答“普通和Shift分别发生什么、总费用多少、保留或消费什么”。按M进入配置页可阅读完整解释与材料/地面条件。纯界面文字中的属性名本地化，不更改属性键。

## 实现与边界

- `ElementVisuals`只负责呈现颜色，复用元素目录；不修改亲和、免疫或反应。
- `SpellVisual`只绘制，不添加碰撞或伤害。尾迹采用固定数量图元；独立命中特效最多同时48个，约0.24秒后释放。
- 自带正式纹理的技能保留原纹理。通用投射物与范围原型中的占位图由程序特效接管，实际伤害、速度、穿透、命中次数、准备事务与地面反应继续使用原实现。
- `surface_overlay`直接读取模拟格，每0.1秒重绘，边界和危险提示来自真实地面；没有另建视觉介质状态。原256活跃格和48格导电访问预算不变。
- 石砖的细节由坐标算出，不调用玩法随机数；画面改变不改变关卡种子或障碍碰撞。
- 弹窗仍使用既有暂停与输入阻断机制；关闭、Esc、切区和锁定提示遵循原有边界。

## 运行与视觉复核

正常运行`project.godot`即可体验，入口仍为`mvp.tscn`。

已提供`tools/capture_visual_review.gd`，在真实渲染窗口中启动隔离的MVP、布置实际元素介质与技能原型并截取可复现画面：营地、元素场景、投射物、范围特效、配置页与小窗口配置页。投射物/范围复核使用中间帧停留以便观察，不代表战斗计时或平衡结论；不会发布内容。

云环境可以使用可写的独立用户目录，在已有显示会话运行：

```bash
mkdir -p /tmp/mygame-visual-check/{data,config,cache}
XDG_DATA_HOME=/tmp/mygame-visual-check/data \
XDG_CONFIG_HOME=/tmp/mygame-visual-check/config \
XDG_CACHE_HOME=/tmp/mygame-visual-check/cache \
godot --path . --rendering-method gl_compatibility --audio-driver Dummy \
  --script res://tools/capture_visual_review.gd -- /tmp/mygame-visual-check/screenshots
```

本轮实图位于`/tmp/mygame-visual-reviewed/`，使用Mesa软件渲染核对，图像不是设计稿。原始对照位于`/tmp/mygame-visual-before/`；这些目录是本次会话产物，可按上述脚本重新生成。截图环境会报告不支持切换VSync，不影响截帧；不以软件渲染帧率推断目标设备性能。
