## 开发失败与测量修正

首轮6项定向中4项通过：生命周期夹具禁用了敌人碰撞体后调用move_and_slide，修为仅隔离AI/执行器时钟、保留实际物理空间；阶段夹具在弓手已经出手后才取序号基线，改为启用AI前订阅提交事实，并匹配同一family的起手与收招。8项稳定定向随后通过，GUT23测试/187断言，Python20项通过。

首轮counter/throw虽杀敌，却没有精准格挡或点火，不能算覆盖成功。调整的是外部辅助输入策略：防反先等可见真实前摇而不抢先普攻；投送接近、等物品提交，再在火花实际近距内站定完成准备。初次无效样本保留，未改敌人、预算、窗口或伤害来变绿。武技与物品成本看已提交事实；目标失去/玩家败退不再误认为杀敌。

归档复测新增严格的物品/火花提交断言后，发现投送辅助策略在48—65距离先普攻，使next_attack不再为0，后续永不请求火花；战斗胜利仍正确判为缺少组合、未放行。外部策略改为先站入火花距离并完成提交才允许普攻；未更改玩法。失败事实另存archive-unqualified-throw.json。

## 冻结归档复测

源码冻结8292fe6，从git archive导出无.godot副本，恢复模式首次导入退出0、无ERROR/WARNING。其原生1152×648三类普通/重击/弓手起手与同family收招、真实RMB及遮挡隐藏检查通过；固定位置和装备仅为观察夹具，不代表自然遭遇与平衡。
