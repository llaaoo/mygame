# 原型视觉对齐：Godot 实装

基线 `28681af0d793b43292228bb9575c8b8476b79cd3`，原型为 `docs/design/ui-system` v1.2。本轮保持真实角色、库存、选材、价格、任务与时间查询；原型示例物品、假定数值与顶部评审工具不进入正式游戏。

## 实装变化

- **主题与字体根因**：此前仅给 Window 指定默认字体，跨 CanvasLayer 的控件仍实际解析到 Open Sans Semibold。现在明确登记各控件字体，并在模态入口应用根主题；字号刷新同步根主题，正文与阅读控件明确使用 Noto Sans SC 400。运行查询与新输入检查确认实际字体资源，不只检查偏好值。
- **统一壳**：标题、紧凑导航和固定返回同一行，细分隔线、世界继续运行与真实时刻栏、底部资源摘要。行囊、技艺、成长、手札、地图和既有工作/人物页共用视觉规范。移除旧装饰河纹、厚重的多行标题与大面积按钮底色。
- **行囊**：默认左对齐条目，图标、名称、来源/瓶标/剂量与数量分层；列表和网格显式切换，按名称、总重或参考总值排序，保留具体UID与选择。真实纸娃娃缩小，九个实际装备槽按纵向条目展示；材料和补给分类分开。960×540 时收起次级标题和排序，不缩小世界。
- **详情/比较**：物品标题、类型、来源、重量与参考价值分层；实际装备属性逐行渲染，同槽比较按原值、候选值、差值与收益/代价显示。包括真实轻击起手费用/冲击/距离、装备加值、百分比加成和施法装备能力；不伪造总DPS。保留UID上的强化、归属、涂层和剩余秒数。原位绑定、主操作和更多操作继续调用原库存事务。
- **技艺**：左侧紧凑目录、右侧独立详情，13个独立绑定槽固定在底部，不再占右侧长滚动列。原武技连招配置、具体瓶来源和普通/魔法资格规则保留。
- **HUD**：细资源条，生命/体力轨道对齐，觉醒后显示法力；稳定性在受压时出现。快捷栏严格按视口居中，键位在上、数量在下，当前形式和费用在栏上方。地点方向、追踪、短交互、行囊/地图入口分区；小窗口上移资源与工具入口，防止压住13槽。点击槽仍先查看；物品检查靠近快捷栏显示。
- **约束布局**：卡片内长服务/路标按钮不再强迫整列扩宽，完整目标保留在正文和悬停。阅读独立滚动，主操作可达，菜单继续真实模拟，不改存档格式或玩法预算。

## 与原型的对应边界

本轮以原型的布局、字体、配色、信息层级和主要交互为验收依据。实际可见内容仍取游戏规则：真实九槽、装备加值和起手参数、实际地图、现有任务/知识与服务，不能拿原型样例的假属性、五个物品或假地点覆盖游戏状态。Godot 和浏览器的字体栅格、原生滚动条仍有平台差异。

**原型 v1.2 的三目标准备缺项、UID收藏/待售与批量结算、分级消息历史、独立HUD缩放、地图传闻分类仍未迁入领域系统。** 工作/人物页已统一外壳与列表语言，交易仍使用现有逐件/按数量操作，未把原型待售清单冒充已完成的事务。完整地图与对话内容布局也未逐像素照抄样例；这些属于后续功能与专题视图迁移，不能以本轮截图声称全部原型功能落地。

图形平台：Linux Xorg/X11、Godot 4.6.3、gl_compatibility、Mesa llvmpipe。截图不证明商业GPU性能；Dummy音频没有听感验收。GitHub Actions保持位于停用目录，未启用。
