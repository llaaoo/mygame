- 首轮定向7/8：敌人观察夹具等待短于0.1秒刷新周期、只读Label遗漏RichTextLabel；保留遮挡/文案断言，改有上界等待并读实际正文，随后GUT22测试/174断言及输入检查通过。
- 安全落点专项2/3：负例Resource.duplicate未复制非导出编译落点规则，改为真实重新编译独立章节；正负例随后均通过。规则没有改成存档字段，旧预算fixture未篡改。
- 原生初轮在作业按钮漏F前缀停止，修后同档继续；后因训练师身体挡住脚本直线而停止，增加步行绕行点后继续。不是玩家无法通行；没有回档、瞬移或赠物跳过。
- 初轮probe把食物耐力加成到期的110→100也计入伤害。旧数据仅为raw HP下降；现按已提交damage_applied事实统计伤害，另保留原始health_decreases。
- 临时包装脚本后来覆盖了初轮主进程日志；步骤JSON和分段命令记录仍在。最终干净归档将重走修后完整路线，并为每个进程分别保存原始日志，不能把旧economy日志标成完整主线日志。
