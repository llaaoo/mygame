## 已落实的变化

| 试玩问题 | 本批行为 |
|---|---|
| 水引瞄准仍提示火花 | 主提示读取当前按住的动作，显示实际形态、费用、材料和范围；准备中显示已经锁定的计划。多个动作按下时取最近一个，释放后回到仍按住的动作 |
| 结果形态变化不明显 | 瞄准按现有条件定期刷新，快捷槽显示当前结果图标；远程投射物与近身范围有明确区别 |
| 法阵耗尽后空放火花 | 只有最后一份充能实际提交后才提示耗尽，并说明该动作下一次按剩余条件会得到什么；执行拒绝、回滚不发布错误提示 |
| 护手费用留下占位符 | 修正百分号格式化，比较页显示额外3 MP；部分消费规则保持 |
| 新捷径与免费返营重复 | 保留便捷返营，为三条机关捷径增加营地反向入口，进入时抵达对应检修口；直接复用原机关完成标记，不增加存档字段 |
| 清场后难以局部比较配置 | 已清区域可在Esc重试本区。重现原遭遇，保留其他区域、知识、机关、任务和完成标记；耗材照常消耗，击杀无经验、掉落和残魂；离区结束 |
| 初次阅读过于集中 | 材料手册、凝霜、毒理和导电记录首次显示短说明与一条可试规律；可立即查看全文，J始终保存完整记录，重读不发奖 |
| 旧存档仍显示新手开场 | 根据进度区分首次、继续与已通关，提示可交付委托、已开返场通路和本区试战 |
| 普通近战与掉落回复收益过高 | 探索场景近战倍率设为0.6，初始30伤改为18伤；属性、装备与Buff仍经原属性系统计算。探索敌人掉落回复由20 HP／30 MP改为8 HP／12 MP。旧房间场景保持原配置 |

三条反向检修通路与旧水路选择、旧关隘入口独立。已有机关完成标记的旧存档进入营地就有对应入口。反向入口同时遵守原出口的知识、清场和完成条件；到达点使用原检修口的障碍净空。

本区试战只增加临时战斗会话，不清空任何清理标记，不重新授予机关、发现或补给。敌人仍使用原AI和参数，死亡仍正常处理。击杀事实带有奖励资格，全球额外击杀经验监听也遵守该资格，避免绕过敌人本身的奖励开关。

## 战斗对照

原试玩中，100 HP角色可用7次有效30伤近战快速击败冷却后的210 HP领主。本批增加同一首领、100 HP／60 MP、零自然回复、相同初始材料的受控对照，保持主动AI，每0.65秒通过实际近战组件攻击；这是固定节奏样本，不代表真人构筑排名。

| 配置 | 结果 | 有效投入 |
|---|---|---|
| 无防护准备，持续近战 | 角色死亡，首领剩12 HP | 11次近战，约7.23秒；60 MP保留 |
| 回响铭印→凝神，保留共鸣护盾后近战 | 首领死亡，角色剩37 HP | 12次近战，约7.87秒；剩44 MP，回响墨1 |

控制组没有扩大敌人生命或角色上限。保留防护开始提供实际收益；普通近战仍可用，玩家可以通过准备、走位与组合改善战果。后续属性成长和更多场景的节奏还需继续校准。
