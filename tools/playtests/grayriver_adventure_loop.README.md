## 当前probe适配审查

- 默认 **G选材、M地图**，不是历史报告中的M选材。空白XDG保证默认映射；若加载了改键偏好，硬编码KEY_G不代表读取当前映射。
- 父agent已将 `wheel_choice` 的固定八向几何改为 `wheel.entry_point(index)`。当前1–3项是紧凑列表，更多项是圆环，而且圆环有缩放；父适配器也补了翻页与失效空项检查。旧计算即使发真实鼠标事件也可能点错。
- 当前轮盘只显示实际可释放的具体形式，不展示auto伪选项；不要发送 `payload:auto` 期望在G中恢复跟随。来源/法力/冷却不满足时缺项是合法拒绝，应查状态，不补料。
- `wheel_choice`仍只按payload取第一个匹配项，没有严格匹配modifier；同payload的普通/修饰可并列，余量瓶还有alternatives。当前路线只用未修饰ember。脚本只查轮盘关闭与攻击未泄漏，不能证明选中了请求UID/形式；须核对shortcuts.selection。翻页和失效空扇区也不能靠旧index无条件重放。
- 旧基础路线在(-3060,-1200)按F读猎营已经过期，记录现位(-3300,-1200)，新路线先在(-3350,-1200)读。该坐标错误属于测试辅助失效，不代表玩家不能交互。
- `duel basic`直追敌人，不自动绕新书架。新路线必须先绕西架南端、东架北端；同组敌人的反应可能使预期顺序变化。`target_missing`、`walk_timeout`、死亡均需保留并人工诊断，不冻结或重置敌人。
- `inventory`用definition查第一件未穿戴实物，不接收精确UID。因此选刀/甲后要记录真正选中的UID；重复装备交易前确认出售的是未穿戴那件。所有此类动作仍经实际UI点击提交。
- 当前武技是Ctrl+左键和临时连招窗口，不能照搬combat_depth中的旧E技能键/technique_bind。此路线不学武技，避免把目标扩大到另一个系统。
- 标签点击会抓第一个可见的同文按钮；例如交易行可能重复。界面里数量/焦点改变后首个Esc可能只离开输入框。实际截图/状态优先于固定多按Esc，避免误开系统菜单。
- `expect`、`note`、`phase`均是人工审查元数据，**probe不会执行这些断言**。step.error为空不是对应机制已经通过。

## 真实物资和易变条件

手册本身提供铭刻灰2、炭4、晶6、树脂制剂2、树液6等，口粮袋再给有限食水/原料。先造2火石支付炭4/晶2；火焰抹布支付树脂制剂1/炭1/布1；树脂喷剂支付树脂制剂1/饮水1。物资必须从新档实际领取/搜刮，不由测试补充。用掉的敌人喷剂、火石不应再从模板掉出。

初始树脂制剂2在抹布与喷剂制造后耗尽，原口袋格释放，新喷剂应进入口袋。因此最后安排“移至背包→移至口袋”，核对移动前后同UID；如本轮额外手动制作/使用或改了奖励，先核对实际位置，不能靠注入库存复原预期。烤饼/水需站定使用，路线保留2.5秒准备，不紧跟移动取消。

萨芙营业受真实日程、距离与安全条件限制，店家钱袋有限。F在(-3210,2220)按当前近物交互应打开整修铺；若实际进入NPC交谈，选“交易与整修”，不要跳过交易。若夜间返回，应通过正常营地休息/行程花费推进到营业时间，并记录成本；不改钟或后台补钱。

压印台本身不额外生成物品。奖励证据应写成“机关开启搬运竖井，原名册/回响物资仍在原处，回镇新委托发1属性点”，不能声称压印台吐出旧原型导能晶簇奖励。原型`archive`与灰河谷`river_archive`不是同一区域。

本轮共用返程落点已改到(-2700,-1800)，声明520单位初始敌岗间距；最近追猎者约583单位。原来(-2600,-1660)约431单位，位于其440侦测范围内。这个安全约束针对初始敌岗；敌人若被引到入口或已有追击，仍须真实撤退，不能把门当成清除仇恨。

## 保存重启证据

1. 制作喷剂后记录其UID、容器与完整properties，绑定Q必须锁定这瓶。
2. Q短喷只为产生真实部分消耗。起手0.25秒、每0.5秒一剂，软件渲染/settle会改变实际按住长度；期望余1或2剂，不能只看按住0.28秒就断言恰好消耗1剂。若未消费或喷空，保留失败样本，不写doses、不偷偷换新瓶。

4. 退出整个进程，再以同一隔离XDG启动新进程；不能仅F9或复用原对象。比较同一瓶UID/余剂、主手/护甲UID、材料与币、卖出物在商家/玩家两边的归属、机关和任务防重。
