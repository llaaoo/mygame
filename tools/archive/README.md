# 历史一次性迁移工具

此目录保存旧目录迁移、批量路径替换、碰撞补丁及占位脚本生成器，保留历史用途，不属于当前游戏、导入、构建或验证流程。`.gdignore`将其排除于Godot资源扫描。

这些脚本含历史硬编码路径，并可能覆盖现有脚本；不要对当前项目直接执行。需要历史操作时先在独立副本审查输入、输出和差异。当前输入统一由`InputBindings`管理，物品使用现有目录注册，不通过重新生成占位文件修复缺失依赖。

当前入口与验证见根目录README、AGENTS.md和`tools/run_tests.py`。内容生成工具`generate_prison_tileset.gd`仍保留在tools下，属于离线美术管线。

`combat_prototypes/`保存没有场景、Resource、运行时调用或行为测试来源的早期枚举、条件、固定加伤及冰甲/火焰示例。它们不再作为当前战斗架构的一部分注册；真正被回归使用的CallableNode和内容校验器继续保留。旧工程分析或代理历史中提到类名，不构成运行时使用证据。
